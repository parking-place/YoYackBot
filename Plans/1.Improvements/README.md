## 기준과 보존 범위

- 최초 브랜치: `claude/plan-1.2.0`. 제품 버전은 `VERSION`, `pyproject.toml`, 패키지에서 `1.1.3.1`이며 출시 명칭은 `v1.1.3a`다.
- `1.2.0`은 6단계 모두 **PLANNED**다. `/말투`, 답장 범위, 평가 후보·심사·최근 평가 기억은 아직 구현된 기능으로 세지 않았다.
- 검토 도중 다른 작업에 의해 체크아웃이 `main`, `3c059f43dbdfea6b3e79e6279939777ccea0e971`로 바뀌었다. 검토자는 브랜치를 바꾸지 않았다. 버전 혼합을 피하기 위해 최초 커밋의 Git archive를 고정했으며, 추적 파일 533개의 내용이 최초 해시와 일치함을 확인했다.

- 작성 대상은 이 폴더의 Markdown 문서뿐이다. 제품 코드·테스트·설정·기존 문서·`Plans`를 수정하거나, 배포·커밋·push하지 않았다. 기존 `.claude/` 미추적 파일도 보존했다.
- 운영 서버 접속, 운영 DB·인증값 열람, 실제 Discord 게시, 실제 모델 호출은 수행하지 않았다.
