# 0.1.0-P2 — 채널 설정 명령·관리 권한 구현

- 상태: **IN_PROGRESS**
- 명세 근거: §4-1–4-4
- 검증 ID: `T010-P2-A`, `T010-P2-B`
- 검증 환경: **LIVE** — 개발 Discord 서버/채널에서 실제 이벤트·권한·출력을 확인한다. 실제 Codex 사용 여부도 구분한다.

## 선행 조건

[0.1.0-P1](../0.1.0/01-gateway.md)가 검증과 GitHub push 확인까지 끝나 DONE이어야 한다.

## 수행 작업

1. `/채널 설정`을 개발 Guild에 등록하고 접근 가능한 텍스트 채널을 고르는 Channel Select UI를 구현한다.
2. 복수 선택, 빈 선택으로 전체 해제, 취소·만료를 처리한다. SDK/API의 선택 개수 제한은 확인 후 나눠 선택하는 UX로 대응한다.
3. 관리자/Manage Channels 권한을 명령 진입과 저장 callback에서 재검증하고 다른 사용자·다른 Guild의 상호작용을 거부한다.

## 산출물

설정 Slash Command, 채널 선택 UI, 권한 검사.

산출물은 앞으로 구현할 대상이다. 이 계획 파일을 작성한 것만으로 산출물이 구현되었다고 판단하지 않는다.

## 검증과 통과 기준

- [ ] `T010-P2-A`: 관리자는 설정을 바꾸고 일반 사용자는 진입 및 위조/만료 callback에서 모두 거부된다.
- [ ] `T010-P2-B`: 접근 불가 채널·지원 외 채널·선택 도중 권한 취소가 저장되지 않으며 오류 안내가 하오체다.
- [ ] 영향받는 선행 기능의 회귀 검사가 통과하고 실패·미실행·실환경 미확인 항목을 구분했다.

## 단계 완료 — GitHub 업로드 필수

- [ ] 위 작업·검증을 완료하고 [증거 양식](../EVIDENCE_TEMPLATE.md)에 대상 SHA·환경·결과·제한을 기록했다.
- [ ] 실제 비밀값·`.private`·DB·Discord 원문·임시 파일이 커밋에 없음을 확인했다.
- [ ] 구현과 증거를 단계별로 commit하고 대상 브랜치에 **GitHub push**했다.
- [ ] 원격에서 증거 커밋 존재와 구현 SHA 포함, 필요한 CI 결과를 확인했다.
- [ ] [STATUS](../STATUS.md)를 DONE으로 갱신한 종료 커밋도 push하고 마지막 원격 반영을 확인했다.

**push 실패 또는 원격 확인 미완료는 PUSH_PENDING이며 단계 완료가 아니다.** 상세 절차와 SHA 기록 방식은 [GIT_WORKFLOW](../GIT_WORKFLOW.md)를 따른다.

## 실패 및 다음 단계

검사 실패 시 실패 사례·환경·복구 방법을 증거에 남기고 IN_PROGRESS/BLOCKED로 유지한다. 수정 후 영향 검사를 다시 수행하며 완료 전에 의존 단계로 넘어가지 않는다.

이 단계의 마지막 원격 반영까지 확인한 뒤 다음으로 진행한다: [0.1.0-P3](../0.1.0/03-settings-store.md).
