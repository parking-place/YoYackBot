# 1.0.0c-P4 — 모델 처리량·역압

상태: **IN_PROGRESS**. 검사: `C7/C8`. P3의 원격 완료 후 개발 LXC에서 수행한다.

## 작업

봇 계정의 모델 CLI 동시 실행 허용치와 비용/한도를 측정한 뒤 `codex_concurrency`와 요청당 작업 예산을 정한다. 무조건 병렬 수를 늘리지 않는다. 용량 부족은 유한한 대기·포화 안내로 처리한다. 1.0.0b-1의 대기 시간 변경과 1.0.1의 사용량/상태 명령이 장시간 작업에 가려지지 않게 한다.

## 통과 기준

- `C7`: 단일/복수 슬롯 후보의 처리량·p95 지연·오류율·한도 소비를 합성 작업으로 비교해 선택 근거를 남긴다.
- `C8`: 모델 실패·한도 초과·취소에도 다른 채널이 진행되고 출력/임시 파일이 교차하지 않는지 확인한다.

결과·동일 구현 SHA를 [검증 목록](TEST_MATRIX.md)에 남긴다. **이 단계만의 C(구현) → E(증거) → D(종료)를 각각 commit·GitHub push하고 원격 포함 관계·필요 CI를 확인해야 DONE**이다. 실패·미실행은 PASS로 세지 않는다. [공통 Git 규칙](../GIT_WORKFLOW.md)을 따른다.
