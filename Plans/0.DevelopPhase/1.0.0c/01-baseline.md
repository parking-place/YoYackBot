# 1.0.0c-P1 — 동시 부하 기준선

상태: **PLANNED**. 검사: `C1/C2`. 1.0.0b의 원격 완료 후 개발 LXC에서 수행한다.

## 작업

합성 채널 2/4/8곳에서 짧은 요청과 100건 초과 요청을 섞어 수집, 모델 슬롯 대기, 모델 실행, 게시 시간을 분리 측정한다. 현재 FIFO 대기열에서 긴 작업이 짧은 작업을 막는 정도와 Discord History/SQLite/CLI 병목을 재현한다. 원문 없이 요청 수·지연·성공률·오류 종류만 남긴다.

## 통과 기준

- `C1`: 같은 Guild와 다른 Guild의 2/4/8 채널 동시 부하에서 성공/만료 비율과 단계별 지연을 재현한다.
- `C2`: 동일 채널 중복 차단·채널별 쿨타임·다른 채널 데이터 분리를 기준선에서 확인한다.

결과·동일 구현 SHA를 [검증 목록](TEST_MATRIX.md)에 남긴다. **이 단계만의 C(구현) → E(증거) → D(종료)를 각각 commit·GitHub push하고 원격 포함 관계·필요 CI를 확인해야 DONE**이다. 실패·미실행은 PASS로 세지 않는다. [공통 Git 규칙](../GIT_WORKFLOW.md)을 따른다.
