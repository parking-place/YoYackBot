# 1.1.2 — 이모지·주제별 한줄 비평·짧은 기본 요약

- 상태: **PLANNED** (계획 문서만 작성; 기능 구현·배포 전)
- 단계 수: **4단계**
- 선행 버전: 출시된 [1.1.1a](../1.1.1a/README.md)(`v1.1.1a`, 2026-10-01)

## 목표

1. 이모지를 적극적으로 써서 가독성과 재미를 높인다(주제 소제목 필수, 결정 ✅·진행 중 ⏳, 본문·비평 줄은 가볍게).
2. 모든 길이에서 주제마다 **짧은 한줄 비평**(`↳ *…*`)을 꼭 붙인다.
3. 기본(짧게) 요약을 **주제마다 내용만 1~2줄**로 바꾼다. `길게`·`자세히`는 지금 형식을 유지한다.
4. 도움말을 새 형식에 맞게 고친다.

원인·이모지 규칙·비평 줄 규칙·짧게 형식 예·코드 지표·사용자 결정은 [계약](CONTRACT.md)에 있다.

## 검증 방침

- 실제 모델 평가에서 짧게는 주제당 내용 2줄 이하가 대부분이어야 하고(목표 주제의 80% 이상), 주제 한줄 비평은 모든 길이에서 주제 90% 이상에 붙어야 하며, 소제목 이모지는 전부 있어야 한다. 사실·화자 오류, 결정·진행 중 분류 오류, 미결 조롱, 금지선 위반은 0건이다.
- 1.1.1 추가 요청 우선(시간순·이모지 빼고·평가 빼기·욕 빼고)과 1.1.1a 진행 중 규칙은 회귀로 확인한다.
- 사용자 보고·실제 대화는 공개 문서에 옮기지 않고 합성 대화만 쓴다. 배포 전 진행 중 요약이 없음을 확인한다. 시간 의존 시험은 고정 시계를 쓴다.
- 실제 시험 Discord 확인은 P4 배포 뒤 사용자가 직접 입력한다. 확인하지 못하면 `NOT_RUN`.
