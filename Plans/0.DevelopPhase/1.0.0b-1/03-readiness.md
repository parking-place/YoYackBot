# 1.0.0b-1 P3 — 초기 수집 안내와 요약 준비 상태

상태: **DONE**. 검사: `B3A/B3B`. [검증 증거](../evidence/1.0.0b-1-P3.md)와 [상태](STATUS.md)에 C/E/CI 및 D 종료를 기록한다. 실제 Discord 게시 검증은 P6에 남았다.

## 작업

새 주시 채널의 첫 전체 수집을 시작할 때 채널에 정확히 `안녕하시오. 요약을 위해 데이터 수집중이오.`를 게시한다. 과거 페이지 수집과 **수집 시작~완료 사이 재확인**까지 끝난 뒤 정확히 `이제부터 요약을 해줄 수 있을 것 같소.`를 게시한다. 그 사이 `!!요약좀`의 요약 요청에는 `참을성을 기르시오 아직 준비가 되지 않았소.`만 답한다. 이 요청으로 History 수집/모델 대기열/쿨타임을 시작하지 않는다. `!!요약좀 도움`은 이용 가능하다. 완료 뒤 요약은 DB에서만 읽고, 새 메시지는 실시간으로 DB에 저장한다. 다른 채널의 작업은 영향받지 않는다.

시작·완료 게시 상태와 Discord 메시지 ID를 저장해 재시작/재시도 시 중복을 억제한다. 게시 결과가 불명확하면 채널의 해당 봇 메시지를 조회해 확인한 뒤 재시도한다. 부분 수집·권한 거부·주시 해제에서는 완료 안내를 보내지 않는다. 게시 권한이 없으면 오류를 기록하되 준비 상태를 거짓으로 바꾸지 않는다. 기존 주시 채널의 업그레이드 전체 수집에도 준비 상태 게이트를 적용하되 첫 주시 안내를 소급 게시하지 않는다. 요청별 안내를 정의한 [1.0.2](../1.0.2/README.md)와 문구/상태를 구별한다.

## 통과 기준

- `B3A`: 신규 주시·완료·재시작·중복 이벤트·게시 응답 불명확·권한 거부에서 시작/완료 문구가 정확하고 중복을 막는다. 완료 전에는 준비 완료 문구를 내지 않는다.
- `B3B`: 초기 수집 중 기본/기간/건수 요약 요청 모두 정확한 대기 문구만 받고 모델 실행·쿨타임이 없으며 도움말은 작동한다. 초기 수집 완료 후 정상 요청이 재개된다.
