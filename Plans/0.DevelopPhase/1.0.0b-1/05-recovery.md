# 1.0.0b-1 P5 — 실패 정리와 재개

상태: **PLANNED**. 검사: `B5A/B5B`. P4 원격 완료 후 개발 LXC에서 수행한다.

## 작업

대량 요약의 입력 초과·모델 오류·대기 만료·게시 오류를 구분하고, 실패 시 채널 잠금과 임시 파일을 정리한다. 실제 전체 게시 전에 성공이나 5분 쿨타임을 기록하지 않는다. 비재시도 오류를 무한 재시도하지 않는다. 초기 수집의 권한 거부·디스크 제한·429/네트워크 장애에서는 부분 범위와 재시도 가능 시점을 남기며, 주시 해제는 작업을 취소한다. 스키마/설정 롤백 후 1.0.0a 서비스가 운영 DB를 읽을 수 있는지 확인한다.

## 통과 기준

- `B5A`: 각 요약 실패 주입 후 잠금·파일·쿨타임이 정리되고 다음 요청이 정상 진행한다.
- `B5B`: 수집 실패·재시작·롤백에서 완료/부분 상태와 시작/완료 안내가 어긋나지 않고 유한하게 재개된다. 다른 채널의 수집·요약은 계속 진행한다.
