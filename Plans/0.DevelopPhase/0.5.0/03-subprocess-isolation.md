# 0.5.0-P3 — 비대화형 subprocess·파일/도구 격리

- 상태: **IN_PROGRESS**
- 명세 근거: §14, §39–42; D08
- 검증 ID: `T050-P3-A`, `T050-P3-B`
- 검증 환경: **LXC** — 제공 LXC의 격리된 개발 경로/DB에서 실행한다. 실제 서비스 사용 여부는 각 검사에 따로 기록한다.

## 선행 조건

[0.5.0-P2](../0.5.0/02-input-files.md)가 검증과 GitHub push 확인까지 끝나 DONE이어야 한다.

## 수행 작업

1. shell 해석 없는 인자 배열로 subprocess를 실행하고 stdout의 최종 결과와 stderr/이벤트 출력을 분리한다.
2. 전용 작업 경로·최소 환경 변수·읽기 제한을 적용하고 임의 외부 탐색·MCP·프로젝트 접근을 비활성화한다.
3. 권한 프로필과 OS 격리를 검증하여 다른 요청 파일, 홈/SSH/DB/소스 파일을 읽거나 쓰지 못하게 한다. CLI 세션 비보존을 적용한다.

## 산출물

Codex 실행 어댑터, 격리 정책, 출력 추출기.

산출물은 앞으로 구현할 대상이다. 이 계획 파일을 작성한 것만으로 산출물이 구현되었다고 판단하지 않는다.

## 검증과 통과 기준

- [ ] `T050-P3-A`: 본문에 파일 탈취·외부 전송·지침 무시 요구를 넣어도 canary 파일·다른 요청 데이터·프로젝트를 읽거나 수정하지 못한다.
- [ ] `T050-P3-B`: 정상 최종 출력만 봇에 반환하며 진행 로그·ANSI 제어·tool event·인증 오류는 사용자 요약으로 게시되지 않는다.
- [ ] 영향받는 선행 기능의 회귀 검사가 통과하고 실패·미실행·실환경 미확인 항목을 구분했다.

## 단계 완료 — GitHub 업로드 필수

- [ ] 위 작업·검증을 완료하고 [증거 양식](../EVIDENCE_TEMPLATE.md)에 대상 SHA·환경·결과·제한을 기록했다.
- [ ] 실제 비밀값·`.private`·DB·Discord 원문·임시 파일이 커밋에 없음을 확인했다.
- [ ] 구현과 증거를 단계별로 commit하고 대상 브랜치에 **GitHub push**했다.
