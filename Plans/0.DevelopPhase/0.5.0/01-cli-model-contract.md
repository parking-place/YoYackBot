## 수행 작업

1. LXC의 고정 CLI 버전에서 비대화형 실행, 모델 ID, Light에 대응하는 reasoning 설정, 최종 출력 수신 옵션을 확인한다.
2. 전용 인증 방식과 최소 권한 실행 환경으로 합성 대화를 호출하고 실제 요청 설정·종료 코드·출력만 증거화한다.
3. 지원하지 않는 모델/설정이나 인증 실패는 BLOCKED로 기록하며 요구 모델을 임의 변경하지 않는다. 자동 fallback과 무제한 재시도는 넣지 않는다.

## 산출물

검증된 CLI 호출 계약, 모델 설정 기록, 인증 운영 절차.

산출물은 앞으로 구현할 대상이다. 이 계획 파일을 작성한 것만으로 산출물이 구현되었다고 판단하지 않는다.
