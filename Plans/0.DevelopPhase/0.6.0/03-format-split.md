## 선행 조건

[0.6.0-P2](../0.6.0/02-quality-evaluation.md)가 검증과 GitHub push 확인까지 끝나 DONE이어야 한다.

## 수행 작업

1. 시간형 시작점·오늘 자정·날짜를 포함한 다일 범위·개수형 최저 시각을 KST 머리말로 출력한다.
2. 문장/문단·Markdown을 가능한 보존하면서 설정된 Discord 전송 길이 아래로 분할하고 첫 메시지에만 머리말을 넣는다.
3. 멘션을 읽기 쉬운 이름으로 표시하고 allowed mentions를 제한하여 @everyone/역할/사용자 알림을 유발하지 않는다.

## 산출물

출력 formatter, splitter, 멘션 안전 정책.

산출물은 앞으로 구현할 대상이다. 이 계획 파일을 작성한 것만으로 산출물이 구현되었다고 판단하지 않는다.

- [x] 영향받는 검사를 수행하고 미실행·실환경 미확인 항목을 증거에서 분리했다.

## 단계 완료 — GitHub 업로드 필수

- [ ] 위 작업·검증을 완료하고 [증거 양식](../EVIDENCE_TEMPLATE.md)에 대상 SHA·환경·결과·제한을 기록했다.

- [ ] 원격에서 증거 커밋 존재와 구현 SHA 포함, 필요한 CI 결과를 확인했다.
