- 대상 구현: `b989a4738455a3f7d8144c654c43b19a458da206`
- 평가 환경: OpenJevLXC 전용 봇 계정, 격리된 합성 대화 20건
- 모델 계약: Codex CLI `0.158.0`, `gpt-6-luna`, reasoning `low`
- 프롬프트: `0.6.0-p1-v1`
- 입력: `tests/fixtures/summary_quality.json`; 실제 Discord 대화는 사용하지 않음

Codex의 예비 판정으로는 `required` 근거 항목 42/42개가 요약에 포함됐고,
중대한 날조·오귀속 0건, 한국어 하오체 적합 20/20건이었다. 이는 단일 실행의
합성 자료 결과이며, 통계적 정확도나 실사용 대화 품질을 보장하지 않는다. 사용자는
Codex의 수동 대조 결과를 수락했다. 독립적인 사람이 출력 원문 20건을 다시 대조한
것은 아니며, 이 차이를 후속 베타 품질 검토에 넘긴다.

출력 전체는 공개 저장소에 싣지 않았다. 개인정보가 없는 합성 입력과 판정 요약만
남겼으며, 원문 대화·인증 정보·모델 실행 로그는 포함하지 않는다. 기계적 출력 검사는
빈 답변·비한국어·원문 그대로 복사·내부 파일 경로 보고를 `output_invalid`로
분류한다. 사실성·하오체 판정은 문자열 검사만으로 보장되지 않는다.

실행 직후 요청 임시 폴더는 0개였고 전용 인증 폴더에는 보호된 `auth.json`만
남았다. LXC의 170개 테스트, Ruff, 저장소 구조 검사와 구현 SHA의 GitHub CI가
통과했다. 실제 Discord 게시와 자동 명령 경로는 후속 단계에서 검증한다.

0.6.0-P5의 실제 통합 시험에서 간접 인용과 불필요한 ‘정정’ 표현을 개선했다.
프롬프트를 `0.6.0-p5-v2`로 올린 뒤 21건 전체를 재실행한 결과는
[보강 평가](QUALITY_REGRESSION_V2.md)에 기록했다. 이 문서의 20건 수치는
최초 `0.6.0-p1-v1` 평가 이력이다.
