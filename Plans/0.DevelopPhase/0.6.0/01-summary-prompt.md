- 상태: **IN_PROGRESS**
- 명세 근거: §14–19, §35–38, §45

## 선행 조건

[0.5.0-P5](../0.5.0/05-engine-acceptance.md)가 검증과 GitHub push 확인까지 끝나 DONE이어야 한다.

## 수행 작업

1. 한국어·하오체·화자 귀속·주제/결정/미해결 우선순위를 담은 버전 관리 프롬프트를 작성한다.
2. 없는 결론·사용자 의도 추측·농담의 결정 오인·빈 섹션 강제를 금지하고 불확실성 표현을 정한다.
3. 신뢰된 요약 지침과 대화 데이터의 경계를 명확히 하며 원문 안의 명령·URL이 추가 도구 실행으로 이어지지 않게 한다.

## 산출물

요약 프롬프트, 합성 대화 품질 fixture, 평가 rubric.

산출물은 앞으로 구현할 대상이다. 이 계획 파일을 작성한 것만으로 산출물이 구현되었다고 판단하지 않는다.

## 검증과 통과 기준

- [ ] `T060-P1-A`: 합성 fixture에 화자별 주장·질문/답변·합의·반대·미확정·농담 사례가 있고 정답 사실 목록이 명시된다.
- [ ] `T060-P1-B`: 프롬프트 변경은 버전과 함께 추적되며 대화 안의 지시를 시스템 지침으로 승격하지 않는 구조다.
- [ ] 영향받는 선행 기능의 회귀 검사가 통과하고 실패·미실행·실환경 미확인 항목을 구분했다.

## 단계 완료 — GitHub 업로드 필수

- [ ] 위 작업·검증을 완료하고 [증거 양식](../EVIDENCE_TEMPLATE.md)에 대상 SHA·환경·결과·제한을 기록했다.

- [ ] 구현과 증거를 단계별로 commit하고 대상 브랜치에 **GitHub push**했다.
