# 0.6.0 합성 대화 품질 평가 기준

- 프롬프트 버전: `0.6.0-p1-v1` (`src/yoyackbot/summary_prompt.py`)
- 합성 자료: `tests/fixtures/summary_quality.json`의 20개 사례
- 모델 계약: Codex CLI `0.158.0`, `gpt-6-luna`, reasoning `low`
- 평가 환경: 실제 모델 호출은 LXC의 전용 계정에서만 수행한다.

각 사례의 `messages`는 `[인물 키, 수집 시점 표시명, 본문, 첨부 존재 여부(선택)]`다.
인물 키가 같으면 표시명이 바뀌어도 같은 사람이며, 표시명이 같아도 인물 키가 다르면
다른 사람이다. `required`는 원문에 근거가 있는 주요 사실이고 `forbidden`은 말해서는
안 되는 결론이다. 이 목록은 문자열 일치 채점표가 아니라 사람이 답변과 원문을 대조할
때 쓰는 사실 기준이다.

## 판정

1. 화자별 발언, 질문과 대답, 최신 정정·철회가 원문과 맞는지 확인한다. 중대한
   날조나 발언 주체 오귀속은 한 건도 허용하지 않는다.
2. 명시적 합의만 결정으로, 답이 나오지 않은 내용만 미해결점으로 적었는지 확인한다.
   농담·가정·조건부 동의를 확정 결정으로 바꾸면 중대한 오류다.
3. `required`의 주요 결정·미해결점 포함률은 전체 해당 항목 기준 90% 이상이어야
   한다. 사례별 하오체 적합률도 90% 이상이어야 한다.
4. 빈 답변, 비한국어 답변, 원문 전체 복사, 도구 실행 보고, 인증/다른 파일 내용 노출은
   실패다. 링크·첨부 내용은 실제 대화 본문에 없는 한 추측하면 안 된다.
5. 평가표에는 사례별 결과와 사람이 확인한 근거, 모델·프롬프트 버전, 미해결 한계를
   기록한다. 문자열 검사만으로 사실성이 보장된다고 해석하지 않는다.

실제 Discord 대화나 인증 정보는 평가 자료와 공개 증거에 포함하지 않는다. 모델 출력
원문은 개발 서버의 요청 전용 경로에서만 검토하고, 공개 문서에는 결과의 판정·건수와
합성 사례만 기록한다.
