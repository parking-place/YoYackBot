# 0.6.0-P5 — 수집부터 게시까지 출력 통합 게이트

- 상태: **PUSH_PENDING**
- 명세 근거: §14–22, §30, §45–47, §53 요약/출력
- 검증 ID: `T060-P5-A`, `T060-P5-B`
- 검증 환경: **LIVE** — 개발 Discord 서버/채널에서 실제 이벤트·권한·출력을 확인한다. 실제 Codex 사용 여부도 구분한다.

## 선행 조건

[0.6.0-P4](../0.6.0/04-delivery.md)가 검증과 GitHub push 확인까지 끝나 DONE이어야 한다.

## 수행 작업

1. 개발 Discord의 합성 대화를 수집해 실제 CLI로 요약하고 동일 채널에 게시하는 통합 경로를 검증한다.
2. 빈 대화·한 사람/다수 화자·긴 대화·첨부/링크·명령성 본문·전송 실패를 포함한다.
3. 출력 품질·길이·임시파일 정리 증거를 기록하고 각 단계 push를 확인해 0.6.0을 통합한다.

## 산출물

실제 수집→CLI→게시 증거, 출력 사용자 안내, 통합 회귀 결과.

산출물은 앞으로 구현할 대상이다. 이 계획 파일을 작성한 것만으로 산출물이 구현되었다고 판단하지 않는다.

## 검증과 통과 기준

- [x] `T060-P5-A`: 정상 결과가 하오체·화자·사실성·채널·머리말·분할 요구를 충족하고 처리 후 입력 파일이 없다.
- [x] `T060-P5-B`: 통합 호출은 개발용 수동 runner에서 수행하며, 아직 미구현인 자동 명령 동시성/쿨타임은 PASS로 기록하지 않는다.
- [x] 영향받는 검사를 수행하고 미실행·실환경 미확인 항목을 증거에서 분리했다.

## 단계 완료 — GitHub 업로드 필수

- [ ] 위 작업·검증을 완료하고 [증거 양식](../EVIDENCE_TEMPLATE.md)에 대상 SHA·환경·결과·제한을 기록했다.
- [ ] 실제 비밀값·`.private`·DB·Discord 원문·임시 파일이 커밋에 없음을 확인했다.
- [ ] 구현과 증거를 단계별로 commit하고 대상 브랜치에 **GitHub push**했다.
- [ ] 원격에서 증거 커밋 존재와 구현 SHA 포함, 필요한 CI 결과를 확인했다.
- [ ] [STATUS](../STATUS.md)를 DONE으로 갱신한 종료 커밋도 push하고 마지막 원격 반영을 확인했다.

**push 실패 또는 원격 확인 미완료는 PUSH_PENDING이며 단계 완료가 아니다.** 상세 절차와 SHA 기록 방식은 [GIT_WORKFLOW](../GIT_WORKFLOW.md)를 따른다.

## 실패 및 다음 단계

검사 실패 시 실패 사례·환경·복구 방법을 증거에 남기고 IN_PROGRESS/BLOCKED로 유지한다. 수정 후 영향 검사를 다시 수행하며 완료 전에 의존 단계로 넘어가지 않는다.
