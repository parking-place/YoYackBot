# 1.0.2c-P3 — 실제 모델 말투·사실성 평가

- 상태: **IN_PROGRESS** · 검사: `T102c-P3-A/B` · 환경: 개발 LXC, 실제 고정 모델(비게시)

## 선행 조건·작업

[P2](02-tone-prompt.md)의 원격 완료 뒤, 1.0.1에서 만든 합성 사례(`tests/fixtures/summary_modes.json`)로 실제 `gpt-6-luna`/low 요약을 비게시로 만든다. 건수는 [계약](CONTRACT.md)의 결정값(기본: 기본·자세히·짧게 각 3건, 총 9건)을 넘지 않는다. 평가 전후 사용량을 기록하고, 한도가 더 내려가 요약 운영에 위험하면 평가를 멈추고 사용자에게 알린다.

사람 검토로 말투와 사실성을 함께 본다. 결과 표에는 합성 대화·모델 출력만 싣는다.

## 검증·완료 기준

- `T102c-P3-A`(사실성 게이트): 필수 사실 전부 포함, 금지 사실 0, 화자 귀속 오류 0, **화자가 하지 않은 말을 지어낸 인용 0**, 제안→결정·미정→확정 둔갑 0. 하나라도 어기면 FAIL이며 P2로 돌아가 프롬프트를 고친다.
- `T102c-P3-B`(말투): 모든 출력이 비속어를 섞은 거친 구어체를 쓰면서 문장 끝이 하오체이고(반말 어미로 끝난 문장 비율 10% 이하 목표), 실제 사람을 성적으로 다룬 문장·혐오 비하어·인신공격 0, `짧게`는 본문 4~6줄 목표를 유지한다. 모델이 비속어를 지나치게 순화하면 사용자에게 보여 주고 프롬프트를 조정한다. 결과 문장 예를 증거에 남기고 사용자 확인을 받는다.

같은 SHA의 결과를 기록하고 구현 C(평가 도구 변경이 있으면) → 증거 E → (E CI 성공 확인) → 종료 D를 각각 commit·GitHub push·원격 확인한다. [공통 Git 규칙](../GIT_WORKFLOW.md)을 따른다.
