# 1.0.2c 쿨타임·요약 말투 계약

이 문서는 구현 목표다. 현재 제품 동작이나 시험 PASS를 뜻하지 않는다. 출시된 `v1.0.2b`(2026-09-30) 코드를 기준으로 작성했다.

## 1. 성공 쿨타임 1분

| 항목 | 현재 (`v1.0.2b`) | 1.0.2c |
|---|---|---|
| `YOYACK_SUCCESS_COOLDOWN_SECONDS` 기본값 | 300초(5분) | **60초(1분)** |
| 운영 LXC 설정 | 설정 파일에서 덮어쓰지 않음(기본값 사용, 2026-09-30 확인) | 그대로 두면 60초 적용 |
| 쿨타임 안내 | `아직은 때가 아니오. 04분 59초 뒤에 오시오.` | 형식 유지, 최대 `01분 00초` |

- 적용 대상은 기존과 같다: 같은 채널에서 **요약 게시 전체 성공** 뒤에만 걸린다. 실패·빈 대화·진행 중 안내·`사용량`·`상태`·`채널`·`도움`은 쿨타임을 쓰지 않는다.
- 업그레이드 직전에 5분 쿨타임으로 기록된 채널도 새 코드에서는 남은 시간이 최대 60초로 줄어든다(기존 `remaining`이 설정 길이로 상한을 둔다). DB schema와 기존 기록은 바꾸지 않는다.
- 운영자가 환경 변수로 다른 값을 주면 그 값을 따른다. `.env.example`과 README의 “5분” 설명을 “1분”으로 바꾼다.

## 2. 요약 말투: 천박하지만 말끝은 하오체

요약 본문(기본·`자세히`·`짧게` 모두)의 **서술자 말투**를 바꾼다. 봇의 안내 문구(시작·진행 중·쿨타임·오류·사용량·상태·채널·도움)는 지금 하오체 그대로 둔다.

### 목표 말투

- 문장 몸통은 거칠고 막 나가는 **천박한 구어체**: 과장, 비꼼, 속된 표현, 반말 어휘(`들이밀다`, `헛짚다`, `박아버리다`, `떠넘기다`, `개판`, `대충 뭉개다` 등).
- 문장 끝은 **반드시 하오체**로 또렷하게 맺는다: `~했소`, `~하오`, `~이오`, `~않았소`, 필요하면 `~했단 말이오!`, `~이란 말이오`로 강조. 반말 어미(`~했다`, `~함`, `~임`, `~ㅋㅋ`)로 끝내지 않는다.
- 예시(합성 대화, 표시 예시일 뿐 고정 문구 아님):

```text
가람 이 양반이 금요일 오후 2시 배포를 떡하니 들이밀었다가, 날짜를 헛짚은 게 들통나서 목요일 오후 2시로 슬쩍 갈아탔소!
나래는 주말에 터지면 누가 뒷감당하냐며 금요일은 절대 안 된다고 못을 박았소.
다온도 거들어서 결국 목요일 오후 2시로 박아버렸단 말이오.
라온이 롤백은 누가 하냐고 찔렀는데, 아직 아무도 안 떠맡았소!
```

### 넘지 않는 선 (말투보다 우선)

1. **사실·화자 귀속 규칙이 먼저다.** 말투 때문에 원문에 없는 사실·동기·결론을 만들거나, 제안을 결정으로, 미정을 확정으로 바꾸지 않는다. 기존 신뢰 경계·화자 표시 이름 규칙을 그대로 지킨다.
2. **거친 말은 서술자의 것이다.** 화자가 하지 않은 욕설·비속어를 그 사람이 한 말처럼 인용하거나 따옴표로 붙이지 않는다(예시의 `개소리라고 했소`처럼 발언을 지어내는 것은 금지).
3. **사람을 겨냥한 모욕 금지.** 참여자·제3자의 외모·지능·성별·출신·장애·종교·성적 지향 등을 비하하거나 혐오 표현·성적 표현을 쓰지 않는다. 거친 표현은 상황·행동·결과(`개판이 났소`, `대충 뭉갰소`)에만 쓴다.
4. **강한 욕설 금지.** 성적·패륜·장애 비하 계열의 강한 욕설과 그 변형·초성은 쓰지 않는다(구체 목록은 P2에서 코드의 차단 목록으로 둔다). 허용 수위는 아래 “결정 필요 항목”을 따른다.
5. 멘션 비활성·출력 분할·내부 화자 표식(`P1`) 금지·한국어 출력 등 기존 출력 검사를 유지한다.

### 구현 방식

- 신뢰 프롬프트의 말투 지시(`한국어 하오체로 자연스럽고 간결하게 쓰시오.`)를 위 목표·금지선으로 바꾸고 프롬프트 버전을 올린다(`1.0.2c-p2-v1`). `자세히`·`짧게` 밀도 지시는 그대로 붙인다.
- 자동 출력 검사는 기존 항목(비한국어·원문 복사·도구 보고·내부 화자 표식)을 유지하고, **강한 욕설 목록**이 나오면 한 번 다시 생성한 뒤 반복되면 안전하게 실패한다(1.0.0d 화자 표식 재시도와 같은 방식). 하오체 어미 비율은 사람 검토로 평가하고 자동 거부하지 않는다(재시도가 계정 한도를 더 쓰므로).

## 결정 필요 항목 (따로 말씀이 없으면 기본값으로 진행)

| 항목 | 기본값(권장) | 다른 선택 |
|---|---|---|
| 비속어 수위 | **가벼운 속된 표현만**(`개판`, `헛짚다`, `뭉개다`, `들이밀다` 등), 강한 욕설 금지 | 비속어 없이 거친 구어체만 / `존나`·`졸라` 수준까지 허용 |
| 적용 범위 | **요약 본문만**(기본·자세히·짧게) | 봇의 모든 안내 문구도 같은 말투로 |
| 실제 모델 평가 | 봇 계정 주간 한도(현재 6%)를 고려해 **모드별 합성 3건씩 총 9건** | 한도 초기화 뒤 20건 이상 |
