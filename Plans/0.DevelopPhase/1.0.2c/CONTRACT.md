# 1.0.2c 쿨타임·요약 말투 계약

이 문서는 구현 목표다. 현재 제품 동작이나 시험 PASS를 뜻하지 않는다. 출시된 `v1.0.2b`(2026-09-30) 코드를 기준으로 작성했다.

## 1. 성공 쿨타임 1분

| 항목 | 현재 (`v1.0.2b`) | 1.0.2c |
|---|---|---|
| `YOYACK_SUCCESS_COOLDOWN_SECONDS` 기본값 | 300초(5분) | **60초(1분)** |
| 운영 LXC 설정 | 설정 파일에서 덮어쓰지 않음(기본값 사용, 2026-09-30 확인) | 그대로 두면 60초 적용 |
| 쿨타임 안내 | `아직은 때가 아니오. 04분 59초 뒤에 오시오.` | 형식 유지, 최대 `01분 00초` |

- 적용 대상은 기존과 같다: 같은 채널에서 **요약 게시 전체 성공** 뒤에만 걸린다. 실패·빈 대화·진행 중 안내·`사용량`·`상태`·`채널`·`도움`은 쿨타임을 쓰지 않는다.
- 업그레이드 직전에 5분 쿨타임으로 기록된 채널도 새 코드에서는 남은 시간이 최대 60초로 줄어든다(기존 `remaining`이 설정 길이로 상한을 둔다). DB schema와 기존 기록은 바꾸지 않는다.
- 운영자가 환경 변수로 다른 값을 주면 그 값을 따른다. `.env.example`과 README의 “5분” 설명을 “1분”으로 바꾼다.

## 2. 요약 말투: 천박하지만 말끝은 하오체

요약 본문(기본·`자세히`·`짧게` 모두)의 **서술자 말투**를 바꾼다. 봇의 안내 문구(시작·진행 중·쿨타임·오류·사용량·상태·채널·도움)는 지금 하오체 그대로 둔다.

### 목표 말투

- 문장 몸통은 거칠고 막 나가는 **천박한 구어체**: 과장, 비꼼, 반말 어휘(`들이밀다`, `헛짚다`, `박아버리다`, `떠넘기다`)와 **비속어·외설적인 속어**(`존나`, `시발`, `개판`, `좆되다`, `좆도 없다` 등)를 쓸 수 있다(사용자 결정 2026-09-30).
- 문장 끝은 **반드시 하오체**로 또렷하게 맺는다: `~했소`, `~하오`, `~이오`, `~않았소`, 필요하면 `~했단 말이오!`, `~이란 말이오`로 강조. 반말 어미(`~했다`, `~함`, `~임`, `~ㅋㅋ`)로 끝내지 않는다.
- 예시(합성 대화, 표시 예시일 뿐 고정 문구 아님):

```text
가람 이 양반이 금요일 오후 2시 배포를 존나 당당하게 들이밀었다가, 날짜를 헛짚은 게 들통나서 목요일 오후 2시로 슬쩍 갈아탔소!
시발, 나래는 주말에 터지면 누가 뒷감당하냐며 금요일은 절대 안 된다고 못을 박았소.
다온도 거들어서 결국 목요일 오후 2시로 박아버렸단 말이오.
라온이 롤백은 누가 하냐고 찔렀는데, 그건 아직 좆도 정해진 게 없소!
```

### 넘지 않는 선 (말투보다 우선)

1. **사실·화자 귀속 규칙이 먼저다.** 말투 때문에 원문에 없는 사실·동기·결론을 만들거나, 제안을 결정으로, 미정을 확정으로 바꾸지 않는다. 기존 신뢰 경계·화자 표시 이름 규칙을 그대로 지킨다.
2. **거친 말은 서술자의 것이다.** 비속어는 서술자의 감탄·추임새·상황 묘사로만 쓴다. 화자가 하지 않은 욕설을 그 사람이 한 말처럼 인용하거나 따옴표로 붙이지 않는다(`나래가 개소리라고 했소`처럼 발언을 지어내는 것은 금지). 원문에 실제로 있던 욕설을 인용하는 것은 허용한다.
3. **실제 사람을 성적으로 다루지 않는다.** `좆`·`씹` 계열 같은 외설적인 속어는 감탄·강조로 쓸 수 있지만, 참여자·제3자를 성적으로 묘사하거나 성적 행위와 엮지 않고, 원문에 없는 성적 내용을 지어내지 않는다.
4. **혐오 비하어와 인신공격 금지.** 성별·출신·인종·장애·종교·성적 지향 등 집단을 겨냥한 비하어(장애 비하에서 온 욕 포함)와 참여자의 외모·지능을 깎아내리는 인신공격은 쓰지 않는다. 구체 목록은 P2에서 코드의 차단 목록으로 둔다.
5. 멘션 비활성·출력 분할·내부 화자 표식(`P1`) 금지·한국어 출력 등 기존 출력 검사를 유지한다.

### 구현 방식

- 신뢰 프롬프트의 말투 지시(`한국어 하오체로 자연스럽고 간결하게 쓰시오.`)를 위 목표·금지선으로 바꾸고 프롬프트 버전을 올린다(`1.0.2c-p2-v1` → P3 평가 뒤 강화한 `1.0.2c-p2-v2`). `자세히`·`짧게` 밀도 지시는 그대로 붙인다.
- 자동 출력 검사는 기존 항목(비한국어·원문 복사·도구 보고·내부 화자 표식)을 유지하고, **혐오 비하어 차단 목록**이 서술자 문장에 나오면(원문 인용 제외) 한 번 다시 생성한 뒤 반복되면 안전하게 실패한다(1.0.0d 화자 표식 재시도와 같은 방식). `존나`·`시발`·`좆` 같은 일반 비속어는 차단하지 않는다. 하오체 어미 비율은 사람 검토로 평가하고 자동 거부하지 않는다(재시도가 계정 한도를 더 쓰므로). 실제 사람을 성적으로 다루는지는 키워드로 가려낼 수 없으므로 P3 사람 검토로 확인한다.

## 사용자 결정 (2026-09-30)

| 항목 | 결정 | 검토했던 다른 선택 |
|---|---|---|
| 비속어 수위 | **`존나`·`시발` 등 비속어와 외설적인 속어 허용**. 실제 사람을 성적으로 다루기·혐오 비하어·인신공격만 금지 | 가벼운 속된 표현만 / 비속어 없이 거친 말투만 |
| 적용 범위 | **요약 본문만**(기본·자세히·짧게). 봇 안내 문구는 유지 | 봇의 모든 안내 문구도 같은 말투로 |
| 실제 모델 평가 | **모드별 합성 3건씩 총 9건** | 한도 초기화 뒤 20건 이상 |

고정 모델이 비속어를 약하게 순화할 수 있다. P3에서 실제 출력 수위를 확인하고, 사용자가 원하는 수위에 못 미치면 프롬프트를 조정하되 위 금지선은 유지한다.

## P3 평가 뒤 결정 (2026-09-30)

고정 모델이 서술자 비속어를 강하게 순화해 v1 프롬프트는 9건 모두 점잖은 하오체로 나왔다. 강화 프롬프트는 거친 소제목과 가끔의 속된 표현까지만 나왔다. 사용자는 후처리·모델 변경 대신 **현재 수준으로 수용**을 선택했다. 효과가 있던 강화 프롬프트(프롬프트 끝의 “말투(반드시 적용)” 단락과 거친 소제목, 말투 예시 없음)를 `1.0.2c-p2-v2`로 반영하고, 바뀐 프롬프트의 사실성을 모드별 1건씩 다시 확인한다.
