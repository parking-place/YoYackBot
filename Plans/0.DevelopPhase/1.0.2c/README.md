# 1.0.2c — 쿨타임 1분·천박한 하오체 요약

- 상태: **IN_PROGRESS** (P1 완료, P2 진행 중)
- 단계 수: **4단계**
- 선행 버전: 출시된 [1.0.2b](../1.0.2b/README.md)(`v1.0.2b`, 2026-09-30)

## 목표

1. 요약 성공 뒤 같은 채널의 쿨타임을 **5분 → 1분**으로 줄인다.
2. 요약 본문의 말투를 **천박하지만 말끝은 하오체로 또렷하게 맺는** 말투로 바꾼다. `존나`·`시발` 같은 비속어와 외설적인 속어를 쓸 수 있다. 사실·화자 귀속, 실제 사람을 성적으로 다루지 않기, 혐오 비하어·인신공격 금지는 말투보다 우선한다.

세부 규칙·예시·금지선·사용자 결정(2026-09-30)은 [계약](CONTRACT.md)에 있다.

## 검증 방침

- 봇 계정 주간 한도가 낮으므로(2026-09-30 기준 6%) 실제 모델 평가는 P3에서만, 계약의 건수 안에서 한다. 평가 전후 `!!요약좀 사용량` 값으로 남은 한도를 기록하고, 경고 경계에서 더 떨어지면 평가를 멈추고 사용자에게 알린다.
