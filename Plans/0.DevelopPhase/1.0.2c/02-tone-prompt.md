# 1.0.2c-P2 — 말투 프롬프트·금지선 검사

- 상태: **PUSH_PENDING** · 검사: `T102c-P2-A/B` · 환경: 개발 LXC, 합성 대역(모델 호출 없음)

## 선행 조건·작업

[P1](01-cooldown.md)의 원격 완료 뒤 [계약](CONTRACT.md) 2절에 따라 신뢰 프롬프트의 말투 지시를 바꾸고 프롬프트 버전을 `1.0.2c-p2-v1`로 올린다. 기본·`자세히`·`짧게`와 화자 표식 재시도 프롬프트가 모두 같은 말투·금지선을 포함한다. 사실·화자 귀속·신뢰 경계 규칙은 말투 지시보다 **앞에** 두고 우선한다고 적는다.

출력 검사에 **혐오 비하어 차단 목록**(변형·초성 포함) 탐지를 추가한다. 원문 인용 줄은 제외하고 서술자 문장에서 탐지되면 같은 입력으로 한 번 다시 생성하고, 반복되면 `OUTPUT_INVALID`로 안전하게 실패한다. `존나`·`시발`·`좆` 같은 일반 비속어는 차단하지 않는다. 하오체 어미 비율은 자동 거부하지 않는다. 봇 안내 문구는 바꾸지 않는다.

## 검증·완료 기준

- `T102c-P2-A`: 세 모드와 재시도 프롬프트가 새 말투·금지선·우선순위 문장을 포함하고, 원문 대화 문자열이 프롬프트에 섞이지 않으며, 모드별 밀도 지시가 유지된다. 안내 문구는 이전과 글자 단위로 같다.
- `T102c-P2-B`: 합성 출력으로 혐오 비하어(변형·초성·공백 끼움 포함) 1회 → 재시도 성공, 2회 → 안전 실패, `존나`·`시발`·`좆` 같은 허용 비속어와 원문 인용 속 단어는 오탐하지 않는다. 재시도·실패 뒤 쿨타임·진행 상태 규칙이 유지된다.

같은 SHA의 결과를 기록하고 구현 C → 증거 E → (E CI 성공 확인) → 종료 D를 각각 commit·GitHub push·원격 확인한다. [공통 Git 규칙](../GIT_WORKFLOW.md)을 따른다.
