# 1.0.2b `!!요약좀 채널` 명령 계약

이 문서는 구현 목표다. 현재 제품 동작이나 시험 PASS를 뜻하지 않는다. 출시된 `v1.0.2`(2026-09-29) 코드를 기준으로 작성했다.

## 응답

`!!요약좀 채널`은 명령을 친 **Discord 서버(Guild)** 에서 봇이 주시 중인 텍스트 채널 목록을 한 번 보낸다. 사용자가 정한 문구는 다음과 같다.

```text
지금 본인이 보고 있는 채널을 알려주겠소
 - 잡담
 - 개발
 - 기획
이상이오.
```

- 첫 줄 `지금 본인이 보고 있는 채널을 알려주겠소`와 마지막 줄 `이상이오.`는 고정 문구다. 채널 한 줄은 ` - {채널 이름}`(앞 공백 1칸, 하이픈, 공백)이다.
- 채널 이름은 Discord 캐시의 현재 이름을 쓰고, `#`이나 채널 멘션(`<#id>`)은 붙이지 않는다. 이름 안의 Markdown 특수 문자는 이스케이프한다.
- 순서는 Discord 채널 목록 순서(카테고리 위치 → 채널 위치)다. 같은 위치면 채널 ID 순서다.
- 주시 채널이 하나도 없으면 목록 대신 `지금 보고 있는 채널이 없소. 관리자가 \`/채널 설정\`으로 정하시오.`를 보낸다.

## 대상과 경계

| 항목 | 규칙 |
|---|---|
| 인식 | 옵션이 **정확히 한 단어 `채널`** 일 때만. `사용량`·`상태`처럼 공손 어미·범위·모드와 함께 쓰면 요약 옵션으로 해석되어 사용법 안내가 나간다. `도움`이 함께 있으면 도움말이 우선한다. |
| 응답 위치 | **주시 채널에서만**(`사용량`·`상태`와 같은 주시 게이트). 미주시 채널에서는 기존 `이 채널은 아직 살피고 있지 않소. \`/채널 설정\`으로 먼저 정하시오.`를 보내고 목록을 보여주지 않는다. DM·스레드는 기존 입력 경계대로 무시한다. |
| 범위 | 현재 서버의 주시 설정만. 다른 서버의 채널·수·ID를 노출하지 않는다. |
| 보이는 채널 | 명령을 친 사람이 **볼 수 있는(`view_channel`) 채널만** 적는다. 비공개 채널 이름이 권한 없는 사람에게 노출되지 않게 하려는 것이다. 볼 수 없는 주시 채널이 있어도 개수·존재를 암시하지 않는다. |
| 사라진 채널 | 주시 설정에는 있지만 캐시에 없거나 텍스트 채널이 아니면 적지 않는다. |
| 부작용 | 메시지 수집·모델·요약 대기열·진행 중 상태·성공 쿨타임을 쓰거나 바꾸지 않는다. 요약이 진행 중이어도 바로 응답한다. |
| 실패 | 주시 설정을 읽지 못하면 기존 `채널 설정을 확인하지 못했소. 잠시 후 다시 시도하시오.`를 보내고 목록을 추측하지 않는다. |
| 전송 | 멘션 비활성화. 목록이 Discord 한 메시지 한도(설정 1,900자)를 넘으면 줄 단위로 나눠 순서대로 보내고, 첫 줄은 첫 메시지에, `이상이오.`는 마지막 메시지에 둔다. |
| 로그 | `channel_list_request count=<보낸 채널 수>`만 남기고 채널 이름·ID는 남기지 않는다. |

## 도움말

`!!요약좀 도움`에 한 줄을 추가하고, 주시 채널 전용 안내 줄에 `채널`을 넣는다. 기존 설명과 2,000자 미만 제한은 유지한다.

```text
`!!요약좀 채널` — 이 서버에서 봇이 살피고 있는 채널 가운데 그대에게 보이는 채널을 알려주오.
사용량·상태·채널은 주시 채널에서만 답하며, 요약이 아니므로 대기 시간을 쓰지 않소.
```

[주시 채널 안내](../../../docs/channel-settings.md)에도 같은 설명을 추가한다.

## 사용자 결정 (2026-09-30)

| 항목 | 결정 | 검토했던 다른 선택 |
|---|---|---|
| 응답 위치 | **주시 채널에서만**(`사용량`·`상태`와 같게) | 서버 안 모든 텍스트 채널 |
| 보이는 채널 필터 | **명령한 사람이 볼 수 있는 채널만** | 필터 없이 전부(비공개 채널 이름 노출 가능) |
| 채널 상태 표시 | **이름만** | 초기 수집·누락 재확인 중인 채널에 `(준비 중)` 덧붙임 |
