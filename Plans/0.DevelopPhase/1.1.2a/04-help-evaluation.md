## 선행 조건·작업

[P3](03-output-checks.md)의 원격 완료 뒤 [계약](CONTRACT.md) 1절 문안으로 `!!요약좀 도움`을 바꾼다(최대 기간은 설정값, 2일보다 짧게 설정되면 `2일` 예를 뺌). 빈 주시 목록 안내와 `docs/channel-settings.md`(누구나 `/채널 설정` 사용, 서버 설정 → 연동에서 역할별 제한 방법, 화면 제한 시간)를 고친다. 합성 사례로 실제 `gpt-6-luna`/low 요약 **6건**(짧게 4 + 길게 2)을 비게시로 만든다.

## 검증·완료 기준

- `T112a-P4-A`(도움말·문서): 도움말이 계약 문안과 글자 단위로 같고(최대 기간 30·7·1일 설정 각각), 2,000자 미만이며, 도움말·빈 주시 목록 안내에 “관리자” 문구가 남지 않는다. 채널 설정 문서·README가 새 권한을 설명한다.
- `T112a-P4-B`(실제 모델): 6건 모두 사실·화자 오류 0, `###` 주제 제목, 주제마다 인용 비평 `> ↳ _…_` 한 줄, 본문 화자 이름 밑줄(`name_underline` 기록), 깨진 마크다운 0, 취소선은 실제 정정·철회에만, 1.1.2 형식(짧게 1~2줄·이모지·평가 줄) 유지. 결과 예를 사용자에게 보여 확정한다.
