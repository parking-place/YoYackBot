# 1.1.2a 슬래시 명령어 권한 계약

이 문서는 구현 목표다. 현재 제품 동작이나 시험 PASS를 뜻하지 않는다. `v1.1.2`(출시 예정, 개발 LXC 배포 후 사용자 확인 대기, 2026-10-01) 코드를 기준으로 작성했다. 1.1.2a 구현은 `v1.1.2` 출시·`main` 통합 뒤에 시작한다.

## 문제 (사용자 요청, 2026-10-01)

`/채널 설정`(주시 채널 관리)을 서버 관리자나 **채널 관리** 권한이 있는 사람만 쓸 수 있다. 서버 관리자가 Discord의 **서버 설정 → 연동(Integrations) → 요약봇**에서 특정 역할·사람·채널에 이 명령어를 허용해도, 봇이 다시 자체 권한 검사를 해서 막는다.

- 등록: `@app_commands.default_permissions(manage_channels=True)` — Discord 기본값으로 관리자·채널 관리 권한자에게만 명령어가 보인다. 서버 관리자는 연동 화면에서 이 기본값을 역할·사람·채널별로 바꿀 수 있다(Discord가 서버 측에서 강제).
- 실행: `channel_config.can_manage()`가 `administrator` 또는 `manage_channels`가 아니면 `DENIED`로 거절한다. 명령어 실행과 설정 화면의 모든 버튼·선택(`interaction_check`)에서 같은 검사를 한다.
- 결과: Discord가 허용한 사용자도 봇이 거절한다. 안내 문구(`도움`, 빈 주시 목록 안내, 동시 수정 안내)도 “관리자”만 언급한다.

## 목표 (1.1.2a)

**Discord의 애플리케이션 명령어 권한 판단을 그대로 따른다.** 명령어를 실행할 수 있게 허용된 사용자라면(기본값: 관리자·채널 관리 권한자, 그 밖에 서버 관리자가 연동 설정에서 허용한 역할·사람) 누구나 `/채널 설정`을 열고 저장할 수 있다.

| 경우 | 1.1.2 | 1.1.2a |
|---|---|---|
| 서버 관리자 / 채널 관리 권한 | 사용 가능 | 사용 가능(기본값 그대로) |
| 연동 설정에서 허용한 역할·사람 | 명령어는 보이지만 봇이 거절 | **사용 가능** |
| 연동 설정에서 막은 역할·사람·채널 | Discord가 막음 | Discord가 막음(그대로) |
| 아무 설정도 안 한 일반 사용자 | 명령어가 안 보임 | 명령어가 안 보임(기본값 그대로) |
| DM·서버 밖 | 거절 | 거절(그대로) |

## 구현 방식

- 명령어 등록의 기본 권한(`default_permissions(manage_channels=True)`)과 `guild_only`는 **유지**한다. 그래야 설치 직후에는 지금처럼 관리자만 보이고, 서버 관리자가 원할 때 연동 화면에서 넓힐 수 있다.
- 명령어 실행 시 봇의 `can_manage` 검사를 없앤다. Discord가 명령어 권한(기본값·역할·사람·채널 재정의, `애플리케이션 명령어 사용` 채널 권한)을 서버 측에서 확인한 뒤에만 상호작용을 보내므로, 봇은 서버 안의 명령어 상호작용인지(`guild`가 있는지)만 확인한다.
- 설정 화면(버튼·채널 선택)은 **화면을 연 본인만** 조작할 수 있게 유지한다(`owner_id` 확인). 화면 제한 시간(120초)도 그대로다. 화면을 연 뒤 권한이 회수되면 그 화면이 끝날 때까지는 조작할 수 있다(최대 120초, 문서에 적음).
- 저장 시 봇 접근 가능 채널·텍스트 채널 검사, 동시 수정 감지(버전 비교)는 그대로다. 동시 수정 안내는 “다른 관리자가” → “다른 사람이”로 바꾼다.
- 지표 로그에 `watched_channels_saved`(서버 ID·채널 수·변경 방식만, 사용자 ID·채널 이름 없음)를 남겨 누가 아닌 **언제·몇 개**로 바뀌었는지 추적한다(사용자 결정 기본안).
- `!!요약좀` 텍스트 명령과 권한은 바뀌지 않는다.

## 안내 문구

- `도움` 마지막 줄: “주시할 채널은 관리자가 `/채널 설정`에서 정하시오.” → “주시할 채널은 `/채널 설정`에서 정하시오. 기본은 관리자·채널 관리 권한자만 쓰며, 서버 설정 → 연동에서 다른 역할에도 허용할 수 있소.”
- 빈 주시 목록 안내(`!!요약좀 채널`): “관리자가 `/채널 설정`으로 정하시오.” → “`/채널 설정`으로 정하시오.”
- `docs/channel-settings.md`: 기본 권한과 연동 화면에서 역할·사람·채널별로 허용·차단하는 방법, 화면 제한 시간 동안의 권한 회수 동작을 적는다.
