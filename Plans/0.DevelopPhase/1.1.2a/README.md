# 1.1.2a — 짧은 도움말·마크다운 요약·닉네임 밑줄·슬래시 명령어 권한

- 상태: **IN_PROGRESS** (P1~P2 완료, P3 진행 중)
- 단계 수: **5단계**
- 선행 버전: 출시된 [1.1.2](../1.1.2/README.md)(`v1.1.2`, 2026-10-01)

## 목표

1. `!!요약좀 도움`을 사용자가 준 더 짧은 문안으로 바꾼다(최대 기간은 설정값).
2. 요약문에 마크다운을 적극적으로 쓴다: `###` 주제 제목, 굵게·취소선, 화자 닉네임 밑줄(`__이름__`, 모델에게 맡김), 주제 한줄 비평은 인용문 `> ↳ _비평_ 이모지`.
3. `/채널 설정`을 비롯한 모든 슬래시 명령어(이후 추가분 포함)를 `애플리케이션 명령어 사용` 권한이 있는 누구나 처음부터 쓰고 설정할 수 있게 한다. 변경 기록은 시각과 채널 수만 남긴다.

문안·마크다운 표·비평 줄 형식·권한 표·사용자 결정은 [계약](CONTRACT.md)에 있다.

## 검증 방침

- 권한은 합성 상호작용 시험과 명령어 트리 전수 검사로, Discord가 강제하는 부분은 실제 시험 서버에서 사용자가 확인한다.
- 비평 줄이 인용문(`>`)으로 바뀌므로, 지금까지 인용 줄을 건너뛰던 비하어·미결 조롱 검사가 `> ↳` 줄을 다시 보는지 합성 시험으로 확인한다.
- 실제 모델 6건(짧게 4 + 길게 2)으로 마크다운·밑줄·인용 비평을 확인한다. 사실·화자 오류 0, 1.1.2 형식(주제별 1~2줄, 주제마다 비평, 이모지) 유지.
- 사용자 보고·실제 대화·실제 닉네임은 공개 문서에 옮기지 않고 합성 이름만 쓴다. 배포 전 진행 중 요약이 없음을 확인한다.
- 실제 시험 Discord 확인은 P5 배포 뒤 사용자가 직접 한다. 확인하지 못하면 `NOT_RUN`.
