# 1.1.2a — 짧은 도움말·닉네임 밑줄·슬래시 명령어 권한

- 상태: **PLANNED** (계획 문서만 작성; 기능 구현·배포 전)
- 단계 수: **4단계**
- 선행 버전: 출시된 [1.1.2](../1.1.2/README.md)(`v1.1.2`, 2026-10-01)

## 목표

1. `!!요약좀 도움`을 사용자가 준 짧은 문안으로 바꾼다.
2. 요약 속 화자 닉네임을 밑줄(`__이름__`)로 표시한다. 코드가 화자 표시 이름 목록으로 결정적으로 붙인다.
3. `/채널 설정`을 비롯한 모든 슬래시 명령어(이후 추가분 포함)를 `애플리케이션 명령어 사용` 권한이 있는 누구나 처음부터 쓰고 설정할 수 있게 한다. 변경 기록은 시각과 채널 수만 남긴다.

문안·밑줄 규칙·권한 표·사용자 결정은 [계약](CONTRACT.md)에 있다.

## 검증 방침

- 권한은 합성 상호작용 시험과 명령어 트리 전수 검사로, Discord가 강제하는 부분은 실제 시험 서버에서 사용자가 확인한다.
- 밑줄은 합성 출력(이름 겹침·한 글자 이름·인용·코드·이모지·추가 요청)으로 검사하고, 실제 모델 6건으로 확인한다.
- 사용자 보고·실제 대화·실제 닉네임은 공개 문서에 옮기지 않고 합성 이름만 쓴다. 배포 전 진행 중 요약이 없음을 확인한다.
- 실제 시험 Discord 확인은 P4 배포 뒤 사용자가 직접 한다. 확인하지 못하면 `NOT_RUN`.
