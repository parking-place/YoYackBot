# 1.1.2a — 슬래시 명령어를 Discord 권한 설정대로

- 상태: **PLANNED** (계획 문서만 작성; 기능 구현·배포 전)
- 단계 수: **3단계**
- 선행 버전: [1.1.2](../1.1.2/README.md)(`v1.1.2` 출시 후 시작)

## 목표

1. `/채널 설정`을 서버 관리자·채널 관리 권한자뿐 아니라, 서버 관리자가 **서버 설정 → 연동**에서 명령어 사용을 허용한 역할·사람도 쓸 수 있게 한다. 봇의 자체 권한 검사 대신 Discord의 애플리케이션 명령어 권한 판단을 따른다.
2. 설치 직후 기본값(관리자·채널 관리 권한자에게만 보임)과 설정 화면의 본인 전용 조작·제한 시간·저장 검증은 유지한다.
3. 도움말·안내 문구·채널 설정 문서를 고친다.

원인·경우별 동작·구현 방식·안내 문구·사용자 결정은 [계약](CONTRACT.md)에 있다.

## 검증 방침

- 합성 상호작용 시험으로 경우별 동작(관리자·채널 관리·연동 허용 사용자·화면을 열지 않은 다른 사람·DM)을 확인한다. Discord가 명령어 권한을 강제하는 부분은 실제 시험 서버에서 사용자가 확인한다.
- 실제 모델 호출은 없다. 배포 전 진행 중 요약이 없음을 확인한다.
- 실제 시험 Discord 확인은 P3 배포 뒤 사용자가 직접 한다: 서버 설정 → 연동에서 관리자가 아닌 역할(또는 사람)에 `/채널 설정`을 허용하고, 그 사람이 설정을 열어 저장할 수 있는지, 허용하지 않은 사람에게는 명령어가 보이지 않는지. 확인하지 못하면 `NOT_RUN`.
