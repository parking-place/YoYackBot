# 1.1.2a-P2 — 도움말·안내 문구·문서

- 상태: **PLANNED** · 검사: `T112a-P2-A/B` · 환경: 개발 LXC, 합성

## 선행 조건·작업

[P1](01-command-permission.md)의 원격 완료 뒤 [계약](CONTRACT.md)의 안내 문구대로 `도움` 마지막 줄과 빈 주시 목록 안내를 고친다(도움말 2,000자 미만). `docs/channel-settings.md`에 기본 권한(관리자·채널 관리), **서버 설정 → 연동 → 요약봇 → `/채널 설정`**에서 역할·사람·채널별로 허용·차단하는 방법, 화면 제한 시간(120초) 동안 권한이 회수돼도 열린 화면은 끝날 때까지 쓸 수 있다는 점을 적는다. README의 관련 설명도 맞춘다.

## 검증·완료 기준

- `T112a-P2-A`: 도움말·빈 목록 안내에 새 문구가 있고 “관리자가 `/채널 설정`” 문구가 코드·문서에 남지 않는다. 도움말 2,000자 미만.
- `T112a-P2-B`: 채널 설정 문서의 링크·절차가 저장소 검증을 통과하고, 공개 이력 비밀 검사·전체 회귀가 통과한다.

같은 SHA의 결과를 [증거 양식](../EVIDENCE_TEMPLATE.md)에 남기고 구현 C → 증거 E → (E CI 성공 확인) → 종료 D를 각각 commit·GitHub push·원격 확인한다. [공통 Git 규칙](../GIT_WORKFLOW.md)을 따른다.
