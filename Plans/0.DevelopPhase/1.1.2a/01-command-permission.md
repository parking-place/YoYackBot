# 1.1.2a-P1 — 슬래시 명령어 권한

- 상태: **PUSH_PENDING** · 검사: `T112a-P1-A/B` · 환경: 개발 LXC, 합성 상호작용(Discord 연결 없음)

## 선행 조건·작업

`v1.1.2` 출시와 `main` 통합을 확인한다. [계약](CONTRACT.md) 3절대로 슬래시 명령어 공통 등록 도우미(서버 전용 + 기본 권한 `use_application_commands`)를 만들고 `/채널` 그룹·`설정` 명령어에 적용한다. 실행 시 `can_manage` 검사를 없애 서버 안 상호작용인지만 확인하고, 설정 화면은 같은 서버·화면을 연 본인만 조작하게 둔다. 동시 수정 안내를 “다른 사람이”로 바꾸고, 저장 시 `watched_channels_saved` 지표(시각·채널 수만)를 남긴다. 쓰이지 않게 된 `can_manage`는 지운다.

## 검증·완료 기준

- `T112a-P1-A`: 관리자·채널 관리 권한자·**권한 플래그가 없는 일반 사용자** 모두 설정 화면을 열고 추가·제거·전체 해제·저장할 수 있다. DM은 거절된다. 명령어 트리의 **모든** 명령어·그룹이 서버 전용이고 기본 권한이 `use_application_commands`뿐이다(새 명령어를 도우미 없이 등록하면 실패하는 전수 시험).
- `T112a-P1-B`: 화면을 연 사람이 아닌 사용자·다른 서버의 조작은 거절된다. 저장 검증(봇 접근·텍스트 채널), 동시 수정 감지, 제한 시간 만료가 그대로다. 지표에 시각·채널 수 외 사용자 ID·채널 이름이 없다. 전체 회귀 통과.

같은 SHA의 결과를 [증거 양식](../EVIDENCE_TEMPLATE.md)에 남기고 구현 C → 증거 E → (E CI 성공 확인) → 종료 D를 각각 commit·GitHub push·원격 확인한다. [공통 Git 규칙](../GIT_WORKFLOW.md)을 따른다.
