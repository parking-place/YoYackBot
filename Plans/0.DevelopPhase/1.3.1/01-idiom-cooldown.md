# 1.3.1-P1 — `!!말하자면` 바로 답·따로 쿨타임

- 상태: **PLANNED** · 검사: `T131-P1-A/B` · 환경: 개발 LXC, 합성 대역(모델 호출 없음)

## 작업

[계약](CONTRACT.md) 1절대로 `!!말하자면`의 시작 안내를 없애고, 성공 쿨타임을 `idiom_cooldowns` 선택 테이블로 따로 기록한다. `ChannelStates`는 채널 작업 슬롯을 계속 하나로 두고 쿨타임만 종류별로 센다. 주시 해제·서버 탈퇴·DB 열 때 고아 정리를 요약 쿨타임과 같게 한다.

## 검증·완료 기준

- `T131-P1-A`: 성공 시 채널에 결과 한 줄만 올라가고 시작 안내가 없다. 빈 대화·실패·대기·준비 중·사용법 안내는 1.3.0 문구 그대로다. 실패하면 쿨타임이 생기지 않는다.
- `T131-P1-B`: `!!말하자면` 성공 뒤 `!!요약좀`이 바로 실행되고 그 반대도 같다. 같은 종류는 설정한 시간 동안 막힌다. 재시작 뒤에도 각 쿨타임이 유지된다. 작업 중 BUSY는 공유된다. 주시 해제·서버 탈퇴·구버전이 해제한 채널의 `idiom_cooldowns` 행이 정리되고 백업에 들어가지 않는다. 전체 회귀 통과.
