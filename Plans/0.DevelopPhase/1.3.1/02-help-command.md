# 1.3.1-P2 — `/도움말`

- 상태: **PUSH_PENDING** · 검사: `T131-P2-A/B` **PASS** ([증거](../evidence/1.3.1-P2.md)) · 환경: 개발 LXC, 합성 대역

## 작업

[계약](CONTRACT.md) 2절대로 누구나 부를 수 있는 서버 전용 슬래시 명령 `/도움말`을 만들어 기존 도움말을 부른 사람에게만 보낸다. `!!요약좀 도움`은 한 줄 안내로 바꾸고, 다른 안내 문구가 가리키는 사용법 위치를 `/도움말`로 고친다.

## 검증·완료 기준

- `T131-P2-A`: `/도움말`이 등록되고 권한 판정(관리 역할) 없이 ephemeral로 1.3.0과 같은 본문(설정의 최대 일수 반영)을 보낸다. 기본 권한 제한이 없어 일반 사용자에게 보인다. `/속도`가 본문에 없다.
- `T131-P2-B`: `!!요약좀 도움`·`도움말`·반복 트리거가 모두 한 줄 안내만 채널에 보내고 도움말 본문은 보내지 않는다. 주시하지 않는 채널에서도 같다. 사용법 안내 문구들이 `/도움말`을 가리킨다. 로그에 내용이 없다. 전체 회귀 통과.
