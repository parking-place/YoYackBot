## 선행 조건

[0.6.0-P5](../0.6.0/05-output-acceptance.md)가 검증과 GitHub push 확인까지 끝나 DONE이어야 한다.

## 수행 작업

1. `(guild_id, channel_id)`별 IDLE/SUMMARIZING/COOLDOWN과 원자적 수락을 구현해 완성된 수집→요약→게시 흐름에 연결한다.
2. 동일 채널 동시 요청 중 하나만 수락하고 나머지는 처리 중 안내로 끝낸다.
3. 입력/주시/권한 검증과 도움말 경로를 상태 머신 앞에 연결하고 처리 중 안내에는 예상 남은 시간을 붙이지 않는다.

## 산출물

작업 coordinator, 채널 lock/state, 명령 자동 실행 연결.

산출물은 앞으로 구현할 대상이다. 이 계획 파일을 작성한 것만으로 산출물이 구현되었다고 판단하지 않는다.

- [x] `T070-P1-A`: 동일 채널 20개 동시 요청에서 실제 파이프라인 실행이 정확히 1개다.
- [x] `T070-P1-B`: 다른 채널/Guild는 독립 상태를 가지며 도움말과 잘못된 옵션은 잠금이나 쿨타임을 생성하지 않는다.
- [x] 영향받는 검사를 수행하고 미실행·실환경 미확인 항목을 증거에서 분리했다.
