# 1.0.0 새 배포의 실제 게시 확인 생략 결정

- 결정일: 2026-09-29.
- 사용자 지시: **실제 시험 채널 게시 결과가 아직 확인되지 않았어도 1.0.0을 진행**한다.
- 적용 범위: 1.0.0-P4에서 새 배포 SHA의 실제 사용자 명령→Discord 게시 결과와 게시 직후 cooldown을 확인하는 항목 `T100-P4-A`를 출시 필수 게이트에서 제외한다. 이 항목의 판정은 `SKIPPED_BY_USER`이며 PASS가 아니다. 도움말·기본/개수/오늘·미주시 채널의 새 배포 실제 응답도 확인되지 않았다.

0.9.0-P2에서는 일반 사용자 계정의 합성 대화와 명령으로 실제 요약 게시·중복/대기·도움말을 확인했다. 그때의 구현 SHA와 1.0.0 배포 SHA 사이에서 패키지 실행 코드의 변경은 `__version__` 문자열 한 줄뿐이다. 1.0.0에서는 동일 SHA wheel 설치, 단일 Gateway 준비, DB 무결성·설정/대기 보존, 실제 인증의 **비게시** 합성 모델 호출을 확인했다. 이 간접 증거는 새 버전의 실제 Discord 게시 성공을 보증하지 않는다.

1.0.0-P4의 상태·자원·보존·복귀 준비 검사 `T100-P4-B`와 단계별 GitHub push·CI·증거 기록은 그대로 수행한다. 릴리스 문서에는 새 배포의 게시 검증 공백, 8/24시간 지속 시험 생략, 실제 권한 거부 조작 미실행을 명시한다. 출시 뒤 시험 채널 게시에 실패가 확인되면 [복귀 절차](../../../docs/upgrade-rollback-1.0.0.md)를 따른다.
