# 1.1.0a-P1 — 가독성 형식 프롬프트

- 상태: **PLANNED** · 검사: `T110a-P1-A/B` · 환경: 개발 LXC, 합성 대역(모델 호출 없음)

## 선행 조건·작업

`v1.1.0` 출시와 `main` 통합을 확인한다. [계약](CONTRACT.md) 1절에 따라 신뢰 프롬프트에 공통 형식 규칙(주제별 굵은 소제목·빈 줄 구분, `- **화자**: …` 불릿, 한 불릿 한 사람·한두 문장, 절제된 굵은 강조, 결정·남은 점 묶음)을 넣는다. 1.1.0의 “사실 문장 뒤 거의 매번 비아냥”을 **주제마다 최대 한 줄, `↳ *…*`로 분리**로 바꾸고 블록 인용을 비아냥에 쓰지 못하게 한다. 짧게 노트를 “주제 2~4개·불릿 최대 8개”로, 길게·자세히 노트를 같은 형식 규칙에 맞게 고친다. 사실·주어 명시·새 미해결점 금지·금지선 문장은 유지한다. 프롬프트 버전을 `1.1.0a-p1-v1`로 올린다.

## 검증·완료 기준

- `T110a-P1-A`: 세 길이 × (일반·화자 재시도·비하어 재시도) 프롬프트가 형식 규칙·비아냥 분리·블록 인용 금지를 포함하고, 1.1.0의 “거의 매번 비아냥” 문구가 없으며, 순서(신뢰 경계 → 사실 → 추가 요청 → 말투·형식 → 금지선 → 길이)가 유지된다.
- `T110a-P1-B`: 형식 예시 같은 합성 출력(굵은 소제목·불릿·`↳ *…*` 비아냥)이 기존 출력 검사(비하어·화자 표식·도구 보고)를 오탐 없이 통과하고, `↳` 줄의 비하어는 검사에 걸린다. 1,900자 분할에서 소제목·불릿 줄이 중간에서 잘리지 않는다(줄 단위 분할 우선 확인).
