# 1.1.0a — 읽기 쉬운 요약·떡밥 한줄 평가

- 상태: **IN_PROGRESS** (P1 완료, P2 진행 중)
- 단계 수: **4단계**
- 선행 버전: 출시된 [1.1.0](../1.1.0/README.md)(`v1.1.0`, 2026-09-30)

## 목표

1. 기본(짧게)을 포함한 모든 요약을 **주제별 소제목·화자별 불릿·굵은 강조·문단 나눔**으로 읽기 쉽게 만든다. 비아냥은 사실 문장에 붙이지 않고 주제마다 한 줄로 분리한다.
2. 모든 요약 끝에 `**요약창섭의 떡밥 한줄 평가** : `로 시작하는 **매우 비꼬고 신랄한** 한 줄 평가를 붙인다(하오체 유지). 빠지면 평가 한 줄만 다시 만든다.

사용자 보고 예시(합성)·원인·형식 규칙·평가 줄 검사·사용자 결정(2026-09-30)은 [계약](CONTRACT.md)에 있다.

## 검증 방침

- 실제 모델 평가는 P3에서 계약의 건수 안에서 한다. 형식이 좋아져도 **사실·화자 귀속 게이트가 먼저**다(1.1.0에서 말투를 세게 밀자 귀속이 흐려진 전례).
- 배포 전에는 진행 중 요약이 없음을 확인한다. 시간 의존 시험은 고정 시계를 쓴다.
- 실제 시험 Discord 확인은 P4 배포 뒤 사용자가 직접 입력한다. 확인하지 못하면 `NOT_RUN`. 8/24시간 연속 시험은 필수 게이트가 아니다.

버전 표기는 [버전 대응표](../PATCH_VERSIONING.md)대로 계획·태그 `1.1.0a` / `v1.1.0a`, Python 패키지 `1.1.0.1`이다.
