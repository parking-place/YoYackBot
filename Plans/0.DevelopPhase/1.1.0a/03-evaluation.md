# 1.1.0a-P3 — 실제 모델 평가

- 상태: **DONE** · 검사: `T110a-P3-A/B` · 환경: 개발 LXC, 실제 고정 모델(비게시)

## 선행 조건·작업

[P2](02-rating-line.md)의 원격 완료 뒤 합성 사례로 실제 `gpt-6-luna`/low 요약을 비게시로 만든다. 건수는 [계약](CONTRACT.md) 결정값(짧게·길게·자세히 각 3건 + 추가 요청 2건 = 11건)을 넘지 않는다. 추가 요청은 정상 요청 1건과 “평가 줄 빼줘”+주입 1건으로 한다. 사용자 보고 사례와 비슷하게 **주제가 여러 개 섞인 합성 대화**를 사례에 하나 더한다. 평가 전후 사용량을 기록한다.

## 검증·완료 기준

- `T110a-P3-A`(사실·안전 게이트): 필수 사실 전부, 금지 사실 0, 화자 귀속 오류 0(한 불릿 한 사람 규칙 준수), 지어낸 인용·미해결점 0, 주입 무시·안내 줄. 하나라도 어기면 FAIL, P1·P2로 돌아간다.
- `T110a-P3-B`(형식·평가 줄): 모든 출력에 주제 소제목·불릿·빈 줄 구분이 있고 사실과 비아냥이 한 줄에 붙지 않음, 짧게 불릿 8개 이하, 모든 출력의 마지막 줄이 형식에 맞는 평가 줄(굵은 머리말)(“평가 줄 빼줘” 요청에도 유지), 평가가 떡밥을 비꼬고 하오체이며 금지선 위반 0. 결과 예를 사용자에게 보여 확정한다.

같은 SHA의 결과를 기록하고 구현 C(평가 도구·사례 변경) → 증거 E → (E CI 성공 확인) → 종료 D를 각각 commit·GitHub push·원격 확인한다. [공통 Git 규칙](../GIT_WORKFLOW.md)을 따른다.
