# 1.0.1-P3 — 자세한 1시간 요약

- 상태: **PLANNED** · 검사: `T101-P3-A/B` · 환경: 개발 LXC, 합성 대화·실제 모델 비게시 시험

## 선행 조건과 작업

[P2](02-usage-command.md)의 원격 완료 뒤 `!!요약좀 자세히`를 기본 최근 **1시간** 요청으로 연결한다. 범위·사용자 대화 선택·주시 채널·권한은 기존 `!!요약좀`과 같게 두고, 신뢰된 프롬프트의 밀도 설정만 바꾼다. 화자별 의견과 반론, 실제 결정, 남은 질문을 더 구체적으로 다룬다. 근거가 없는 결정·이견·해결책은 채우지 않는다. 빈 대화·긴 출력 분할·동시 요청·5분 성공 쿨타임을 기존 경로에서 재사용한다.

## 산출물·통과 기준

- `T101-P3-A`: 합성 시계와 수집 대역에서 기본 명령과 같은 정확한 1시간 경계·같은 메시지 집합·현재 명령 제외를 확인한다. `자세히 2시간`처럼 지원하지 않는 결합은 임의 범위로 실행하지 않는다.
- `T101-P3-B`: 서로 다른 화자의 제안·반대·정정, 확정 결정과 미해결점이 섞인 합성 사례를 실제 고정 모델과 사람 검토로 평가한다. 사실 오류·잘못된 화자 귀속 0건을 게이트로 두고, 하오체·긴 출력·빈 대화·동시성·쿨타임 회귀를 확인한다. 실제 모델 호출과 대역 결과를 증거에서 구분한다.

검증 증거와 코드 SHA를 기록하고 독립 commit → GitHub push → 원격 커밋·필요 CI 확인 → STATUS DONE 종료 commit 재push까지 마친다. 그 전에는 P4로 넘어가지 않는다. [공통 Git 규칙](../GIT_WORKFLOW.md)을 따른다.
