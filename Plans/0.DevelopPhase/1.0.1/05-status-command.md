# 1.0.1-P5 — 상태 명령·실측 지표

- 상태: **DONE** · 검사: `T101-P5-A/B` · 환경: 개발 LXC, 격리 DB·시험 Discord

## 선행 조건과 작업

[P4](04-short-summary.md)의 원격 완료 뒤 `!!요약좀 상태`를 주시 채널에서 읽기 전용으로 처리한다. [명령 계약](COMMAND_CONTRACT.md)에 따라 현재 Guild의 주시 채널 수·보존 캐시 건수, SQLite 주 파일과 WAL 파일의 크기 합계, **실제 설정의** 모델/effort, 현재 Guild의 최근 전체 게시 성공 시각을 읽는다. 서비스 준비 상태가 확인될 때만 `평온하오.`를 쓴다. 없거나 읽을 수 없는 값은 `기록이 없소.`/`확인할 수 없소.`처럼 분리한다. 공개 응답에는 다른 Guild의 수치·경로·ID·원문을 포함하지 않는다.

## 산출물·통과 기준

- `T101-P5-A`: 두 Guild를 넣은 격리 DB에서 주시·캐시 건수가 현재 Guild만 반영되고, 마지막 요약 없음/23분 전/재시작 후/시계 경계와 모델 설정 변경 시 표시를 검증한다. 예시의 4곳·12,481건·18.4 MB·GPT-5.6은 고정값으로 사용하지 않는다.
- `T101-P5-B`: DB 잠금·파일 누락·인증 준비 실패·Gateway 미준비에서 `평온하오.`라는 허위 정상 표시가 없고 조회가 요약 대기열·모델 호출·쿨타임을 건드리지 않는다. 시험 Discord에서 실제 읽기 전용 출력과 비밀정보 비노출을 확인한다.

검증 증거와 코드 SHA를 기록하고 독립 commit → GitHub push → 원격 커밋·필요 CI 확인 → STATUS DONE 종료 commit 재push까지 마친다. [공통 Git 규칙](../GIT_WORKFLOW.md)을 따른다.
