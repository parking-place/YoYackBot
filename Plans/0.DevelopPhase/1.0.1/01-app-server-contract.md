# 1.0.1-P1 — app-server JSON·계정 범위 계약

- 상태: **DONE** · 검사: `T101-P1-A/B` · 환경: 개발 LXC, 격리 합성 JSON

## 선행 조건과 작업

출시된 `v1.0.0`의 정확한 운영 SHA·봇 전용 계정·CLI 버전·인증 경로 권한을 확인한다. 운영 인증값은 읽거나 기록하지 않는다. [명령 계약](COMMAND_CONTRACT.md)의 `account/rateLimits/read`를 현재 고정 CLI로 읽을 수 있는지, 봇 요약 계정과 같은 버킷을 반환하는지 개발 LXC에서 비게시·읽기 전용으로 확인한다. 실제 응답의 필드 **이름·타입·창 길이·버킷 ID만** 비밀값 없이 기록한다. 해당 메서드가 고정 버전에 없으면 P1을 BLOCKED로 두고 호환 버전·회귀 범위를 결정한 뒤 진행한다.

요청 ID 대조, `initialize` 절차, 5시간/주간 창 선택, `usedPercent`→남은 %, 반올림, 누락·오류 처리와 timeout/출력 상한을 갖춘 읽기 전용 어댑터를 만든다. 인증 파일을 서비스 계정 경계 밖에 복사하거나 비밀정보를 로그에 남기지 않는다. 사용량 리셋 크레딧 소비·계정 변경은 범위 밖이다.

## 산출물·통과 기준

- `T101-P1-A`: 합성 JSON으로 단일/복수 버킷, 300·10080분 식별, 0·10·100% 경계, 소수 반올림, 누락·잘못된 값·오류 응답·알림 선행을 검사한다. 추측한 숫자는 절대 출력하지 않는다.
- `T101-P1-B`: 개발 LXC에서 실제 봇 계정의 읽기 전용 응답을 확인하고, 계정·토큰·raw JSON 비노출, timeout·종료 시 자식 정리, 요약 실행·Discord 게시 0회를 확인한다. 실제 창이 다르면 라벨을 속이지 않고 BLOCKED로 남긴다.

검증 결과와 정확한 코드 SHA를 [증거 양식](../EVIDENCE_TEMPLATE.md)에 기록한다. 단계별 독립 commit을 GitHub에 push하고 원격 커밋·필요 CI를 확인한 뒤에만 [1.0.1 상태](STATUS.md)를 DONE으로 바꾼 종료 커밋까지 다시 push한다. **마지막 원격 반영 전에는 다음 P2를 시작하지 않는다.** [공통 Git 규칙](../GIT_WORKFLOW.md)을 따른다.
