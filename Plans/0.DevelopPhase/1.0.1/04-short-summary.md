# 1.0.1-P4 — 짧은 1시간 요약

- 상태: **PLANNED** · 검사: `T101-P4-A/B` · 환경: 개발 LXC, 합성 대화·실제 모델 비게시 시험

## 선행 조건과 작업

[P3](03-detailed-summary.md)의 원격 완료 뒤 `!!요약좀 짧게`를 최근 **1시간** 요청으로 연결한다. 선택 메시지·보안·주시 경계는 기본 명령과 같다. 요약 본문을 모바일에서 훑기 쉬운 **4~6줄 목표**로 압축하고, 중요한 화자·결정·미해결점은 원문에 있을 때만 남긴다. 길이 제한 때문에 관계나 결론을 왜곡하지 않도록 프롬프트와 출력 검증을 함께 다듬는다. 비어 있는 범위는 기존 빈 대화 안내를 쓴다.

## 산출물·통과 기준

- `T101-P4-A`: 기본 1시간과 수집 범위가 일치하고 `짧게 30분` 같은 결합이 거부되며, 요청 선택·쿨타임·중복 차단이 기본 요약과 같다.
- `T101-P4-B`: 짧은 대화·긴 대화·화자 다수·결정 미확정 사례의 실제 모델 출력에서 본문 밀도, 주요 사실 보존, 화자 귀속·하오체를 사람 검토로 확인한다. 사실 오류 0건을 게이트로 두고, 분할 시 Discord 길이 제한과 허용 멘션 없음도 검사한다.

검증 증거와 코드 SHA를 기록하고 독립 commit → GitHub push → 원격 커밋·필요 CI 확인 → STATUS DONE 종료 commit 재push까지 마친다. [공통 Git 규칙](../GIT_WORKFLOW.md)을 따른다.
