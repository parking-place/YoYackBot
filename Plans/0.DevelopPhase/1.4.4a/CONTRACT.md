# 1.4.4a 계약 — Codex CLI 0.164.0 업데이트

이 문서는 구현 목표다. 기준 코드는 출시된 `v1.4.4`(`1034a3a`)이다. “사용자 결정”은 2026-10-27 사용자 요청과 질문 답이고, “기본안”은 그 밖의 세부를 개발자가 정한 것이다.

## 1. CLI 고정값

- `PINNED_CLI_VERSION`을 `codex-cli 0.164.0`으로 바꾼다. 모델 `gpt-6-luna`·허용 추론 강도·빠른 모드·격리 실행 인자는 그대로다(사용자 결정).
- 실행 파일은 공식 릴리스 `rust-v0.164.0`의 `codex-x86_64-unknown-linux-musl`과 `codex-code-mode-host-x86_64-unknown-linux-musl`이다. 운영 경로 `/usr/local/bin/yoyack-codex`·`/usr/local/bin/yoyack-codex-code-mode-host`는 그대로 쓰고, 배포 때 파일만 바꾼다. 바꾸기 전의 0.158.0 두 파일은 버전을 붙여 남긴다(기본안).

## 2. 호환 확인

- 새 CLI로 봇이 쓰는 모든 호출이 실제 모델에서 돌아야 한다: 요약(후보·평가 고르기), `!!말하자면`, `/셀프디스`, 안내 문구 다시 쓰기(high), 식단 평가(사진 첨부), 주간 훈수, 빠른 모드, `사용량` 조회(app-server).
- 단계별 소요 시간 로그(1.3.2)가 새 CLI 출력에서도 남아야 한다. 오류 분류·격리 실행(bwrap, 읽기 전용 마운트, 네트워크·도구 차단)은 그대로다.
- DB·환경·프롬프트는 바뀌지 않는다. 복귀 대상은 `v1.4.4`이고, 복귀 때는 0.158.0 두 파일도 함께 되돌린다.
