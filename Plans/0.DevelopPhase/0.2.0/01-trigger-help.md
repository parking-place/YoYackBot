## 선행 조건

[0.1.0-P5](../0.1.0/05-channel-acceptance.md)가 검증과 GitHub push 확인까지 끝나 DONE이어야 한다.

## 수행 작업

1. 메시지 안의 `!!요약좀` 포함을 인식하고 트리거 뒤의 옵션만 파서에 넘긴다.
2. `!!요약좀 도움`을 일반 요약보다 먼저 처리하며 주시 여부·처리 상태와 관계없이 도움말을 제공한다.
3. 기본/숫자/분/시간/개/오늘/일/주 예제와 주시 설정 안내를 하오체로 작성한다.

## 산출물

트리거 router, 도움말 템플릿, 명령 문법 fixture.

산출물은 앞으로 구현할 대상이다. 이 계획 파일을 작성한 것만으로 산출물이 구현되었다고 판단하지 않는다.

## 검증과 통과 기준

- [ ] `T020-P1-A`: `신창섭아 !!요약좀`, `!!요약좀 도움`과 복수 트리거 입력의 라우팅이 결정적이다.
- [ ] `T020-P1-B`: 도움말은 SUMMARIZING/COOLDOWN에서 동작하고 History·CLI·쿨타임 상태 변경을 일으키지 않는다.
- [ ] 영향받는 선행 기능의 회귀 검사가 통과하고 실패·미실행·실환경 미확인 항목을 구분했다.

## 단계 완료 — GitHub 업로드 필수

- [ ] 위 작업·검증을 완료하고 [증거 양식](../EVIDENCE_TEMPLATE.md)에 대상 SHA·환경·결과·제한을 기록했다.
- [ ] 실제 비밀값·`.private`·DB·Discord 원문·임시 파일이 커밋에 없음을 확인했다.
- [ ] 구현과 증거를 단계별로 commit하고 대상 브랜치에 **GitHub push**했다.
- [ ] 원격에서 증거 커밋 존재와 구현 SHA 포함, 필요한 CI 결과를 확인했다.
