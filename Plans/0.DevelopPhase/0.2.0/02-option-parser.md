## 선행 조건

[0.2.0-P1](../0.2.0/01-trigger-help.md)가 검증과 GitHub push 확인까지 끝나 DONE이어야 한다.

## 수행 작업

1. 오늘 → X개 → X분 → X시간 → X일 → X주 → 숫자 → 기본값의 파싱 규칙을 구현한다.
2. 옵션 없음은 1시간, 숫자만 있으면 시간으로 해석하고 `30분 부탁하오` 같은 허용 후행 문구를 지원한다.
3. 서로 다른 범위 옵션의 중복, 명령 반복, 미지원 문자열은 D06 규칙에 따라 거부하거나 한 번만 처리한다.

## 산출물

범위 파서, 형식별 요청 타입, 긍정/부정 입력 집합.

산출물은 앞으로 구현할 대상이다. 이 계획 파일을 작성한 것만으로 산출물이 구현되었다고 판단하지 않는다.
