# 1.0.2-P3 — 준비 완료 채널의 요약 시작 안내

- 상태: **PLANNED** · 검사: `T102-P3-A/B` · 환경: 개발 LXC, 합성 Discord 전송

## 선행 조건·작업

[P2](02-active-scope.md)의 원격 완료 뒤, **준비 완료 채널에서 채널 입장에 성공한 모든 요약 요청**에 시작 안내를 한 번 보낸다. 위치는 입장 직후 준비 상태를 다시 확인한 뒤, 캐시 조회(`CacheOnlyCollector.collect`) 직전이다. `!!요약좀 10일`의 문구는 정확히 `10일 채팅을 요약해보겠소.`이고, 다른 범위·모드는 [안내 계약](NOTICE_CONTRACT.md) 표를 따른다.

재확인에서 준비 완료가 아니면 시작 안내 없이 기존 준비 중 안내를 보내고 입장을 해제한다. 시작 안내 전송이 실패하면 조회·모델 호출 없이 입장을 해제한다. 시작 안내 뒤의 결과(게시·빈 대화·대기열·입력 과다·모델 실패·확인된 한도 초과·권한 변경)는 기존 안내를 그대로 뒤따르게 한다.

미주시·설정 확인 실패, 초기 수집·누락 재확인 중(준비 중), 잘못된 옵션, 진행 중 작업, 성공 쿨타임, 서비스 종료에는 시작 안내를 보내지 않는다. 안내는 요약 게시나 성공 쿨타임으로 세지 않는다. 모든 전송에서 멘션을 비활성화한다.

## 검증·완료 기준

- `T102-P3-A`: 준비 완료 채널의 기본·숫자·분·시간·오늘·일·주·개수·자세히·짧게 요청마다 시작 안내가 조회 전에 정확히 한 번 나오고, 요약 게시·빈 결과·대기열·모델 실패·한도 초과에서도 순서와 기존 후속 안내가 맞다.
- `T102-P3-B`: 미주시·초기 수집 중·누락 재확인 중·첫 주시 완료 안내 미게시·입장 뒤 준비 상태 상실·잘못된 옵션·쿨타임·종료·전송 실패에서 허위 시작 안내나 조회·모델 실행이 없고, 실패 뒤 재시도가 가능하다. 안내문에 원문·멘션·식별자가 섞이지 않는다.
