# 1.0.2-P4 — 진행 중 범위를 알려주는 중복 안내

- 상태: **PLANNED** · 검사: `T102-P4-A/B` · 환경: 개발 LXC, 합성 동시성·대기열

## 선행 조건·작업

[P3](03-collection-notice.md)의 원격 완료 뒤 BUSY 응답을 [안내 계약](NOTICE_CONTRACT.md)의 활성 범위 기반 두 줄로 바꾼다. 예를 들어 `10일` 수집 중 들어온 `!!요약좀 5분`에는 다음 문구를 보낸다.

```text
현재 10일 분 채팅을 요약중이오.
참을성을 가져보시오.
```

중복 안내는 수집·모델 대기·모델 실행·게시 중 동일한 활성 범위를 사용한다. 첫 시작 안내보다 앞서 게시되지 않도록 같은 채널의 전송 순서를 지킨다. 진행 작업이 끝나면 일반적인 새 요청·쿨타임 처리로 돌아가고 예전 범위를 표시하지 않는다. 비요약 명령은 BUSY에 묶지 않는다.

## 검증·완료 기준

- `T102-P4-A`: 활성 10일/후속 5분 사례에서 두 줄의 **정확한 문구**, 한 번뿐인 수집·모델·결과 게시, 중복 19건의 범위 일치와 시작 안내 우선 게시를 확인한다.
- `T102-P4-B`: 수집·전역 모델 대기·모델·게시 각 구간, 다른 Guild/채널, 성공 쿨타임, 작업 취소/실패 경계를 시험한다. 다른 요청의 범위 누설·유령 BUSY·중복으로 인한 쿨타임 갱신이 없다.
