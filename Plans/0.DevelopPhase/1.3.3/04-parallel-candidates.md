## 작업

[계약](CONTRACT.md) 5절대로 요약 호출과 평가 후보 호출을 같은 시점에 시작한다. 후보 프롬프트에서 요약 줄 의존을 뺀다. 심사는 둘 다 끝난 뒤 최종 요약 본문으로 따로 하고, 본문과 평가 줄은 함께 게시한다. 동시 실행 자리는 비어 있을 때만 빌리고, 없으면 지금처럼 순서대로 실행한다.

## 검증·완료 기준

- `T133-P4-A`: 정상·요약 재작성·후보 실패·후보 재생성·`평가 빼줘` 경로에서 호출 순서·겹침·결과(`picked`/`regenerated`/`fallback_summary`/`missing`/`skipped`)와 게시 한 번(본문+평가 줄)이 맞다. 호출 상한 5회. `request_timing`에서 두 호출의 시작이 같다.
- `T133-P4-B`: 요약 실패·모델 오류·권한 회수·종료 때 후보 호출이 취소되고 임시 파일이 남지 않는다. 자리가 없으면 기다리지 않고 순서 실행으로 바뀌며 다른 채널 요청을 밀어내지 않는다(동시 요청 시험). 최근 평가 저장·쿨타임·지표 불변, 전체 회귀 통과.
