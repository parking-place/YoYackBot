# 1.3.3-P2 — `!!말하자면` 대화 직접 전달

- 상태: **DONE** · 검사: `T133-P2-A/B` **PASS** ([증거](../evidence/1.3.3-P2.md)) · 환경: 개발 LXC, 합성 대역

## 작업

[계약](CONTRACT.md) 2·3절과 [결정 D11](../DECISIONS.md#d11--대화-입력의-프롬프트-직접-전달)대로 공통 자료 블록(요청별 nonce 구분자)과 프롬프트 조립을 만들고, `!!말하자면`의 후보·선택 호출에 먼저 적용한다. 대화 파일 마운트를 빼고, 실패 분류가 되찍힌 프롬프트를 보지 않게 하며, 프롬프트 상한을 입력 상한에 맞춘다. 호출 구조(후보 → 선택, 최대 3회)와 최종 한 줄 조립은 그대로다.

## 검증·완료 기준

- `T133-P2-A`: 두 호출의 프롬프트에 최근 30개(및 후보)가 자료 블록 안에만 있고, 블록 밖 지시문은 고정 문구다. nonce가 요청마다 다르고 대화 속 구분자 흉내로 블록을 닫을 수 없다. 격리 명령에 대화 파일이 없고 나머지 격리 옵션은 그대로다. 30개 × 긴 메시지 최악 입력이 상한 안에서 동작한다.
- `T133-P2-B`: 대화에 “quota exceeded”·“unauthorized” 같은 글이 있어도 실패 분류가 바뀌지 않는다. 기존 사자성어 시험(30개 경계·후보 형식·재생성·salvage·선택·쿨타임·실패 안내)이 그대로 통과하고, “대화는 프롬프트에 없다”를 고정하던 시험은 “자료 블록 안에만 있다”로 바뀐다. 로그에 내용 없음, 전체 회귀 통과.
