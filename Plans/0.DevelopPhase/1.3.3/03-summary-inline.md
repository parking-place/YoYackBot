# 1.3.3-P3 — 요약 대화 직접 전달·입력 상한

- 상태: **PLANNED** · 검사: `T133-P3-A/B` · 환경: 개발 LXC, 합성 대역 + 크기 측정용 실제 CLI 확인

## 작업

[계약](CONTRACT.md) 2·4절대로 요약·재작성·후보 호출에 대화 전체를 자료 블록으로 넣고, 심사 호출은 요약 본문·후보·최근 평가만 받게 한다. 고정된 CLI 0.158.0의 모델 문맥 크기와 잘림 정책을 확인하고, 한국어 합성 대화의 바이트당 토큰을 재서 입력 상한 기본값(약 500,000바이트 안)을 확정한다. 상한 초과는 지금의 “너무 많소” 안내로 막는다. 프롬프트 버전을 올린다.

## 검증·완료 기준

- `T133-P3-A`: 요약 5회 경로(재작성·후보 재생성 포함)에서 호출마다 자료 블록 내용이 계약대로다(요약·재작성·후보는 대화 전체, 심사는 대화 없음). 추가 요청·서버 말투·최근 평가·답글 참조(F10)·답장 범위가 지금처럼 전달된다. 입력 상한 경계(상한 −1·상한·상한 +1)에서 모델 호출 없이 안내하고 쿨타임이 없다.
- `T133-P3-B`: 출력 검사(화자 키·메시지 키·비하어·본문 없음·미결 조롱)와 평가 후보 거르기·심사 파싱이 그대로 동작한다. 대화 속 지시·구분자 위조 합성 사례가 자료 블록 밖으로 나가지 않는다. 요약 프롬프트 고정 시험을 새 버전으로 갱신, 전체 회귀 통과. 확정한 입력 상한과 근거(CLI 확인값, 바이트당 토큰)를 증거에 남긴다.
