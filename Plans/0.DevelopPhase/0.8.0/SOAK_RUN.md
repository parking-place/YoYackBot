# 0.8.0-P5 장시간 시험 진행 기록

- 상태: **IN_PROGRESS**. 8시간 결과는 아직 판정하지 않는다.
- 고정 실행 SHA: `8085be4a6958826045be37d423a1806bbf2ecd87`.
- 시작: 2026-09-28 16:25:21 UTC (2026-09-29 01:25:21 KST).
- 완료 판정 가능 시각: **2026-09-29 00:25:21 UTC 이후**. 실행 중단·표본 부족·임계값 초과 시 완료로 계산하지 않는다.
- 사전 기준: [8시간 시험 계획](../../../docs/soak-0.8.0-plan.md). 개발 LXC 전용 서비스와 격리 합성 workload를 동시에 관측한다.
- 첫 표본의 SHA·UTC 시각과 시작 manifest의 SHA가 일치했고, 실제 봇 서비스는 준비 상태였다. 비공개 전체 표본과 집계는 LXC의 전용 시험 디렉터리에만 둔다.
- 이전에 시작했던 1표본 실행은 표본마다 UTC·SHA를 남기지 않는 계측 누락으로 즉시 중단했다. 그 시간은 이 8시간에 포함하지 않는다. 수정한 SHA로 처음부터 다시 시작했다.

시험이 끝난 뒤 전체 지속 시간·표본 수·실측 최대값·장애 주입과 연결 복원·모델 probe 결과를 검사하고, 통과한 경우에만 단계 증거와 상태를 갱신한다.
