# 1.1.0 — 짧은 기본 요약·추가 요청·더 싸가지없는 말투

- 상태: **IN_PROGRESS** (P1 완료, P2 진행 중)
- 단계 수: **5단계**
- 선행 버전: 출시된 [1.0.2c](../1.0.2c/README.md)(`v1.0.2c`, 2026-09-30)

## 목표

1. `!!요약좀`의 기본을 **짧게**로 바꾼다. 현행 기본은 `!!요약좀 [범위] 길게`, `자세히`는 **아주 긴 버전**이 된다.
2. 범위·길이 뒤의 문장을 **추가 요청**으로 모델에 넘긴다. 예: `!!요약좀 2분 길게 시간순으로 해줘`.
3. 요약 말투를 **더 띠껍고 싸가지없게**, 마구 비꼬되 **하오체는 유지**한다.
4. `!!요약좀 도움`을 새 규칙으로 고친다.

세부 문법·오인 방지·추가 요청의 신뢰 경계·말투 금지선·사용자 결정(2026-09-30)은 [계약](CONTRACT.md)에 있다.

## 검증 방침

- 실제 모델 평가는 P4에서만, 계약의 건수 안에서 한다. 평가 전후 사용량을 기록하고 위험하면 멈추고 알린다.
- 추가 요청은 사용자가 쓴 문장이 모델에 들어가므로 **프롬프트 주입 시험**(범위 확대·사실 조작·도구 사용·금지선 해제 요구)을 합성·실제 모델 양쪽에서 한다.
- 시간에 따라 결과가 바뀌는 시험은 고정 시계를 주입한다. 배포 전에는 **진행 중 요약이 없는지** 확인한 뒤 서비스를 멈춘다(1.0.2c 교훈).
- 실제 시험 Discord 확인은 P5 배포 뒤 사용자가 직접 입력한다. 확인하지 못하면 `NOT_RUN`으로 남긴다. 8/24시간 연속 시험은 필수 게이트가 아니다.
