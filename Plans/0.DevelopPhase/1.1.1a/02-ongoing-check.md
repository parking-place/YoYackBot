# 1.1.1a-P2 — 미결 조롱 표현 검사와 1회 재생성

- 상태: **IN_PROGRESS** · 검사: `T111a-P2-A/B` · 환경: 개발 LXC, 합성 대역(모델 호출 없음)

## 선행 조건·작업

[P1](01-ongoing-prompt.md)의 원격 완료 뒤 `output_quality`에 [계약](CONTRACT.md)의 `narrator_mocks_ongoing` 검사(새 `OutputIssue.ONGOING_JAB`)를 넣는다. 서술자 문장만 보고(인용·`>`·코드 줄 제외, 비하어 검사와 같은 방식), 표현 목록은 코드 상수로 둔다. 본문에서 감지되면 화자 표식·비하어와 같은 1회 재생성 한도 안에서 “진행 중인 이야기를 비꼬지 말 것” 노트를 붙여 다시 만들고, 평가 줄에서만 감지되면 평가 줄만 다시 만든다. 그래도 남으면 게시하고 지표 로그 허용 목록에 `ongoing_jab=none/retried/retried_left`를 더한다. 모델 호출 상한(요약당 3번)과 원문 비기록 규칙은 그대로다.

## 검증·완료 기준

- `T111a-P2-A`: 표현 목록 각각이 서술자 문장·비아냥 줄·평가 줄에서 감지되고, 원문 인용·`>` 줄·코드 블록 안에서는 감지되지 않으며, 평범한 문장(“다음 주에 보자고 했소”, “진행 중이오”)은 오탐하지 않는다.
- `T111a-P2-B`: 합성 대역으로 본문 감지 → 1회 재생성, 평가 줄만 감지 → 평가 줄만 재생성, 재생성 후에도 남음 → 게시+`retried_left`, 다른 재시도와 겹칠 때 호출 3번 이하, 평가 빼기·추가 요청 인용 유지, 로그에 원문 없음.
