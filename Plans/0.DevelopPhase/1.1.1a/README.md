# 1.1.1a — 결론 안 난 이야기는 진행 중으로

- 상태: **IN_PROGRESS** (P1~P2 완료, P3 진행 중)
- 단계 수: **4단계**
- 선행 버전: 출시된 [1.1.1](../1.1.1/README.md)(`v1.1.1`, 2026-10-01)

## 목표

1. 채널 대화는 계속 이어지는 대화로 본다. **완벽하게 매듭지어진 것만 결정**, 나머지는 모두 **진행 중**으로 담담하게 적는다(`아직 안 정해진 거` → `진행 중인 거`, `미정` → `진행 중`).
2. 결론이 안 났다는 사실·미룸·지연을 **비아냥 줄과 떡밥 한줄 평가의 소재로 쓰지 않는다.** 띠꺼운 하오체·비속어·한줄 비평은 유지한다.
3. 서술자의 미결 조롱 표현을 코드로 찾아 한 번 다시 만들게 해 재발을 막는다.

원인 분석·원칙·표시 변경·코드 검사·사용자 결정은 [계약](CONTRACT.md)에 있다.

## 검증 방침

- 실제 모델 12건에서 서술자의 미결 조롱 표현 **0건**, 결정·진행 중 분류 오류 0건(진행 중을 결정으로, 결정을 진행 중으로 바꾸지 않음), 사실·화자 오류 0건, 비아냥 줄·평가 줄·하오체 유지.
- 1.1.1의 추가 요청 우선·주입 방어·평가 빼기는 회귀로 확인한다.
- 사용자 보고·실제 대화는 공개 문서에 옮기지 않고 합성 대화만 쓴다. 배포 전 진행 중 요약이 없음을 확인한다. 시간 의존 시험은 고정 시계를 쓴다.
- 실제 시험 Discord 확인은 P4 배포 뒤 사용자가 직접 입력한다. 확인하지 못하면 `NOT_RUN`.
