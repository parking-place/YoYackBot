# 1.1.1a 진행 중인 대화 계약

이 문서는 구현 목표다. 현재 제품 동작이나 시험 PASS를 뜻하지 않는다. 출시된 `v1.1.1`(2026-10-01) 코드를 기준으로 작성했다.

## 문제 (사용자 피드백, 2026-10-01)

채널 대화는 끝나는 회의가 아니라 **계속 이어지는 대화**인데, 요약이 결론이 안 난 이야기를 매번 흠으로 짚어 듣는 사람이 불쾌하다. 1.1.1 실제 평가(합성 대화)에서도 다음 같은 표현이 반복됐다.

- 평가 줄: “마무리는 늘 다음으로 미루는 …”, “끝맺음은 영 싱겁구려”, “나머진 죄다 제자리걸음이오”, “계획은 아직 제자리에서 헛바퀴나 …”
- 비아냥 줄: “투표 하나 열 일도 이렇게 질질 끄니 …”, “담당 하나는 아직 공중에 떠 있으니 …”
- 소제목·묶음: `**아직 안 정해진 거**`, 짧게의 `**미정**:` — 결론이 없는 것을 결함처럼 표시한다.

원인은 `v1.1.1` 신뢰 프롬프트다.

- 말투 단락이 “질질 끄는 꼴”을 비꼴 대상으로 꼽고, 예로 “역시나 아무것도 안 정했단 말이오”를 준다.
- 평가 줄 예 “말은 산더미인데 남은 건 하나도 없구려”가 결론 없음을 깎아내리는 틀을 가르친다.
- “남은 점”·“미해결점”·“아직 안 정해진 거”라는 이름 자체가 대화를 끝난 회의처럼 다룬다.

## 원칙 (1.1.1a)

1. **완벽하게 매듭지어진 것만 결정**이다. 참여자들이 명시적으로 합의·확정한 것(“그걸로 하자”에 반대 없이 동의, 담당·일시를 정해 수락 등)만 `결정`으로 적는다. 1.1.1의 결정 판정 규칙(제안·조건부 동의·가정·농담은 결정 아님)은 그대로다.
2. **그 밖의 이야기는 모두 진행 중**이다. 결론이 안 났거나, 질문에 아직 답이 없거나, 다음에 보자고 했거나, 담당이 미정인 것은 흠이 아니라 **아직 이어지는 이야기**로 담담하게 적는다.
3. **진행 중이라는 사실 자체를 비꼬지 않는다.** 결론이 없음·미룸·지연·질질 끎·제자리걸음·흐지부지·용두사미·숙제로 남김·마무리 부족을 비아냥 줄과 평가 줄의 소재로 쓰지 않는다. 띠꺼운 하오체·비속어·비아냥 자체는 유지하고, 소재는 말바꿈·헛짚음·딴소리·호들갑·뻔한 소리처럼 **실제로 한 말과 행동**에서 고른다.
4. 진행 중 항목도 지어내지 않는다. 대화에서 실제로 물었거나, 정하자고 했거나, 다음에 보자고 한 것만 적는다(1.1.1 규칙 유지).

## 표시 변경

| 위치 | 1.1.1 | 1.1.1a |
|---|---|---|
| 길게·자세히 끝 묶음 | `**결정 난 거**` / `**아직 안 정해진 거**` | `**결정 난 거**` / **`**진행 중인 거**`** |
| 짧게 불릿 안 | `**결정**:` / `**미정**:` | `**결정**:` / **`**진행 중**:`** |
| 결정이 없을 때 `결정만 알려줘` | “결정 난 게 없소.” | “아직 매듭지어진 건 없고, 다들 얘기 중이오.”(비꼬지 않는 담담한 하오체) |
| 비아냥 줄 소재 | 질질 끄는 꼴 포함 | 진행 중·미결은 제외, 실제 말·행동만 |
| 떡밥 한줄 평가 | 대화 전체를 깎아내리는 비평 | 같은 신랄한 비평이되 **결론 없음·미룸을 소재로 쓰지 않음**. 예: `이새끼들 또 쓸데없는 소리나 하고 있구료.`, `떡밥 하나에 다들 침 튀기며 달려드는 꼴이 장관이오.` |

- `진행 중`은 시제도 바꾼다: “~하기로 했지만 아직 안 열었소”보다 “~하자는 얘기가 나왔고 이안이 내일 열겠다고 했소”처럼 **현재 이어지는 흐름**으로 쓴다.
- 추가 요청 우선(1.1.1)은 그대로다. 요청이 명시적으로 “안 끝난 거 짚어줘”처럼 미결을 모아 달라면 진행 중 목록으로 보여 주되, 비꼬는 말은 요청에 그 말투가 있을 때만 쓴다.

## 코드 검사 (보조)

- 출력에서 서술자 문장(인용·`>`·코드 줄 제외)의 **미결 조롱 표현**을 결정적으로 찾는 검사 `narrator_mocks_ongoing`을 추가한다. 대상 예: `질질`, `미루`(미뤄·미뤘), `제자리걸음`, `헛바퀴`, `흐지부지`, `용두사미`, `숙제로 남`, `끝맺음`, `마무리는`, `결론도 없`, `아무것도 안 정`, `정한 게 없`, `싱겁`. 원문 인용 안의 같은 단어는 무시한다.
- 기본 처리: 감지되면 **본문 전체를 한 번 다시 만든다**(1.1.0의 화자 표식·비하어 재시도와 같은 1회 한도, 재시도 노트에 “진행 중인 이야기를 비꼬지 말 것”). 그래도 남으면 그대로 게시하고 지표 로그에 `ongoing_jab=retried_left`를 남긴다. 평가 줄에만 있으면 평가 줄만 다시 만든다(평가 전용 재생성 1회 한도 공유).
- 원문을 로그에 남기지 않는 규칙, 한 요약당 모델 호출 최대 3번은 유지한다.
