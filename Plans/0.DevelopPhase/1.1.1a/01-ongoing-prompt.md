# 1.1.1a-P1 — 진행 중 원칙·표시 이름·비꼼 소재 프롬프트

- 상태: **PUSH_PENDING** · 검사: `T111a-P1-A/B` · 환경: 개발 LXC, 합성 대역(모델 호출 없음)

## 선행 조건·작업

`v1.1.1` 출시와 `main` 통합을 확인한다. [계약](CONTRACT.md)의 원칙대로 신뢰 프롬프트를 고친다.

- 사실 단락: “남은 점·미해결점”을 “진행 중인 이야기”로 바꾸고, 완벽하게 매듭지어진 것만 결정, 나머지는 진행 중이라는 원칙과 “진행 중은 흠이 아니다”를 넣는다.
- 형식 단락·길이 노트: `**아직 안 정해진 거**` → `**진행 중인 거**`, 짧게 `**미정**:` → `**진행 중**:`. 진행 중 항목은 현재 이어지는 흐름으로 담담하게 쓴다.
- 말투·비아냥 단락: “질질 끄는 꼴”과 “역시나 아무것도 안 정했단 말이오” 예를 지우고, 결론 없음·미룸·지연을 소재로 쓰지 말라는 문장과 대신 쓸 소재(말바꿈·헛짚음·딴소리·호들갑)를 넣는다.
- 떡밥 한줄 평가 단락과 평가 전용 프롬프트: “남은 건 하나도 없구려” 예를 지우고 같은 금지 소재를 넣는다.
- 추가 요청 우선 단락의 `결정만`(결정이 없을 때 문구)을 계약대로 바꾼다.

프롬프트 버전을 `1.1.1a-p1-v1`로 올린다. 도움말의 “결정·남은 점” 표현은 P4에서 고친다.

## 검증·완료 기준

- `T111a-P1-A`: 세 길이 × (일반·추가 요청·재시도) 프롬프트에 진행 중 원칙·새 묶음 이름·금지 소재 문장이 있고, `아직 안 정해진 거`·`미정**:`·`질질 끄는`·`아무것도 안 정했`·`남은 건 하나도 없` 문구가 없다. 평가 전용 프롬프트도 같다.
- `T111a-P1-B`: 1.1.1의 1순위 규칙(신뢰 경계·사실·귀속·금지선), 추가 요청 우선 순서·인용·평가 빼기, 출력 검사·평가 줄 분할 시험이 그대로 통과한다.

같은 SHA의 결과를 [증거 양식](../EVIDENCE_TEMPLATE.md)에 남기고 구현 C → 증거 E → (E CI 성공 확인) → 종료 D를 각각 commit·GitHub push·원격 확인한다. [공통 Git 규칙](../GIT_WORKFLOW.md)을 따른다.
