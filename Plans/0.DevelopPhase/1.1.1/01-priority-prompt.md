# 1.1.1-P1 — 우선순위 재배치·요청자 원문 인용·한줄 비평 프롬프트

- 상태: **PLANNED** · 검사: `T111-P1-A/B` · 환경: 개발 LXC, 합성 대역(모델 호출 없음)

## 선행 조건·작업

`v1.1.0a` 출시와 `main` 통합을 확인한다. [계약](CONTRACT.md)의 우선순위 표대로 신뢰 프롬프트를 재배치한다: 신뢰 경계·사실·금지선 → 기본 형식·말투·비아냥·평가 줄(“반드시”를 “기본으로”로, 각 단락 끝에 “추가 요청이 있으면 그쪽을 따르시오”) → 길이 노트 → **맨 끝 “추가 요청 우선” 단락**(요청별 해석 예, 1순위 규칙·범위 불변, 무시 안내 줄, 평가 줄 처리). 추가 요청이 있으면 그 뒤에 `«…»` 인용(원문에서 `«`·`»`·백틱 제거)과 앞뒤 경고 문장을 붙여 프롬프트를 **요청마다** 만든다(`prompt_for(mode, note=…)`). 화자 표식·비하어 재시도 노트는 인용 뒤에 붙는다. [계약](CONTRACT.md) 3절대로 떡밥 한줄 평가 지시를 “내용 요약 금지·한줄 비평·참여자 싸잡는 비속어 호칭 허용(개인 지목 욕·인신공격·비하·성적 표현 금지)”으로 바꾸고, 평가 전용 프롬프트도 같은 규칙으로 고친다. 프롬프트 버전을 `1.1.1-p1-v1`로 올린다.

## 검증·완료 기준

- `T111-P1-A`: 세 길이 × (일반·화자 재시도·비하어 재시도) 프롬프트에서 추가 요청 단락이 **길이 노트보다 뒤**(재시도 노트 앞)에 있고, 형식·말투·평가 단락이 추가 요청 양보 문구를 갖고, “반드시 적용/반드시 지키시오”가 기본 표현 규칙에서 사라지며, 1순위 규칙 문구(사실·귀속·신뢰 경계·금지선)는 유지된다.
- `T111-P1-B`: 추가 요청 원문이 scope 줄과 프롬프트 끝 인용에 **둘 다** 있고, 인용 안의 `«`·`»`·백틱이 제거되며, 경고 문장이 인용 앞뒤에 있고, 200자 원문으로도 프롬프트 상한 안이다. 추가 요청이 없으면 인용 블록이 없다. 평가 지시·평가 전용 프롬프트가 “요약 금지·한줄 비평·허용 호칭·금지선”을 담는다. 기존 출력 검사·평가 줄·분할 시험이 그대로 통과한다.
