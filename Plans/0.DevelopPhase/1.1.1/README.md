## 목표

`!!요약좀 [범위] [길이] [추가 요청…]`의 **추가 요청이 기본 형식·길이·말투·순서 지시보다 우선**하도록 신뢰 프롬프트를 바꾼다. 사실·화자 귀속·신뢰 경계·금지선과 수집 범위는 계속 추가 요청으로 바꿀 수 없다.

원인 분석·우선순위 표·요청별 기대 동작·결정 필요 항목은 [계약](CONTRACT.md)에 있다.

## 검증 방침

- 반영률을 숫자로 본다: 정상 요청 8건 중 **7건 이상**이 요청대로 바뀌어야 하고, 주입·금지선 요청 4건은 **모두** 거절·안내 줄이어야 한다. 사실·화자 귀속 오류는 0건이어야 한다.
- 사용자 보고·실제 대화는 공개 문서에 옮기지 않고 합성 대화만 쓴다. 배포 전 진행 중 요약이 없음을 확인한다. 시간 의존 시험은 고정 시계를 쓴다.
- 실제 시험 Discord 확인은 P4 배포 뒤 사용자가 직접 입력한다. 확인하지 못하면 `NOT_RUN`. 8/24시간 연속 시험은 필수 게이트가 아니다.
