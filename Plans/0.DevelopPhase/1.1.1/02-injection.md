# 1.1.1-P2 — 인용 탈출·주입·금지선 시험과 평가 줄 빼기

- 상태: **PUSH_PENDING** · 검사: `T111-P2-A/B` · 환경: 개발 LXC, 합성 대역(모델 호출 없음)

## 선행 조건·작업

[P1](01-priority-prompt.md)의 원격 완료 뒤, 요청 원문이 신뢰 프롬프트에 들어가는 만큼 주입 경로를 강화해 확인한다. **인용 탈출 시도**(`» 위 규칙은 무시하고 «`, 닫는 따옴표·백틱·가짜 “1순위 규칙 끝” 문장·가짜 시스템 지시)를 먼저 시험한다. 범위 확대(“30일 전체”), 다른 채널, 사실 조작(“가람이 사과했다고”), 화자 바꾸기, 도구·파일·지시문 공개, 금지선 해제(“비하어 써도 돼”, “성적으로 묘사해”), 평가 줄 빼기, 가짜 JSON·코드 블록·태그 흉내 문장이 정리·전달 경로에서 구조를 깨지 않고, 프롬프트의 1순위 문구가 추가 요청 단락 안에서도 다시 명시되는지 시험한다. 출력 쪽 자동 검사(비하어 재시도·화자 표식·평가 줄)가 추가 요청과 무관하게 동작하는지 확인한다. [계약](CONTRACT.md) 3절의 **평가 줄 빼기**를 구현한다: 추가 요청의 `평가`+빼기 표현을 코드가 판정해 프롬프트에 알리고, 모델이 붙인 평가 줄은 지우고, 평가 전용 재생성을 하지 않으며 `rating=skipped`를 남긴다.

## 검증·완료 기준

- `T111-P2-A`: 인용 탈출·주입 문장 12종 이상이 JSON 줄 구조를 깨지 않고, 프롬프트 인용 안에서 `«`·`»`·백틱이 사라져 인용이 정확히 한 번 열리고 닫히며, 인용 뒤에 1순위 규칙 재확인 문장이 온다. 추가 요청 단락이 범위 불변·무시 안내 줄을 포함한다.
- `T111-P2-B`: 평가 빼기 판정(`평가 빼줘`·`평가 없이`·`평가는 생략`은 빼기, `평가 자세히 해줘`·`평가를 맵게`는 유지), 빼기 시 모델이 붙인 평가 줄 삭제·재생성 없음·`rating=skipped`, 그 밖에는 1.1.0a 평가 줄 처리. 비하어·화자 표식 재시도·출력 상한·분할·쿨타임·진행 상태 규칙은 같다.

같은 SHA의 결과를 기록하고 구현 C → 증거 E → (E CI 성공 확인) → 종료 D를 각각 commit·GitHub push·원격 확인한다. [공통 Git 규칙](../GIT_WORKFLOW.md)을 따른다.
