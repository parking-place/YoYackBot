1. `!!요약좀 사용량`·`상태`·`채널`의 응답과 요약 시작·진행 중·쿨타임·수집·실패·명령 해석 안내, 슬래시 설정 화면, 요약 머리말에 이모지를 적극적으로 쓴다. 뜻과 하오체는 그대로다.
2. 조사에서 나온 `/관리권한 설정` 거절 문구 오류를 고치고, 쓰이지 않는 중복 문구를 정리하며, 고정되지 않은 문구를 문구 목록 시험으로 고정한다.
