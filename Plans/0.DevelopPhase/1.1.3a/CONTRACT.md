# 1.1.3a 안내 문구 이모지 계약

이 문서는 구현 목표다. 현재 제품 동작이나 시험 PASS를 뜻하지 않는다. 출시된 `v1.1.3`(2026-10-01) 코드를 기준으로 작성했다.

## 요청 (2026-10-01)

`!!요약좀 사용량`·`상태`와 그 밖의 안내 문구에도 이모지를 적극적으로 쓴다(1.1.2에서 요약 본문과 도움말에 적용한 것을 봇의 나머지 말에도).

## 대상 (코드 조사, `v1.1.3` 기준)

요약 본문(프롬프트)과 도움말은 이미 이모지를 쓰므로 제외한다. 나머지 사용자에게 보이는 문구 약 80개를 13묶음으로 나눈다.

| 묶음 | 위치 | 예(지금) |
|---|---|---|
| 1. 사용량 | `usage.py` | `Codex의 기운을 살펴보았소.` / `5시간 한도는 N% 남았소.` / `주간 한도는 N% 남았소.` / 넉넉·버거움 줄 / 확인 불가·한도 소진 안내 |
| 2. 상태 | `status_report.py` | `📜 현재 형편을 살펴보았소.` / `상태:`·`주시 채널:`·`캐시된 대화:`·`DB 크기:`·`Codex:`·`마지막 요약:` 줄 |
| 3. 채널 목록 | `channel_list.py` | 머리줄·` - 채널`·`이상이오.`·빈 목록 |
| 4. 시작·진행 중 | `scope.py`, `workflow.py` | `N시간 채팅을 요약해보겠소.` / `현재 … 요약중이오.` + `참을성을 가져보시오.` |
| 5. 쿨타임 | `cooldown.py` | `아직은 때가 아니오. MM분 SS초 뒤에 오시오.` |
| 6. 빈 범위 | `collection.py` | `해당 범위에 요약할 일반 사용자 대화가 없소.` |
| 7. 수집 안내 | `backfill.py` | 수집 시작·준비 완료·아직 준비 안 됨 |
| 8. 주시 안내 | `watch_gate.py` | 주시하지 않는 채널·설정 확인 실패 |
| 9. 실패 안내 | `errors.py`, `workflow.py`, `discord.py` | 불러오기·요약·전송 실패, 대기열, 입력 과다, 종료 중, 미리보기 |
| 10. 명령 해석 | `parser.py` | 알아듣기 어려움·추가 요청 200자·범위 한도 |
| 11. `/채널 설정` 화면 | `channel_config.py` | 거절·서버 전용·권한 없음·잘못된 채널, 요약 줄, 추가·제거·비움·저장·취소·시간 초과·읽기 실패, 버튼·선택 안내 |
| 12. `/관리권한 설정` 화면 | `role_config.py` | 11과 같은 구성 |
| 13. 요약 머리말 | `summary_format.py` | `오후 8시 00분부터 지금까지의 요약이오.`(기준 시각 꼬리) |

제외: 요약 본문·떡밥 한줄 평가·거절 안내 줄(모델 출력 형식, 1.1.2·1.1.2a 규칙), 나뉜 메시지 번호 `(1/2)`, 멘션 치환 문자(`@사용자` 등).

## 규칙

- **뜻과 말투(하오체)는 그대로**, 이모지만 더한다. 숫자·시간·채널 이름 글자 사이에는 넣지 않는다.
- **줄마다 앞에 이모지를 붙인다**(여러 줄 안내는 줄마다, 제목 줄은 2개까지). 상황별로 고정한다(사용자 결정 기본안). 예:
  - 사용량: `🔮 Codex의 기운을 살펴보았소.` / `⏱️ 5시간 한도는 …` / `📅 주간 한도는 …` / 넉넉 `🟢`, 버거움 `🟠`, 확인 불가 `🌫️`, 한도 소진 `🪫`
  - 상태: `📜🔍 현재 형편을 …` / `🩺 상태` / `📡 주시 채널` / `💬 캐시된 대화` / `💾 DB 크기` / `🤖 Codex` / `🕒 마지막 요약`
  - 채널 목록: `📡 지금 본인이 …` / ` - 💬 채널` / `✅ 이상이오.` / 빈 목록 `🫥`
  - 시작 `📝`, 진행 중 `⏳` + `🧘 참을성을 가져보시오.`, 쿨타임 `🧊`, 빈 범위 `🍃`, 수집 시작 `👋📥`, 준비 완료 `✅`, 준비 안 됨 `⏳`, 주시 안 함 `👀`, 설정 확인 실패·실패 안내 `⚠️`, 대기열 몰림 `🚦`, 대기 초과 `⌛`, 종료 중 `🔌`, 입력 과다 `📚`, 명령 해석 `🤔`, 요약 머리말 `🗓️`
  - 슬래시 화면: 거절 `🚫`, 서버 전용 `🏠`, 권한 없음 `🔒`, 잘못된 선택 `⚠️`, 요약 줄 `📡`/`🛡️`, 저장 `💾`, 취소 `↩️`, 시간 초과 `⌛`. **버튼에는 Discord 버튼 이모지 속성**(전체 해제 `🧹`, 저장 `💾`, 취소 `✖️`)을 쓰고 글자는 그대로 둔다.
- 메시지 길이(2,000자)와 멘션 차단은 그대로 지킨다.

## 함께 고칠 것 (조사에서 나온 것)

- `/관리권한 설정` 화면을 연 사람이 아닌 사용자가 누르면 공용 거절 문구가 “`/채널 설정`을 직접 여시오.”라고 **다른 명령을 안내한다**. 화면별 문구로 나눠 `/관리권한 설정`을 안내한다(사용자 결정 기본안: 고침).
- `errors.USER_MESSAGES`의 5개 문구(주시 안 함·잘못된 명령·빈 대화·진행 중·쿨타임)는 쓰이지 않으면서 실제 안내 문구와 따로 적혀 있어 어긋날 수 있다. 실제 상수를 가리키게 정리한다(사용자 결정 기본안: 정리).
- 지금 시험이 글자를 고정하지 않은 문구(대기 초과, 잘못된 채널, 범위 한도 전체, 슬래시 화면 대부분)를 **문구 목록 시험**으로 고정한다. 목록 시험은 모든 안내 문구가 비어 있지 않고, 줄마다 이모지로 시작하며, 하오체 끝맺음과 숫자·이름 자리 표시를 지키는지 본다.
