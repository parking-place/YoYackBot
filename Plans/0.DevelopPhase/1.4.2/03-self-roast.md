# 1.4.2-P3 — `/셀프디스`

- 상태: **PLANNED** · 검사: `T142-P3-A/B` · 환경: 개발 LXC, 합성 대역

## 작업

[계약](CONTRACT.md) 3절대로 `/셀프디스`를 등록한다. 부른 사람의 이 채널 최근 발언만 모델에 주고, 결과를 명령 흔적 없이 채널에 올린다.

## 검증·완료 기준

- `T142-P3-A`: 등록(서버 전용·누구나), 주시 채널·준비 확인, 본인 발언만 최대 30개·7일 입력(다른 사람 0), 3개 미만 안내, 결과는 채널 일반 메시지 한 번(멘션 알림 없음)·대기 삭제, 서버 말투 적용.
- `T142-P3-B`: 검사 실패 시 한 번 재생성 뒤 실패 안내, 1분 쿨타임, 안내는 부른 사람에게만, 로그에 내용 없음, 안내 문구 목록 포함, 전체 회귀.
