# 1.0.0d-P4 — 품질·안전 평가

상태: **IN_PROGRESS**. 검사: `D7/D8`. P3의 원격 완료 후 개발 LXC에서 수행한다.

## 작업

화자별 의견·결정·미해결점의 귀속 정확도와 이름 안전성 평가표를 만든다. 동명이인·개명·악성 멘션·Markdown·긴 이름·한글/이모지와 장문 분할을 포함한다. 하오체·사실성도 확인한다. 개인 대화 대신 합성 입력/출력을 사용하고 사람 검토가 필요한 항목은 자동 검사와 구분한다.

## 통과 기준

- `D7`: 합성 사례의 필수 화자 귀속과 닉네임 노출 오류 0건·실제 멘션 알림 0건을 평가표에 기록한다.
- `D8`: 사실 오류·화자 혼동·누락을 사람 검토로 평가하고 미검토 항목을 PASS로 세지 않는다.

결과·동일 구현 SHA를 [검증 목록](TEST_MATRIX.md)에 남긴다. **이 단계만의 C(구현) → E(증거) → D(종료)를 각각 commit·GitHub push하고 원격 포함 관계·필요 CI를 확인해야 DONE**이다. 실패·미실행은 PASS로 세지 않는다. [공통 Git 규칙](../GIT_WORKFLOW.md)을 따른다.
