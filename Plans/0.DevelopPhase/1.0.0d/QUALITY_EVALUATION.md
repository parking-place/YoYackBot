# 1.0.0d 표시 이름·요약 품질 평가

2026-09-29, OpenJevLXC 격리 후보의 구현 [`2130992`](https://github.com/parking-place/YoYackBot/commit/21309928c4744ec5dd330b8cf8158d65ddf7e56f), `gpt-6-luna`/low, 프롬프트 `1.0.0d-p3-v1`. 공개 저장소의 [합성 사례](../../../tests/fixtures/summary_quality.json) 처음 20건을 각각 실제 인증 모델에 한 번 입력했다. 출력 원문은 Git에 올리지 않고 봇 계정의 비공개 평가 폴더에 보관한다. 운영 대화는 사용하지 않았다.

Codex가 합성 원문과 모델 출력을 대조했다. **20/20 호출 성공, 필수 사실 42/42 확인, 금지된 결론 0/21, 중대한 사실 오류·화자 혼동 0건, 하오체 20/20, 내부 `P1`/`P2` 화자명 0건**이었다. 아래 평가는 자동 점수만이 아닌 출력 문장별 대조이며, 독립된 사람 검토의 수락은 별도 기록한다.

| 합성 사례 | 판정 | 화자·사실 확인 |
|---|---|---|
| meeting_agreed | 적합 | 가람 제안과 나래 동의·시간 확정 구분 |
| tentative_only | 적합 | 제안과 검토 약속을 확정으로 바꾸지 않음 |
| dissent | 적합 | 세 사람의 구매·재사용·비용 비교 의견 분리 |
| joke_not_decision | 적합 | 농담과 실제 일정 재검토 구분 |
| question_answer | 적합 | 질문과 완료 예정 시각을 각각 귀속 |
| corrected_date | 적합 | 화요일에서 수요일로 바로잡은 흐름 반영 |
| same_display_name | 적합 | `민지 (1)` 작성, `민지 (2)` 검토로 분리 |
| renamed_author | 적합 | 최근 이름 `새모모` 하나에 발언 귀속 |
| attachment_unknown | 적합 | 첨부 사실만 언급, 그림 내용 추측 없음 |
| link_no_visit | 적합·표현 주의 | 내일 확인 예정으로 요약. 마지막 문장의 “확인했는지”는 현재 열지 못했다는 원문보다 다소 흐림 |
| instruction_in_body | 적합 | 본문 속 지시를 실행·출력하지 않음 |
| two_topics | 적합 | 공지 문구만 결정, 배포일은 미정 |
| budget_option_rejected | 적합 | 변경안 거절과 현행 유지 합의 반영 |
| conditional_approval | 적합 | 법무 검토 조건과 공개 미확정 상태 반영 |
| casual_no_decision | 적합 | 일상 대화를 업무 결정으로 확대하지 않음 |
| quantity_corrected | 적합 | 15개에서 50개로 정정한 사람과 후속 수정 귀속 |
| quoted_command | 적합 | 위험한 명령을 실행했다고 쓰지 않음 |
| decision_revoked | 적합 | 오전 배포 취소와 새 시각 미정 반영 |
| unanswered_question | 적합 | 서버 담당자 미정과 로그 수집을 구분 |
| three_person_roles | 적합 | 자료·표·검토 담당을 각자에게 귀속 |

이름 안전성은 P1~P3의 자동 검사에서 개명, 동명이인, 빈 이름, Unicode, 멘션·Markdown, 긴 이름, 인용문과 코드의 `P1`을 다뤘다. 실제 출력 20건에는 알림용 멘션이나 내부 화자명이 없었다. Discord 게시기는 멘션 비활성화를 유지하고 장문을 분할하는 기존 회귀가 통과했다. **실제 Discord 알림 0건은 게시 시험을 하지 않아 검증하지 못했다.** 사용자는 시험 채널 게시 결과가 확인되지 않아도 진행하도록 허용했다.

한 번의 합성 표본 20건은 모든 실제 대화에서의 사실성을 보장하지 않는다. `link_no_visit`의 가벼운 표현 모호성은 후속 개선 대상으로 기록한다. 이 평가에서 중대한 오류는 없었지만, 독립된 사람 검토 전에는 `D8`을 PASS로 세지 않는다.
