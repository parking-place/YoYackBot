# 1.0.0d-P5 — Discord 통합·출시

상태: **DONE (실제 Discord 게시 시험 면제)**. 검사: `D9/D10`. P4의 원격 완료 후 개발 LXC에서 수행했다.

## 작업

P1~P4 원격 DONE 후 같은 SHA에서 기본 및 100건 초과 요약의 닉네임을 개발 LXC에서 회귀한다. `자세히`·`짧게`는 아직 1.0.1 계획이라 이 버전의 실행 명령으로 세지 않는다. 사용자가 허용한 최대 4개의 모델 호출을 위해 공유 인증 갱신의 이전 사본 덮어쓰기를 막고 큐·모델 동시 실행을 4로 제한한다. 격리 인증 사본으로 실제 병렬 모델 호출과 토큰 갱신 경쟁을 검증한다. 시험 Discord에는 합성 대화와 시험용 닉네임만 쓰고 실제 게시의 이름·중복 구분·알림 없음·장문 분할을 확인한다. 버전·프롬프트 버전·검증기·변경 기록·롤백을 갱신한다.

## 통과 기준

- `D9`: 실제 게시에서 화자명의 P1/P2 대신 기대한 표시 이름을 확인하고 개명·동명이인·멘션 안전성을 검증한다.
- `D10`: 4개 병렬 모델 호출 상한·인증 갱신 경쟁 안전성, 후보/서비스 SHA, 실제 게시·롤백, 단계별 C/E/D 원격 증거와 필요한 CI를 확인한다.

결과·동일 구현 SHA를 [검증 목록](TEST_MATRIX.md)에 남긴다. **이 단계만의 C(구현) → E(증거) → D(종료)를 각각 commit·GitHub push하고 원격 포함 관계·필요 CI를 확인해야 DONE**이다. 실패·미실행은 PASS로 세지 않는다. [공통 Git 규칙](../GIT_WORKFLOW.md)을 따른다.
