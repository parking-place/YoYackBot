# 요약 화자 표시 이름 계약

요약 요청에서 선택된 일반 사용자 메시지만 사용한다. 화자 구분의 내부 키는 작성자 ID에 해당하는 `P1`, `P2`이지만 외부 게시 문장과 운영 지표에는 ID와 내부 키를 표시하지 않는다. 한 작성자의 **선택 범위 안에서 가장 최근의 유효한 Discord 표시 이름**을 사용한다. 마지막 메시지의 이름이 비어 있거나 유효하지 않으면 범위 안의 이전 유효한 이름을 쓴다. 선택 범위에 이름이 없으면 `사용자`를 쓴다. 서버 밖의 사용자 조회나 현재 프로필 추측은 하지 않는다.

입력 메시지는 시각과 메시지 ID 순으로 정렬한다. 같은 안전한 이름이 여러 작성자에게 귀속되면 최초 발언 순으로 `이름 (1)`, `이름 (2)`를 붙여 전원 구분한다. 범위 중 개명한 한 작성자는 최근 유효한 이름 하나로 묶는다. 다른 요청과 다른 서버는 별도의 매핑을 만든다. 삭제되어 선택 범위에 남지 않은 발언·작성자는 표시 이름 결정에 참여하지 않는다.

표시 이름은 NFC 정규화 후 한 줄로 공백을 정리한다. 제어 문자·방향 전환 문자를 제거하고 최대 32문자로 줄인다. Discord 멘션과 Markdown 문법 문자는 읽기 쉬운 전각 문자로 치환한다. `unknown`, `P1` 같은 내부 키 모양, 빈 문자열은 유효한 표시 이름으로 간주하지 않는다. 이 경우 `사용자`를 쓴다. 원문 이름을 로그나 GitHub 검증 결과에 기록하지 않는다. 게시 시에도 Discord 멘션을 비활성화하고 결과 본문의 멘션을 무력화한다.

이 문서는 [P1](01-contract.md)에서 정한 데이터·안전 계약이다. 실제 모델 입력 연결과 게시 출력 검사는 P2~P5에서 단계별로 확인한다.
