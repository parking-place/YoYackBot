# 1.0.0d-P2 — 안정적 화자 매핑

상태: **IN_PROGRESS**. 검사: `D3/D4`. P1의 원격 완료 후 개발 LXC에서 수행한다.

## 작업

내부 P1/P2 화자 키는 귀속 추적용으로 유지하고 출력 이름 매핑을 모델 입력에 명시한다. 한 사람이 범위 중 이름을 바꿔도 같은 화자로 취급하고, 동명이인은 사용자에게 구별 가능한 짧은 접미표기를 부여한다. author ID는 요청 내부에서만 쓰며 게시 문장이나 운영 지표에 넣지 않는다.

## 통과 기준

- `D3`: 대화 순서와 닉네임 변경 뒤에도 같은 사람의 의견이 한 표시 이름으로 귀속되는지 확인한다.
- `D4`: 동명이인·삭제 메시지·빈 이름·다른 Guild 동시 요청에서 매핑 충돌이나 ID 노출이 없는지 확인한다.

결과·동일 구현 SHA를 [검증 목록](TEST_MATRIX.md)에 남긴다. **이 단계만의 C(구현) → E(증거) → D(종료)를 각각 commit·GitHub push하고 원격 포함 관계·필요 CI를 확인해야 DONE**이다. 실패·미실행은 PASS로 세지 않는다. [공통 Git 규칙](../GIT_WORKFLOW.md)을 따른다.
