## 작업

`summary_prompt.py`에서 `speaker(P1)`은 내부 참조이고 출력은 검증된 `display_name`을 쓰도록 명시한다. 화자명으로 `P1`/`P2`가 남는 경우를 탐지하고 안전하게 정정하거나 재생성한다. 인용문·코드·일반 문장 안의 `P1`을 무차별 치환하지 않으며 근거 없는 이름을 추측하지 않는다. 기존 멘션 비활성화와 장문 분할도 유지한다.

## 통과 기준

- `D5`: 고정 모델 설정의 합성 대화 20건에서 화자명이 실제 표시 이름이고 P1/P2가 화자명으로 게시되지 않는지 확인한다.
- `D6`: 불명확한 귀속·모델 실패·긴 출력에서 잘못된 치환 없이 재생성/명시적 실패로 끝나는지 확인한다.
