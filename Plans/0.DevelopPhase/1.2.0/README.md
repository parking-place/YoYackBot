# 1.2.0 — `/말투`·답장으로 범위 지정·떡밥 한줄 평가 다양화

- 상태: **PLANNED** (계획 문서만 작성; 기능 구현·배포 전)
- 단계 수: **6단계**
- 선행 버전: 출시된 [1.1.3a](../1.1.3a/README.md)(`v1.1.3a`, 2026-10-01)

## 목표

1. **`/말투`**: 관리자·봇 관리 역할이 서버별 말투 프롬프트를 보고(기본값이 채워져 있음) 고쳐 저장한다. 사실·신뢰 경계·금지선은 고칠 수 없다.
2. **답장으로 범위 지정**: 메시지에 답장으로 `!!요약좀`을 쓰면 그 메시지부터 지금까지 요약한다.
3. **떡밥 한줄 평가 다양화**: “화제가 튀어 정신없다”류를 금지하고, 후보 10개를 한 번에 만든 뒤 luna가 심사해 1개를 고른다.

방식·화면 흐름·검사·호출 수·실패 대체·사용자 결정은 [계약](CONTRACT.md)에 있다.

## 검증 방침

- 평가 줄: 실제 모델 12건에서 금지 소재 0건, 서로 다른 소재(같은 틀 반복 없음), 심사가 고른 번호가 유효, 사실·화자 오류 0, 요약 소요 시간 증가 기록.
- `/말투`: 서버 말투 2종(예: 점잖은 보고서체, 사극체)으로 실제 모델 4건에서 말투 반영·금지선 유지 확인. 위험 표현 저장 거절은 합성 시험.
- 답장 범위: 합성 시험으로 경계(같은 채널·최대 기간·최대 개수·삭제된 대상·범위 옵션 동시 사용)를 확인하고 시험 Discord에서 사용자가 확인한다.
- 실제 대화·닉네임·서버 이름은 공개 문서에 옮기지 않고 합성 예시만 쓴다. 서버 말투 내용은 로그·문서에 남기지 않는다.

버전 표기는 [버전 대응표](../PATCH_VERSIONING.md)대로 계획·태그 `1.2.0` / `v1.2.0`, Python 패키지 `1.2.0`이다.
