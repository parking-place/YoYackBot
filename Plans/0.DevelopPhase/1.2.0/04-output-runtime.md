## 선행 조건

P3의 종료 D가 원격에 반영됐는지 확인한다. 네 결함 모두 합성 대역으로 재현됐지만 실제 모델 출력 빈도·실제 인증 성공을 검증한 결과는 아니다. 현행 본문/평가 호출 상한 3회, 기본 말투·밀도·추가 요청 정책을 유지한다. 1.3.0의 후보 생성·심사·말투 저장을 이 단계에 넣지 않는다.

F10의 메시지 M 키가 붙은 뒤 최종 출력 검사에 같은 누출 방지를 연결하는 것은 P6 인수 항목이다. 현재 단계는 출력 검증의 일관된 경로를 제공한다. 새 모델 호출 단계나 health마다 실제 모델을 호출하는 준비 검사는 추가하지 않는다.

## 실패 경계

- 본문이 없으면 formatter의 뒤늦은 예외까지 넘기지 않는다. 정상 성공·게시·성공 쿨타임을 만들지 않는다.
- 평가 생성 실패/검증 실패는 검증된 본문을 망가뜨리지 않는다. 반대로 불량한 본문을 평가가 정상이라는 이유로 게시하지 않는다.
- 공통 검사와 최종 합성 순서를 고정한다. 출력 검증이 재시도될 때 현행 총 호출 상한 3회를 넘지 않는다.
- 준비 단계가 수락한 executable을 실행 단계가 상대 경로라는 이유로 다시 거절하지 않게 한다. 경로 해석·실행 파일 검증과 실제 계정 인증 유효성은 서로 다른 결과로 기록한다.
- 실행파일 오류·인증 형태 오류에 경로·원문·비밀값을 공개 응답이나 로그로 흘리지 않는다. 합성 파일로 시험하고 운영 인증을 고치거나 덮어쓰지 않는다.
