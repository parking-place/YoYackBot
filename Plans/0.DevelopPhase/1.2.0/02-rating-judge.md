## 선행 조건·작업

[P1](01-rating-candidates.md)의 원격 완료 뒤 요약 엔진의 평가 흐름을 바꾼다: 요약 본문(+필요 시 전체 재생성) → 후보 호출 1번 → 코드 거르기 → 심사 호출 1번(같은 고정 모델, 후보 목록·최근 평가·기준을 주고 `비슷함: 번호들` / `선택: 번호`로 답하게 함 — 첫 기준은 “주제가 바뀌어 정신없다”와 비슷한지) → 고른 후보를 붙이고 최근 평가에 저장. 모두 비슷하거나 유효 0개면 후보 1회 재생성. 요약 본문의 평가 줄은 버린다. [계약](CONTRACT.md)의 실패 대체(요약 본문 평가 → 첫 후보 → 평가 없음), `평가 빼줘` 시 후보·심사 생략, 호출 상한 5번, 지표 `rating=picked/regenerated/fallback_summary/fallback_first/missing/skipped`·`rating_candidates`·`rating_similar`를 구현한다. 기존 “평가 줄만 다시 만들기”는 후보 생성으로 대체한다.

## 검증·완료 기준

- `T120-P2-A`: 합성 대역으로 정상(후보 10 → 심사 번호 → 그 후보), 후보 일부 무효, 후보 호출 실패, 유효 후보 0, 심사 실패·범위 밖 번호·“비슷함”에 든 번호를 선택·형식 어긋남, 모두 비슷함 → 재생성, `평가 빼줘`, 화자/비하어 재생성과 겹침에서 결과·지표·호출 수(5번 이하)가 기대대로다. 게시된 평가만 최근 평가에 저장된다.
- `T120-P2-B`: 고른 평가 줄이 메시지 마지막에 붙고 금지 소재가 없으며, 이모지 제거·거절 안내·주제 비평·밑줄 지표가 그대로다. 로그에 후보·평가 문장이 없다. 전체 회귀 통과.
