- 상태: **PLANNED** · 검사: `T120-P6-A/B` · 환경: 개발 LXC, 시험 Discord, GitHub CI

## 선행 조건·작업

[P1~P5](STATUS.md)의 원격 완료를 확인한다. 도움말은 그대로 둔다([계약](CONTRACT.md) 4절). `docs/channel-settings.md`에 `/말투`와 답장 범위를, README·`CHANGELOG`·`docs/upgrade-rollback-1.2.0.md`(복귀 대상 `v1.1.3a`, wheel `1.1.3.1`, checkout `d51c72a`, schema 5 유지 — 복귀하면 서버 말투·최근 평가 표는 무시되고 기본 말투·이전 평가 방식으로 돌아감)를 갱신한다. 패키지·`VERSION`을 `1.2.0`으로, 버전 대응표와 저장소 검증기에 1.2.0의 6단계·12검사 집계를 넣는다.

정확한 후보 SHA로 LXC 자동 회귀를 돌린 뒤, 진행 중 요약이 없음을 확인하고 이전과 같은 절차로 배포한다. 이전 `v1.1.3a` wheel로의 복귀 호환성은 서버 말투·최근 평가 표가 있는 격리 합성 DB로 확인한다.

배포 뒤 사용자가 시험 채널에서 확인한다: `/말투` 보기·수정·기본값으로, 바뀐 말투의 `!!요약좀`, 메시지에 답장으로 `!!요약좀`, 떡밥 한줄 평가(여러 번 요약해 겹치지 않는지). 확인하지 못한 항목은 `NOT_RUN`으로 남긴다.

- `T120-P6-B`: 후보·서비스 SHA 대조, 시험 Discord 사용자 확인과 서비스 로그(`tone_saved`·`tone`·`rating`·`rating_candidates`) 대조, 배포·복귀·비밀정보 비노출·P1~P5 원격 증거, 병합 후 `main` CI를 기록한다.
