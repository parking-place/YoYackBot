# 1.2.0-P3 — 답장으로 범위 지정

- 상태: **PLANNED** · 검사: `T120-P3-A/B` · 환경: 개발 LXC, 합성(Discord 연결 없음)

## 선행 조건·작업

[P2](02-rating-judge.md)의 원격 완료 뒤 [계약](CONTRACT.md) 2절대로 답장 범위를 만든다. 명령 메시지의 답장 대상(같은 채널)을 캐시나 Discord에서 찾아 시각을 얻고, 그 시각부터 지금까지의 시간 범위로 요청을 만든다. 길이·추가 요청은 그대로 해석하고, 범위 옵션이 함께 있으면 답장을 우선하고 기간·개수는 무시했다는 한 줄을 시작 안내 아래 더한다. 최대 기간·최대 개수·대상 없음·다른 채널을 안내 문구(이모지, 하오체)로 거절한다. 시작·진행 중 안내에 “답장한 메시지부터”를 쓴다.

## 검증·완료 기준

- `T120-P3-A`: 답장 + 없음/`길게`/`자세히`/추가 요청이 대상 시각부터의 범위로 요약되고, 대상 메시지가 포함되며, 시작·진행 중 안내 문구가 기대대로다. 답장이 아닌 명령은 지금과 같다.
- `T120-P3-B`: 답장 + 범위 옵션(답장 우선·무시 안내), 최대 기간 초과, 최대 개수 초과, 대상 삭제·조회 실패, 다른 채널 대상, 주시 안 함·준비 안 됨·쿨타임·진행 중이 기대대로 안내된다. 문구 목록 시험(이모지)이 새 안내를 포함한다. 전체 회귀 통과.
