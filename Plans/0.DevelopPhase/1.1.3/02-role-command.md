# 1.1.3-P2 — `/관리권한 설정` 명령

- 상태: **PUSH_PENDING** · 검사: `T113-P2-A/B` · 환경: 개발 LXC, 합성 상호작용(Discord 연결 없음)

## 선행 조건·작업

[P1](01-manager-roles.md)의 원격 완료 뒤 공통 도우미로 `/관리권한` 그룹의 `설정` 명령을 만든다. 본인에게만 보이는 설정 화면(현재 목록, 역할 추가·제거 선택, 전체 해제, 저장, 취소, 120초)을 `/채널 설정`과 같은 모양으로 만들고, `@everyone`·봇/연동 관리 역할·서버에 없는 역할은 고를 수 없게 한다. 저장 시 동시 수정을 감지하고 `manager_roles_saved at=… count=…`를 남긴다.

## 검증·완료 기준

- `T113-P2-A`: 관리자와 관리 역할 사용자가 화면을 열고 역할을 추가·제거·전체 해제·저장할 수 있고, 저장 뒤 그 역할의 사용자가 `/채널 설정`을 쓸 수 있으며, 빼면 쓸 수 없다. 그 밖의 사용자·DM은 거절된다.
- `T113-P2-B`: `@everyone`·관리 역할(managed)·없는 역할 선택이 거절되고, 다른 사람·다른 서버의 조작, 동시 수정, 제한 시간 만료가 기대대로다. 로그에는 시각·역할 수만 있다. 전체 회귀 통과.

같은 SHA의 결과를 [증거 양식](../EVIDENCE_TEMPLATE.md)에 남기고 구현 C → 증거 E → (E CI 성공 확인) → 종료 D를 각각 commit·GitHub push·원격 확인한다. [공통 Git 규칙](../GIT_WORKFLOW.md)을 따른다.
