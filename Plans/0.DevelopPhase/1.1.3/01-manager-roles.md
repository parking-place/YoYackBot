# 1.1.3-P1 — 관리 역할 저장과 실행 시 판정

- 상태: **PUSH_PENDING** · 검사: `T113-P1-A/B` · 환경: 개발 LXC, 합성 상호작용(Discord 연결 없음)

## 선행 조건·작업

`v1.1.2a` 출시와 `main` 통합을 확인한다. [계약](CONTRACT.md)대로 서버별 관리 역할 저장소(SQLite 선택 테이블 `manager_roles`, schema 5 유지, 버전 비교로 동시 수정 감지)를 만든다. 슬래시 명령어 공통 등록 도우미에 실행 전 판정(관리자 또는 채널 관리 권한, 또는 이 서버의 관리 역할 보유)을 넣고 `/채널 설정`과 그 설정 화면에 적용한다. 서버에서 나가면 관리 역할을 지우고, 설정 전용 백업·복원에 관리 역할을 넣으며(이전 백업 파일 호환), 서비스 호스트 운영 명령 `manager-roles`(list/set/clear)를 추가한다.

## 검증·완료 기준

- `T113-P1-A`: 판정 표의 모든 칸(관리자·채널 관리·관리 역할 보유·역할 없음·DM)이 `/채널 설정` 실행과 설정 화면 조작에서 기대대로이고, 조작 도중 역할을 잃으면 거절된다. 실제 클라이언트 명령어 트리의 모든 명령어가 공통 판정을 거친다(도우미 없이 등록하면 실패하는 전수 시험).
- `T113-P1-B`: 저장소가 서버별로 분리되고 동시 수정을 감지하며, schema가 5로 유지되고 `v1.1.2a` 코드가 이 DB를 읽는다(격리). 백업·복원이 관리 역할을 왕복하고 이전 백업 파일도 복원한다. 운영 명령이 서비스 계정 권한에서 동작한다. 전체 회귀 통과.

같은 SHA의 결과를 [증거 양식](../EVIDENCE_TEMPLATE.md)에 남기고 구현 C → 증거 E → (E CI 성공 확인) → 종료 D를 각각 commit·GitHub push·원격 확인한다. [공통 Git 규칙](../GIT_WORKFLOW.md)을 따른다.
