# 1.1.3 — 슬래시 명령어 관리자 기본값과 `/관리권한 설정`

- 상태: **IN_PROGRESS** (P1 진행 중)
- 단계 수: **3단계**
- 선행 버전: 출시된 [1.1.2a](../1.1.2a/README.md)(`v1.1.2a`, 2026-10-01)

## 목표

1. 슬래시 명령어를 기본적으로 **관리자만** 쓰게 되돌린다.
2. 관리자 또는 봇 관리 역할의 사용자가 **`/관리권한 설정`**으로 서버 역할 가운데 봇 관리 역할을 고르고, 그 역할의 사용자도 슬래시 명령어를 쓰게 한다. 이후 추가되는 슬래시 명령어도 같은 판정을 따른다.

Discord 제약(봇 토큰으로는 명령어별 역할 허용을 바꿀 수 없음)과 그에 따른 실행 시 판정 방식, 판정 표, 저장·운영, 사용자 결정은 [계약](CONTRACT.md)에 있다.

## 검증 방침

- 합성 상호작용 시험으로 판정 표의 모든 칸과 명령어 트리 전수 판정을 확인한다. 실제 모델 호출은 없다.
- DB는 schema 5를 유지하고, 이전 릴리스(`v1.1.2a`) 코드가 관리 역할 표가 있는 DB를 그대로 읽는지 격리 시험한다.
- 실제 Discord·서버·역할 이름은 공개 문서에 옮기지 않고 합성 이름만 쓴다. 배포 전 진행 중 요약이 없음을 확인한다.
- 실제 시험 Discord 확인은 P3 배포 뒤 사용자가 직접 한다. 확인하지 못하면 `NOT_RUN`.

버전 표기는 [버전 대응표](../PATCH_VERSIONING.md)대로 계획·태그 `1.1.3` / `v1.1.3`, Python 패키지 `1.1.3`이다.
