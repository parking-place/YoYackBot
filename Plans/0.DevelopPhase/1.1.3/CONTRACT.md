# 1.1.3 슬래시 명령어 관리자 기본값·관리 역할 계약

이 문서는 구현 목표다. 현재 제품 동작이나 시험 PASS를 뜻하지 않는다. 출시된 `v1.1.2a`(2026-10-01) 코드를 기준으로 작성했다.

## 요청 (2026-10-01)

1. 슬래시 명령어를 **기본적으로 모두 관리자만** 쓰게 되돌린다(1.1.2a의 “애플리케이션 명령어 사용 권한이 있으면 누구나”를 롤백).
2. 관리자 또는 관리 권한이 있는 역할의 사용자가 **`/관리권한 설정`**으로 서버의 역할 가운데 **봇 관리 역할**을 고른다. 이후 그 역할을 가진 사용자도 슬래시 명령어를 쓸 수 있다.

## Discord 제약과 방식

- Discord의 명령어별 역할 허용(서버 설정 → 연동)은 **봇 토큰으로 바꿀 수 없다**(사용자 OAuth 권한이 필요). 그래서 봇이 “이 역할에게 명령어를 보여 줘”를 Discord에 직접 설정할 수 없다.
- 따라서 **실행 시 봇이 판정**한다: 명령어 실행·설정 화면 조작 때마다 사용자가 ① 관리자이거나 ② 이 서버의 봇 관리 역할을 가지고 있는지 확인하고, 아니면 “이 명령은 관리자나 봇 관리 역할만 쓸 수 있소.”로 거절한다(본인에게만 보이는 답).
- 그러려면 관리 역할 사용자에게도 명령어가 **보여야** 하므로, 명령어 등록의 기본 권한은 `애플리케이션 명령어 사용`으로 두고(누구에게나 보임) 실제 허용은 봇이 판정한다(사용자 결정 기본안). 서버 관리자가 연동 화면에서 해 둔 개별 제한은 Discord가 먼저 적용한다.
- 이후 추가되는 슬래시 명령어도 같은 판정을 거치도록 1.1.2a의 공통 등록 도우미에 **실행 전 판정**을 넣고, 명령어 트리 전수 시험으로 모든 명령어가 판정을 거치는지 확인한다.

## 판정 규칙

| 사용자 | `/채널 설정` 등 슬래시 명령어 | `/관리권한 설정` |
|---|---|---|
| 서버 관리자(Administrator) 또는 채널 관리 권한(1.1.2 이전 기준) | 사용 가능 | 사용 가능 |
| 이 서버의 봇 관리 역할을 가진 사용자 | **사용 가능** | **사용 가능** |
| 그 밖의 사용자 | 거절(본인에게만 안내) | 거절 |
| DM·서버 밖 | 거절 | 거절 |

- 판정은 상호작용 시점의 사용자 역할로 한다. 설정 화면(버튼·선택)도 조작할 때마다 다시 판정하고(역할을 잃으면 그 화면도 쓸 수 없음), 화면은 연 본인만 조작한다(1.1.2a 그대로).

## `/관리권한 설정`

- 본인에게만 보이는 설정 화면: 현재 봇 관리 역할 목록, **역할 추가**(역할 선택, 한 번에 최대 25개), **역할 제거**, **전체 해제**, **저장**, **취소**. 제한 시간 120초. `/채널 설정`과 같은 모양·동작.
- 고를 수 없는 역할: `@everyone`(사실상 전원 허용이 됨), 봇·연동이 관리하는 역할(managed). 서버에 없는 역할 ID는 저장 때 거절한다.
- 동시 수정 감지(버전 비교)와 “다른 사람이 설정을 바꾸었소” 안내는 `/채널 설정`과 같다.
- 관리 역할 사용자가 자기 역할을 빼서 잠길 수 있다. 서버 관리자는 언제나 다시 설정할 수 있다.
- 저장 로그: `manager_roles_saved at=<UTC 시각> count=<역할 수>`(사용자 ID·역할 이름·서버 ID 없음).

## 저장·운영

- 서버별 관리 역할을 기존 SQLite에 **선택 테이블**(`manager_roles`)로 둔다. schema 번호(5)는 올리지 않아 이전 릴리스 코드가 그대로 DB를 읽을 수 있다(주시 채널 백필 표와 같은 방식). 봇이 서버에서 나가면 그 서버의 관리 역할을 지우고, 삭제된 역할은 판정에서 무시하며 다음 저장 때 정리한다.
- 설정 전용 백업·복원(`backup-settings`·`restore-settings`)에 관리 역할을 포함한다(이전 백업 파일도 읽을 수 있게).
- 서비스 호스트 전용 운영 명령 `manager-roles`(목록 보기·설정·비우기)를 둔다. 잠김 복구나 초기 설정을 위해 서비스 계정으로만 실행하며, Discord 명령이 아니다.

## 안내 문구

- 도움말은 바꾸지 않는다(1.1.2a 사용자 문안 유지, 사용자 결정 기본안). `docs/channel-settings.md`에 판정 규칙·`/관리권한 설정`·연동 화면과의 관계를 적는다.

## 사용자 결정 (계획 게시 시점, 확인 필요)

| 항목 | 기본안 | 다른 선택 |
|---|---|---|
| “관리자” 기준 | **서버 관리자 또는 채널 관리 권한**(1.1.2 이전과 같음) | 서버 관리자(Administrator)만 |
| 명령어 노출 | **모두에게 보이고 실행 시 봇이 판정**(관리 역할 사용자도 보여야 하므로) | 관리자에게만 보이게(관리 역할 사용자는 서버 관리자가 연동 화면에서 그 역할에 따로 허용해야 보임) |
| `/관리권한 설정` 사용 | **관리자와 봇 관리 역할 모두** | 관리자만 |
| 변경 기록 | **시각과 역할 수만** | 사용자 ID까지 |
| 도움말 | **그대로** | `/관리권한 설정` 한 줄 추가 |
