# 1.0.0b-P1 — 실패 분류·재현

상태: **PUSH_PENDING**. 검사: `B1/B2`. 1.0.0a의 원격 완료 후 개발 LXC에서 수행했다.

## 작업

운영 `summary_request`의 원문 없는 집계를 기준선으로 남기고 `CodexRunError`, `InputFileError`, `QueueWaitExpired`를 구분한다. 선택 건수, 입력 바이트, 수집/모델 슬롯 대기/모델 실행 시간과 실패 종류만 안전하게 측정한다. 298/858/574건의 모델 오류 원인을 추정으로 확정하지 않는다. 격리 DB와 합성 대화로 101/150/200/300/500/858/1000건을 재현한다.

## 통과 기준

- `B1`: 각 건수의 실패 지점이 수집·입력·모델·대기열 중 어디인지 같은 SHA의 로그와 시험에서 구분된다.
- `B2`: 원문·닉네임·사용자/채널 ID·토큰이 새 지표에 포함되지 않는지 확인한다.

결과·동일 구현 SHA를 [검증 목록](TEST_MATRIX.md)에 남긴다. **이 단계만의 C(구현) → E(증거) → D(종료)를 각각 commit·GitHub push하고 원격 포함 관계·필요 CI를 확인해야 DONE**이다. 실패·미실행은 PASS로 세지 않는다. [공통 Git 규칙](../GIT_WORKFLOW.md)을 따른다.
