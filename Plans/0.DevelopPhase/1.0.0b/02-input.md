# 1.0.0b-P2 — 대량 입력·모델 한도

> 이 계획은 [1.0.0b-1](../1.0.0b-1/README.md)로 **폐기·대체**됐다. 후보 코드만 push했고 증거 E/종료 D 없이 중단했다.

상태: **STOPPED**. 검사: `B3/B4`는 이 버전에서 완료되지 않았다.

## 작업

현재 `max_input_bytes=1,000,000`, 모델 실행 제한 120초, History 페이지/건수 상한의 실제 경계를 확인한다. 확인된 원인만 수정한다. 필요하면 입력을 시간순 의미 단위로 나누어 중간 요약과 최종 요약을 연결하되, 화자 귀속·포함 범위를 보존한다. 조용한 절단/표본 요약을 전체 요약으로 게시하지 않고 작업량 상한을 둔다.

## 통과 기준

- `B3`: 101~1000건 합성 자료의 선택 건수·실제 포함 건수·입력 바이트·출력을 대조해 100건 초과 성공을 확인한다.
- `B4`: 긴 본문·Unicode·삭제/편집 메시지에서 중간 처리의 누락·중복, 시간순 붕괴, 원문 로그 유출이 없는지 확인한다.

결과·동일 구현 SHA를 [검증 목록](TEST_MATRIX.md)에 남긴다. **이 단계만의 C(구현) → E(증거) → D(종료)를 각각 commit·GitHub push하고 원격 포함 관계·필요 CI를 확인해야 DONE**이다. 실패·미실행은 PASS로 세지 않는다. [공통 Git 규칙](../GIT_WORKFLOW.md)을 따른다.
