# 1.0.0b-P5 — 실패 정리·재시도

상태: **PLANNED**. 검사: `B9/B10`. P4의 원격 완료 후 개발 LXC에서 수행한다.

## 작업

대량 요청의 입력 초과·모델 오류·큐 만료를 운영상 분류한다. 실패 뒤 동일 채널 작업 잠금, 임시 파일, 중간 산출물, 쿨타임을 정리하고 새 요청을 허용한다. 전체 게시 완료 전에는 성공으로 기록하지 않는다. 권한 거부·계정 한도·입력 한도 같은 비재시도 오류를 자동 무한 재시도하지 않는다.

## 통과 기준

- `B9`: 각 실패를 주입한 뒤 잠금 해제·파일 정리·쿨타임 미적용·다음 요청 성공을 확인한다.
- `B10`: 동일 채널 중복·다른 채널 독립 작업·1.0.2의 계획된 시작 안내와 응답 상태가 충돌하지 않는지 확인한다. 초기 수집의 부분 상태에서도 결과 범위를 과장하지 않는다.

결과·동일 구현 SHA를 [검증 목록](TEST_MATRIX.md)에 남긴다. **이 단계만의 C(구현) → E(증거) → D(종료)를 각각 commit·GitHub push하고 원격 포함 관계·필요 CI를 확인해야 DONE**이다. 실패·미실행은 PASS로 세지 않는다. [공통 Git 규칙](../GIT_WORKFLOW.md)을 따른다.
