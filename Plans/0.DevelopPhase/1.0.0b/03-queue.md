# 1.0.0b-P3 — 모델 대기열 시간 정책

상태: **PLANNED**. 검사: `B5/B6`. P2의 원격 완료 후 개발 LXC에서 수행한다.

## 작업

`job_queue.py`의 전역 모델 동시성 1, 대기 슬롯 4, 60초 `YOYACK_QUEUE_WAIT_SECONDS`와 수집 대기를 분리한다. 실제 지연 분포를 측정하고 긴 모델 작업 뒤 정상 요청이 불필요하게 만료되면 유한한 대기시간 상향을 시험한다(180초는 검증 후보값이며 확정값이 아니다). 모델 실행 제한은 모델 지연 증거가 있을 때만 조정한다. 취소·종료·포화 시 슬롯을 반환한다.

## 통과 기준

- `B5`: 120초 모델 실행 뒤 두 번째 요청이 60초에서 만료되던 시나리오와 새 정책의 성공/명시적 만료를 시간 제어 시험으로 비교한다.
- `B6`: 포화·취소·서비스 종료·채널 교차 요청에서 무한 대기나 슬롯 누수가 없는지 확인한다.

결과·동일 구현 SHA를 [검증 목록](TEST_MATRIX.md)에 남긴다. **이 단계만의 C(구현) → E(증거) → D(종료)를 각각 commit·GitHub push하고 원격 포함 관계·필요 CI를 확인해야 DONE**이다. 실패·미실행은 PASS로 세지 않는다. [공통 Git 규칙](../GIT_WORKFLOW.md)을 따른다.
