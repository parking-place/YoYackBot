# 1.0.0b-P6 — 대량 요청·초기 수집 통합·출시

> 이 계획은 [1.0.0b-1](../1.0.0b-1/README.md)로 **폐기·대체**됐다. 이 버전의 출시·태그는 만들지 않는다.

상태: **SUPERSEDED**. 검사: `B11/B12`는 이 버전에서 미실행이다.

## 작업

P1~P5 원격 DONE 뒤 101/150/200/300/500/858/1000건 합성 대화와 시험 Discord의 개인 대화 없는 대량 요청을 같은 SHA에서 검증한다. 처음 주시한 채널의 30일 이내 기록 초기 수집, 실시간 저장, 수집 중 대기 안내, 시작·완료 알림과 재시작 후 재개도 함께 확인한다. 성공률, p95 수집/대기/실행 시간, 실제 게시 여부, 유한 상한 안내를 기록한다. 모델 오류와 대기열 만료를 따로 보고하고 버전·검증기·배포·롤백을 갱신한다.

## 통과 기준

- `B11`: 100건 초과 여러 크기의 게시 성공과 상한 초과의 정확한 실패 안내를 확인한다. 초기 수집이 끝난 채널의 캐시 조회와 부분 수집 채널의 History 보충을 구분한다.
- `B12`: 배포 후보·서비스 SHA, 실제 시험 게시 여부, 초기 수집 재개·롤백과 단계별 C/E/D·필요 CI를 확인한다.

결과·동일 구현 SHA를 [검증 목록](TEST_MATRIX.md)에 남긴다. **이 단계만의 C(구현) → E(증거) → D(종료)를 각각 commit·GitHub push하고 원격 포함 관계·필요 CI를 확인해야 DONE**이다. 실패·미실행은 PASS로 세지 않는다. [공통 Git 규칙](../GIT_WORKFLOW.md)을 따른다.
