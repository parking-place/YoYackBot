# 1.4.3-P4 — 실제 모델 평가

- 상태: **PUSH_PENDING** · 검사: `T143-P4-A/B` **PASS** ([증거](../evidence/1.4.3-P4.md)) · 환경: 개발 LXC, 실제 모델(합성 글·합성 이미지), 사용자 예시 확인

## 작업

P3 완료 SHA로 합성 식단(만든 음식 그림과 글)을 실제 모델에 붙여 평가를 돌린다. 주간 사용량을 전후로 기록하고 70% 아래면 멈춘다.

## 검증·완료 기준

- `T143-P4-A`: 사진이 모델에 실제로 전달되고(사진 속 음식이 평가에 반영), 검사 통과율·비하어 0·없는 음식 지어내기 0, 사람 수·순서가 맞고, 호출 시간이 제한 안이다. 서버 말투 2종(기본·프리셋)에서도 같다.
- `T143-P4-B`: 평가 예시를 사용자가 확인한다.
