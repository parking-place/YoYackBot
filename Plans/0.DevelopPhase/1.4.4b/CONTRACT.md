# 1.4.4b 계약 — 식단·운동 평가에 GPT-6.1 Terra

이 문서는 구현 목표다. 기준 코드는 출시된 `v1.4.4a`(`cb928d8`)이다. “사용자 결정”은 2026-10-28 사용자 요청이고, “기본안”은 그 밖의 세부를 개발자가 정한 것이다.

## 1. 호출별 모델

- 식단 평가 호출(`diet`, 사진 첨부)과 주간 훈수 호출(`diet_week`, 텍스트만)은 `gpt-6.1-terra`로 실행한다(사용자 결정). Codex CLI 0.164.0의 모델 목록에 있고 사진 입력·추론 강도 low–ultra를 지원한다(2026-10-28 봇 계정으로 확인).
- 추론 강도는 지금처럼 서비스 설정값(`medium`)이고, 시간 제한도 그대로다(식단 평가 300초, 주간 훈수 기본값). 다른 모든 호출과 서비스 설정 모델(`YOYACK_CODEX_MODEL`, 준비 점검의 모델 확인)은 `gpt-6-luna` 그대로다(사용자 결정).
- 모델은 호출 단위로만 바꾼다(1.3.3 호출별 추론 강도와 같은 방식). 허용 모델은 `gpt-6-luna`·`gpt-6.1-terra` 두 개뿐이다(기본안).

## 2. 대체

- 계정이 Terra를 쓸 수 없어 CLI가 모델 오류(`model`)를 내면, 같은 요청을 Luna로 한 번 더 실행하고 경고 로그(`codex_model_fallback call=…`)만 남긴다(기본안). 사용량 한도·시간 초과 같은 다른 실패는 지금처럼 처리한다.
- 프롬프트·검사·게시 모양·DB·환경은 바뀌지 않는다. 복귀 대상은 `v1.4.4a`다.
