# 1.0.0a-P4 — 명령·도움말

상태: **IN_PROGRESS**. 검사: `A7/A8`. P3의 원격 완료를 확인한 뒤 개발 LXC에서 수행한다.

## 작업

`parser.py` 도움말에 `기간 요약은 최대 30일까지 가능하오.`와 `!!요약좀 30일` 예를 넣는다. 실제 설정이 30일보다 낮을 때 도움말/오류 안내가 거짓말하지 않도록 실효 상한을 사용한다. 개수 상한과 기간 상한을 구별한다.

## 통과 기준

- `A7`: `도움`, `30일`, `31일`, `5주`, `100개`의 파싱·응답을 같은 설정에서 확인한다.
- `A8`: 개발 LXC의 합성 Discord 전송에서 주시·미주시 경계, 도움말 표시와 잘못된 범위 안내, 멘션 비활성화를 확인한다. 실제 시험 Discord 게시 여부는 별도 기록한다. 사용자가 앞서 실제 시험 채널 결과 미확인 상태의 진행을 허용했으므로, 미확인 게시를 PASS로 부르지 않고도 합성 검증이 통과하면 다음 단계로 진행한다.

결과와 동일 구현 SHA를 [검증 목록](TEST_MATRIX.md)에 남긴다. **이 단계만의 구현 C → 증거 E → 종료 D를 각각 commit·GitHub push하고 원격 포함 관계 및 필요한 CI를 확인해야 DONE**이다. 실패·미실행은 PASS로 세지 않는다. [공통 Git 규칙](../GIT_WORKFLOW.md)을 따른다.
