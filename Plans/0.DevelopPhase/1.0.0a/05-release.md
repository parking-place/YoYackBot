# 1.0.0a-P5 — 운영 회귀·출시

상태: **PLANNED**. 검사: `A9/A10`. P4의 원격 완료를 확인한 뒤 개발 LXC에서 수행한다.

## 작업

P1~P4 원격 DONE 뒤 같은 SHA의 30일 보존/요약/도움말/정리/복원/권한 회귀를 개발 LXC에서 실행한다. 30일 확대의 DB·백업 용량과 7일로 되돌릴 때 삭제될 자료를 문서화한다. `VERSION`, 패키지, 검증기, 변경 기록과 배포·롤백을 [버전 대응표](../PATCH_VERSIONING.md)에 맞춘다.

## 통과 기준

- `A9`: 합성 30일 자료와 자동 회귀, 운영 설정의 실효 30일을 동일 후보 SHA에서 확인한다.
- `A10`: 배포·롤백, 실제 Discord 게시 여부, P1~P4 C/E/D 원격 증거와 필요한 CI를 확인한다.

결과와 동일 구현 SHA를 [검증 목록](TEST_MATRIX.md)에 남긴다. **이 단계만의 구현 C → 증거 E → 종료 D를 각각 commit·GitHub push하고 원격 포함 관계 및 필요한 CI를 확인해야 DONE**이다. 실패·미실행은 PASS로 세지 않는다. [공통 Git 규칙](../GIT_WORKFLOW.md)을 따른다.
