# 1.4.1b 계약 — 처형 로그 문구·`/처형도움`

이 문서는 구현 목표다. 기준 코드는 출시된 `v1.4.1`(`18ec31e`)이다. “사용자 결정”은 2026-10-07 사용자 요청이고, “기본안”은 요청에 없는 세부를 개발자가 정한 것이다. 아래 예의 `<@대상>`·`<@처형자>`는 Discord 멘션 자리이고 알림은 가지 않는다.

## 1. 처형 로그 (사용자 결정 문구)

모든 로그는 위아래에 구분선 `------------------------------------------------------`을 두고, 내용 줄 사이에 빈 줄을 둔다. 메시지 끝에는 보이지 않는 한 줄(폭 없는 공백)을 더해 다음 메시지와 간격을 둔다. Discord가 끝의 빈 줄을 지우기 때문이다(기본안).

**적용**
```
------------------------------------------------------
⚔️처형했소

☠️<@대상> 을(를) 🗡️<@처형자> 이(가) 처형하였소.

📜사유는 "<사유>" 이며, ⏳<시간> 동안 시체요.

🕑<풀리는 시각> 이후에 오시오🚨
------------------------------------------------------
```

**해제**
```
------------------------------------------------------
🕊️ 사면되었소

☠️<@대상> 을(를) 🗡️<@사면자> 이(가) 사면하였소

📜사유는 "<사유>" 이였소.

🗽자유를 만끽하시오!⛓️‍💥
------------------------------------------------------
```

- **연장**(이미 처형 중에 더 늘림, 기본안): 적용과 같고, 첫 줄은 `⚔️처형을 연장했소`, 둘째 줄은 `… 이(가) 처형을 연장하였소.`다.
- `<시간>`은 지금까지처럼 `10분`·`1시간 30분`이다. `<풀리는 시각>`은 사용자 예처럼 봇 시간대(KST)의 `2026-10-07 17:03` 모양 글이다(기본안: 예시 형식을 따름).
- 사유가 없으면 `사유 없음`, 실행자를 모르면 `알 수 없는 사람`이다(1.4.0과 같음). 사유는 한 줄로 정리해 400자에서 자른다.
- `/처형`·`/사면`으로 한 처형·사면의 실행자는 지금처럼 명령을 쓴 사람이다.

## 2. `/처형도움`

- 서버 전용 슬래시 명령이다. 누구나 쓸 수 있고 부른 사람에게만 보인다(기본안, `/도움말`과 같음).
- 내용(기본안): `/처형 대상 [시간] [사유]`(시간 형식·기본 30초·최대 28일, 사유 기본 `내맴`·400자), `/사면 대상 [사유]`, `/처형설정 채널관리`·`/처형설정 관리역할`과 각각 쓸 수 있는 사람, 처형·사면할 수 없는 대상, 로그 채널이 정해져야 로그가 올라간다는 점이다.

## 3. 말투 변경 목록

- 새 로그 줄과 `/처형도움` 본문은 서버 말투 안내 문구 목록에 들어간다(사용자 결정). 구분선과 끝의 빈 줄은 그대로다.
- 1.4.0의 옛 로그 문구는 목록에서 빠진다. 서버 문구가 이미 있는 서버는 시작 뒤 새 문구만 다시 써서 더한다(1.4.1 방식).

## 4. 호환

- DB·환경·프롬프트는 바뀌지 않는다. 복귀 대상은 `v1.4.1`이다. 복귀하면 로그가 1.4.0 모양으로 돌아가고 `/처형도움`이 사라진다. 1.4.1b가 더한 문구 행은 1.4.1이 읽지 않는다.
