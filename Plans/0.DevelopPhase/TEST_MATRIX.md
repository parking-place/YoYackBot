# 검증 목록

각 단계 파일의 통과 기준이 원본이며 여기서는 검사 ID·환경·범위를 모아 본다. **현재 모든 검사는 NOT_RUN**이다. 문서 구조 검사 결과가 제품 검사 결과를 바꾸지 않는다.

## 환경 구분

| 코드 | 범위 |
|---|---|
| DOC | 문서 검토·추적성/링크/공개 정보 검사. 제품 실행 PASS를 뜻하지 않는다. |
| MOCK | LXC의 합성 데이터·대역 기반 단위/통합 검사. 실제 Discord/모델 검증과 구분한다. |
| LXC | 제공 LXC의 격리된 개발 경로/DB에서 실행한다. 실제 서비스 사용 여부는 각 검사에 따로 기록한다. |
| LIVE | 개발 Discord 서버/채널에서 실제 이벤트·권한·출력을 확인한다. 실제 Codex 사용 여부도 구분한다. |
| OPS | LXC의 서비스·장애·자원·복구 검증. 운영 변경은 그 단계 실행 시 확인된 대상과 범위에서 수행한다. |

실제 Discord와 실제 Codex가 함께 필요한 단계는 두 가지 증거를 모두 남긴다. 테스트를 LXC에서 했다는 사실만으로 실제 외부 서비스 성공이라고 표시하지 않는다. 문서 검사는 설치/빌드/제품 실행 없이 수행할 수 있다.
