## 목표

`!!말하자면`과 같은 기능을 슬래시 명령 **`/말하자면`**으로도 쓴다(사용자 결정).

- **명령을 내린 것은 다른 사람에게 보이지 않는다.** 답 한 줄(`말하자면 작심삼일? 😅`)만 채널에 일반 채팅으로 올라간다(사용자 결정).
- 사용자 의견: “말하자면 드립은 남들이 보기에 준비동작 없이 바로 튀어나와야 웃길거 같아서”.
- `!!말하자면`은 그대로 둔다.
