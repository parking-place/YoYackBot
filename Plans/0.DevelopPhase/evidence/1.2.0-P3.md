## 정책과 구현

- **채널별 격리**: 페이지 처리, 접근 불가 채널의 `defer`, 오류 처리 안의 `defer`·`block`을 각각 보호한다.
  - 재시도 상태 저장이 실패하면 그 채널만 메모리 `RetryHolds`에 지수 backoff(5초→최대 300초)로 보류한다. DB가 복구돼 저장에 성공하면 보류를 해제한다.
  - 실패 중에는 진척을 기록하지 않는다. 예상 밖 예외는 `kind=unexpected`로만 분류하고 지연 처리한다.
  - 로그는 고정 이벤트명(`initial_backfill_state_write_failed action=defer|block`, `initial_backfill_page_failed kind=unexpected`, `initial_backfill_channel_failed kind=unexpected`)만 남기며 예외 문자열은 남기지 않는다.
- **공용 상태 장애**: `pending`·간격 예약 실패는 loop 수준 backoff(5초→최대 60초, 상태 `backoff`)로 기다린 뒤 다시 진행한다.
  - 모든 후보가 보류 중이면 50 ms 반복 대신 가장 이른 보류 해제 시각(최대 3초)까지 쉰다.
  - 알림 확인·게시 단계도 60초 timeout으로 제한했다.
- **worker 감독**: `_supervise_backfill`이 loop의 예기치 않은 종료를 재시작한다. 재시작 간격은 1초부터 최대 60초이고, 5분 넘게 정상 동작하면 처음 간격으로 돌아간다.
  - `CancelledError`는 삼키지 않고 상태를 `stopped`로 바꾼 뒤 전파한다. 동시에 도는 loop는 1개다.
  - heartbeat와 `health`에 `collection_worker`를 추가했다. 정상은 `running`·`waiting`·`disabled`뿐이다.
  - task 종료(`failed`), 15분 무진척(`stalled`), `backoff`·`restarting`·`stopped`·이전 heartbeat(`unknown`)이면 `ready=false`다. 사용자 상태 표시 확장(F02)은 P5다.
- **조회 한도**: 시간형·개수형 캐시 조회의 `fetchall()`을 128행 `fetchmany`로 바꿨다.
  - 각 행의 본문 바이트 누적과 `행 수 × 최소 직렬화 줄 151바이트` 중 큰 값이 입력 예산을 넘는 즉시 `ConversationTooLarge`로 끝낸다.
  - 최소 줄 크기는 실제 JSONL 줄 생성 함수로 계산한다. 실제 줄은 그보다 작아질 수 없으므로 정상 입력을 일찍 거절하지 않는다.
  - 요청 트리거는 SQL에서 제외한다. 최종 JSONL(scope·메타데이터 포함)은 기존처럼 작업 공간·슬롯·모델 호출 전에 바이트 상한을 검사한다.
- schema 5, 메시지 레이아웃, 설정 백업은 변경하지 않았다.

## T120-P3-D 한정 부하

**사전 고정 기준**: 계획서([P3](../1.2.0/03-worker-memory.md))의 제안값을 실행 전에 그대로 채택했고 변경하지 않았다.
- 입력: 예산 4 MiB(4,194,304바이트), batch 128행, 본문은 행마다 ASCII 256바이트다. 같은 채널·같은 20시간 구간에 10만 행과 100만 행을 넣었다.
- 실행 방식: 크기마다 3회, 총 6회다. 매회 새 프로세스로 실행하고 timeout 60초, `RLIMIT_AS` 512 MiB를 걸었다. 합성 DB 디스크 상한은 2 GiB다.
- 합격 기준:
  - 매회 읽은 행이 16,640행 이하
  - peak RSS가 256 MiB 이하
  - 100만 행 중앙값이 10만 행 중앙값보다 32 MiB 넘게 늘지 않을 것
  - 모든 회차가 초과 실패로 끝날 것
- SQLite: 기본 `cache_size=-2000`, mmap 미사용으로 측정 중 바꾸지 않았다.

DB 생성(`scripts/measure_input_memory.py build`)은 측정과 다른 프로세스에서 끝냈다. 생성 크기는 36,610,048 / 366,276,608바이트였다. 측정은 실제 `CacheOnlyCollector.collect`를 사용했다. 측정 뒤 `/var/tmp/yoyack-p3-load`는 삭제했다.
