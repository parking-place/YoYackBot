  - `execution_settings`(서버당 로그 채널 하나, 행이 없으면 로그 없음)와 `execution_roles`(서버·역할)를 둔다.

- **`/처형설정 채널관리`**: 1.1.3 판정(관리자·채널 관리 권한·봇 관리 역할)을 따른다.
  - 화면에 현재 채널과 텍스트 채널 하나 고르기·저장·해제·닫기가 있다.
  - 봇이 보고 쓸 수 없는 채널은 거절한다(저장 때 다시 확인).
- **`/처형설정 관리역할`**: **서버 관리자(또는 서버 주인)만** 쓴다. 지금 멤버 정보로 판정하고 거절은 본인에게만 보인다.
  - 역할 고르기(고른 목록으로 교체)·저장·전체 해제·닫기가 있다. `@everyone`·연동 관리 역할은 거절한다.
  - 저장할 때 사라진 역할은 뺀다.
- 두 화면 모두 연 사람만 쓸 수 있고, 누를 때마다 권한을 다시 확인하며, 120초가 지나면 만료된다. 같은 값을 덮어쓰는 설정이라 동시 수정 충돌 검사는 없다(기본안).
- **클라이언트**: 명령 그룹 `처형설정`을 등록한다. 채널·역할 삭제 이벤트에서 해당 설정을 지운다. 접속(ready) 때 들어가 있지 않은 서버의 처형 설정을 지운다(서버 목록이 비면 건너뜀).
- 로그: `execution_channel_saved set=true|false`, `execution_roles_saved count=N`(이름·ID 없음).
