# 1.0.0d P2 — 요청별 화자 이름표 검증

- 구현 C [`62503d4`](https://github.com/parking-place/YoYackBot/commit/62503d4ef7b47af4890d301428e8a889bd6d56eb), 추가 시험 C [`b9ebd02`](https://github.com/parking-place/YoYackBot/commit/b9ebd02bdc2416dae405a01e494a57fb3324b6d1). 개발 LXC 격리 후보를 최종 C SHA로 고정했다. [C CI](https://github.com/parking-place/YoYackBot/actions/runs/36539980610) 성공.
- 모델 입력의 범위 레코드에 내부 `P1`→안전한 표시 이름 대응표를 넣고, 각 발언의 `display_name`도 그 요청에서 정한 이름으로 고정했다. 같은 사람의 이전 이름과 최근 이름이 섞여도 한 표시 이름을 쓴다. 작성자 ID는 문서에 기록하지 않는다.
- 합성 검사에서 동명이인 접미사, 빈 이름의 `사용자`, 삭제되어 선택되지 않은 발언, 동시 다른 서버 요청의 분리를 확인했다. 트리거 명령은 입력에서 제외한다. `D3/D4`는 이 합성 범위에서 PASS다.
- 최종 C SHA의 OpenJevLXC에서 전체 `pytest -q` **277 passed**, Ruff 및 저장소 검증 PASS. 첫 전체 시험에서는 무관한 프로세스 종료 시험이 `/proc`가 사라지는 순간 `ProcessLookupError`를 내어 1건 실패했고, 같은 SHA의 재검사에서 277건 모두 통과했다. 원격 C CI도 성공했다.
- 실제 모델 출력·Discord 게시는 이 단계에서 검사하지 않았으며 P3~P5에서 별도 다룬다.

E 원격·CI와 D 종료는 [상태](../1.0.0d/STATUS.md)에 기록한다.
