## 구현

- **`/사면 대상 [사유]`**(`execute_command.py`): 서버 전용이다. 실행할 때 서버 멤버를 다시 읽어 처형 역할·관리자·서버 주인인지 확인한다. 이 확인은 `/처형`과 같은 함수를 쓴다(사용자 결정).
- 기본 사유는 “내맴”이고, `/처형`처럼 공백을 정리하며 400자까지 받는다(사용자 결정).
- **거부 순서**: 사유 길이 → 자기 자신 → 봇 → 서버 주인·관리자 → 같거나 높은 역할(서버 주인은 예외, 사용자 결정) → 봇 권한·역할 높이 → 처형 중 아님(타임아웃 없음·이미 끝남). 거부는 모두 Discord를 부르기 전이다. 문구는 사면에 맞게 따로 두었다.
- **동작**: 사면자를 기억한 뒤 `timeout(None, reason=사유)`를 부른다. 답은 본인에게만 보인다(“🕊️ <@대상>의 처형을 풀었소. 📝 사유: …”). 서비스 로그에는 `pardon_command outcome=` 범주만 남는다.
- **로그**: 봇이 푼 해제의 감사 로그는 120초 안의 사면자를 실행자로 적는다. 1.4.0 `/처형`과 같은 대응표를 쓰고, 한 번만 쓴다.
- **안내 문구**: 사면 문구 9개를 목록에 더했다(179개).
  - 시작할 때 서버 말투가 있는 서버마다 현재 말투 버전에 빠진 키를 찾는다. 이미 문구가 있는 서버는 빠진 키만 다시 써서 더하고(`add`), 문구가 없는 서버는 1.4.0처럼 전체를 쓴다.
  - 더할 때도 말투 버전을 한 트랜잭션에서 확인한다. 로그에 `added=True`가 남는다.
  - 검증에서 떨어져 기본으로 남은 키는 다음 시작 때 다시 시도한다.
