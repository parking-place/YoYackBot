`scripts/benchmark_multi_channel.py`의 1/1000 축척 합성 8채널 혼합 부하에서 같은 서버/다른 서버 모두 **기준선 3/8 → 후보 단일 슬롯 8/8 성공**이었다. 후보 단일 슬롯의 성공 요청 p95 총 지연은 각각 524/521ms, 최대 큐 대기는 490/488ms였다. **가짜 모델**을 두 슬롯으로 실행한 후보는 두 배치 모두 8/8 성공, p95 총 지연 303/280ms, 최대 대기 173/219ms였다. 이 두 슬롯 결과는 실제 Codex 계정의 처리량·사용량을 나타내지 않는다. 실제 계정 한도 소비는 읽기 전용 스냅샷만 확인했고, 병렬 호출은 **NOT_RUN**이다. 계정이 여유 있을 때 별도 버전에서 인증 갱신 안전성과 실제 병렬 호출을 평가한다.

한 채널에서 모델 한도 오류를 주입해도 다른 채널은 게시됐고, 실패 채널은 슬롯·잠금·쿨타임을 남기지 않아 다음 요청에서 성공했다. 동시 엔진 호출은 공유 계정 잠금 때문에 직렬 실행됐으며 요청별 입력 작업공간은 분리됐다. 취소·종료·포화 회귀도 통과했다. `C7`은 **합성 후보 비교와 보수적 단일 슬롯 결정 범위에서 PASS**, 실제 병렬 계정 소비는 NOT_RUN이다. `C8`은 **LXC 합성 장애 범위에서 PASS**다. 실제 Discord 게시 결과는 P5에서 구분한다.
