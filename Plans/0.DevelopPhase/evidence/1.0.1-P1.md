- 산출물: [`src/yoyackbot/usage.py`](../../../src/yoyackbot/usage.py)의 읽기 전용 `read_usage`/`read_account_usage`, [`scripts/probe_usage_shape.py`](../../../scripts/probe_usage_shape.py), [`tests/test_usage.py`](../../../tests/test_usage.py). 인증 갱신 보존은 요약과 같은 `persist_refreshed_auth` 비교·교체를 공유한다. `rateLimitResetCredit/consume` 등 쓰기 메서드는 호출하지 않는다.
- 고정 규칙: `rateLimitsByLimitId.codex` 우선, 없으면 `limitId`가 `codex`인 `rateLimits`만. 창은 `windowDurationMins` 300·10080으로만 식별하고 **응답에 있는 창만** 표시한다. 창이 없거나 다른 길이·중복이면 사용 불가. 남은 비율 = `100 - usedPercent` **내림**. 경고는 표시한 창 중 하나라도 10% 이하.
- 계약 변경: 실제 봇 계정이 주간 창 하나만 반환해 원래 계약(두 창 필수)으로는 항상 사용 불가였다. 계획대로 BLOCKED 판단을 사용자에게 올렸고, 사용자가 2026-09-29 **있는 창만 표시**를 선택했다. [명령 계약](../1.0.1/COMMAND_CONTRACT.md)을 갱신했다.
- 격리: app-server는 요청별 임시 `CODEX_HOME`(0700, 인증 사본 0600)에서 실행한다. 0.156.1 관찰대로 app-server가 `CODEX_HOME`에 상태 파일을 만들기 때문에 공유 인증 디렉터리를 넘기지 않는다. 종료 후 임시 디렉터리를 지운다.
