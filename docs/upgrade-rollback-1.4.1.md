# 1.4.1 승격과 복귀

1. **사전 확인**: [1.4.1 상태](../Plans/0.DevelopPhase/1.4.1/STATUS.md)에서 P1 원격 완료를 확인한다. `VERSION`, wheel, 설치 모듈이 `1.4.1`이고 checkout이 후보의 정확한 코드 SHA인지 확인한다.
2. **중지 전 백업**: 진행 중 요약·`!!말하자면`이 없는지 서비스 로그로 확인한다(접수 줄 수 = 결과 줄 수). SQLite 온라인 백업과 설정 전용 백업을 만든 뒤 중지한다.
3. **설치와 점검**: 후보 wheel을 설치하고 checkout을 같은 SHA로 맞춘다. `check-ready`, 설치 모듈 버전, 프롬프트 `1.4.0-p6-v1`(변경 없음), Gateway·`health`·DB `quick_check`(schema 5)를 확인한다. 슬래시 명령이 9개(채널·관리권한·도움말·말투·속도·말하자면·처형설정·처형·사면)로 동기화되는지 본다. DB·서비스 환경·봇 권한은 1.4.0과 같다.
4. **확인**: 시험 서버에서 처형 역할이 있는 사람이 처형 중인 사람에게 `/사면`을 쓰고, 타임아웃이 풀리며 로그의 사면자가 그 사람인지 본다. 처형 중이 아닌 사람·높은 역할에 대한 거부 안내가 본인에게만 보이는지도 본다. 실제 확인을 하지 못한 항목은 **NOT_RUN**으로 남긴다.

**복귀**가 필요하면 서비스를 정상 중지한 다음 [`v1.4.0`](https://github.com/parking-place/YoYackBot/releases/tag/v1.4.0)의 wheel `1.4.0`과 checkout `312e5b0`을 함께 복원한다. DB·서비스 환경은 그대로 쓴다. 복귀하면 `/사면`이 명령 목록에서 사라진다. 더해진 사면 안내 문구 행은 1.4.0이 읽지 않는다.
