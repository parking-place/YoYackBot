# 1.3.4 승격과 복귀

1. **사전 확인**: [1.3.4 상태](../Plans/0.DevelopPhase/1.3.4/STATUS.md)에서 P1 원격 완료를 확인한다. `VERSION`, wheel, 설치 모듈이 `1.3.4`이고 checkout이 후보의 정확한 코드 SHA인지 확인한다.
2. **중지 전 백업**: 진행 중 요약·`!!말하자면`이 없는지 서비스 로그로 확인한다(접수 줄 수 = 결과 줄 수). SQLite 온라인 백업과 설정 전용 백업을 만든 뒤 중지한다.
3. **설치와 점검**: 후보 wheel을 설치하고 checkout을 같은 SHA로 맞춘다. `check-ready`, 설치 모듈 버전, 프롬프트 `1.3.3-p4-v1`(변경 없음), Gateway·`health`·DB `quick_check`를 확인한다. 슬래시 명령이 6개(채널·관리권한·도움말·말투·속도·말하자면)로 동기화되는지 본다. DB·환경은 바뀌지 않는다.
4. **확인**: 시험 채널에서 한 사람이 `/말하자면`을 쓰고, 다른 사람 화면에 명령 사용 표시 없이 답 한 줄만 보이는지 확인한다. 부른 사람의 대기 표시가 지워지는지, 쿨타임 중에 다시 부르면 안내가 부른 사람에게만 보이는지도 본다. 실제 확인을 하지 못한 항목은 **NOT_RUN**으로 남긴다.

**복귀**가 필요하면 서비스를 정상 중지한 다음 [`v1.3.3`](https://github.com/parking-place/YoYackBot/releases/tag/v1.3.3)의 wheel `1.3.3`과 checkout `b6e2219`를 함께 복원한다. DB·서비스 환경은 그대로 쓴다. 복귀하면 `/말하자면`이 명령 목록에서 사라지고 `!!말하자면`만 남는다.
