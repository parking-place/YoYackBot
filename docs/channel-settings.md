# 주시 채널 설정

`/채널 설정`을 비롯한 요약봇의 모든 슬래시 명령어는 **`애플리케이션 명령어 사용` 권한이 있는 사람이면 누구나** 쓰고 설정할 수 있소(1.1.2a부터, 설치 직후 기본값). Discord는 이 권한을 기본으로 모든 사람에게 주므로 서버 구성원 누구나 주시 채널을 추가·제거·전체 해제할 수 있소. 설정은 Discord 서버별로 저장되며 봇을 재시작해도 유지되오.

사용할 수 있는 사람을 줄이려면 서버 관리자가 **서버 설정 → 연동 → 요약봇 → `/채널`**에서 역할·사람·채널별로 허용·차단하시오. Discord가 이 설정을 먼저 적용하며, 막힌 사람에게는 명령어가 보이지 않소. 권한을 회수해도 이미 열린 설정 화면은 제한 시간(120초)이 끝날 때까지 연 사람이 쓸 수 있소. 설정 화면은 연 사람만 조작할 수 있고, 저장하면 서비스 로그에 저장 시각과 채널 수만 남소(누가 바꿨는지와 채널 이름은 남기지 않음).

1. 설정하려는 서버에서 `/채널 설정`을 여시오. 현재 주시 채널 수와 목록은 명령을 실행한 사람에게만 보이오.
2. **주시할 텍스트 채널 추가**에서 채널을 고르시오. 한 번에 최대 25개를 고를 수 있으며, 더 필요하면 선택을 반복하시오.
3. 목록에서 뺄 채널은 **주시 목록에서 텍스트 채널 제거**로 고르시오. 전부 비우려면 **전체 해제**를 누르시오.
4. 최종 목록을 확인하고 **저장**을 누르시오. **취소**하거나 선택 화면이 만료되면 변경 사항은 저장되지 않소.

봇이 채널을 읽고 메시지를 보낼 수 없거나 텍스트 채널이 아니면 저장할 수 없소. 설정 화면을 연 뒤 권한이나 다른 사람의 설정이 바뀌었다면 명령을 다시 열어 확인하시오.

주시 채널에서는 `!!요약좀` 요약과 `!!요약좀 사용량`·`!!요약좀 상태`·`!!요약좀 채널`이 동작하오. `!!요약좀 채널`은 이 서버의 주시 채널 가운데 명령한 사람에게 보이는 채널의 이름만 알려주오. 상태의 수치는 명령을 친 서버의 값만 보이되, DB 크기는 모든 서버가 함께 쓰는 파일 크기요. [개발 진행 상태](../Plans/0.DevelopPhase/STATUS.md)에서 완료 범위를 확인할 수 있소.
