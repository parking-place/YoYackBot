# 주시 채널 설정

`/채널 설정`은 서버 관리자 또는 **채널 관리** 권한이 있는 사람만 사용할 수 있소. 설정은 Discord 서버별로 저장되며 봇을 재시작해도 유지되오.

1. 설정하려는 서버에서 `/채널 설정`을 여시오. 현재 주시 채널 수와 목록은 명령을 실행한 사람에게만 보이오.
2. **주시할 텍스트 채널 추가**에서 채널을 고르시오. 한 번에 최대 25개를 고를 수 있으며, 더 필요하면 선택을 반복하시오.
3. 목록에서 뺄 채널은 **주시 목록에서 텍스트 채널 제거**로 고르시오. 전부 비우려면 **전체 해제**를 누르시오.
4. 최종 목록을 확인하고 **저장**을 누르시오. **취소**하거나 선택 화면이 만료되면 변경 사항은 저장되지 않소.

봇이 채널을 읽고 메시지를 보낼 수 없거나 텍스트 채널이 아니면 저장할 수 없소. 설정 화면을 연 뒤 권한이나 다른 관리자의 설정이 바뀌었다면 명령을 다시 열어 확인하시오.

주시 채널에서는 `!!요약좀` 요약과 `!!요약좀 사용량`·`!!요약좀 상태`·`!!요약좀 채널`이 동작하오. `!!요약좀 채널`은 이 서버의 주시 채널 가운데 명령한 사람에게 보이는 채널의 이름만 알려주오. 상태의 수치는 명령을 친 서버의 값만 보이되, DB 크기는 모든 서버가 함께 쓰는 파일 크기요. [개발 진행 상태](../Plans/0.DevelopPhase/STATUS.md)에서 완료 범위를 확인할 수 있소.
