# 주시 채널 설정

`/채널 설정`을 비롯한 요약봇의 모든 슬래시 명령어는 **서버 관리자 또는 채널 관리 권한이 있는 사람**, 그리고 그 서버의 **봇 관리 역할**을 가진 사람만 쓸 수 있소(1.1.3부터). 설정은 Discord 서버별로 저장되며 봇을 재시작해도 유지되오.

봇 관리 역할은 관리자나 이미 봇 관리 역할을 가진 사람이 **`/관리권한 설정`**에서 고르시오. 화면에서 역할을 추가·제거하거나 전체 해제한 뒤 저장하면 되오. `@everyone`과 봇·연동이 관리하는 역할은 고를 수 없소. 관리 역할 사용자가 자기 역할을 빼면 그 사람은 더 쓸 수 없지만, 서버 관리자는 언제나 다시 설정할 수 있소. 역할이 삭제되거나 봇이 서버에서 나가면 그 설정도 지워지오.

Discord는 봇이 역할별로 명령어를 보이거나 숨기게 해 주지 않소. 그래서 명령어 목록에는 보이지만, 권한이 없는 사람이 실행하면 봇이 본인에게만 “이 명령은 관리자나 봇 관리 역할만 쓸 수 있소.”라고 답하오. 목록에서 아예 숨기려면 서버 관리자가 **서버 설정 → 연동 → 요약봇**에서 명령어를 역할별로 제한하시오(Discord가 먼저 적용하오). 설정 화면은 연 사람만 조작할 수 있고, 조작할 때마다 권한을 다시 확인하며, 제한 시간은 120초요. 저장하면 서비스 로그에 저장 시각과 개수만 남소(누가 바꿨는지와 채널·역할 이름은 남기지 않음).

서버 운영자는 서비스 호스트에서 서비스 계정으로 `python -m yoyackbot manager-roles list|set|clear <서버 ID> [역할 ID …]`를 실행해 봇 관리 역할을 확인하거나 되살릴 수 있소(관리자가 모두 잠긴 경우 등).

1. 설정하려는 서버에서 `/채널 설정`을 여시오. 현재 주시 채널 수와 목록은 명령을 실행한 사람에게만 보이오.
2. **주시할 텍스트 채널 추가**에서 채널을 고르시오. 한 번에 최대 25개를 고를 수 있으며, 더 필요하면 선택을 반복하시오.
3. 목록에서 뺄 채널은 **주시 목록에서 텍스트 채널 제거**로 고르시오. 전부 비우려면 **전체 해제**를 누르시오.
4. 최종 목록을 확인하고 **저장**을 누르시오. **취소**하거나 선택 화면이 만료되면 변경 사항은 저장되지 않소.

봇이 채널을 읽고 메시지를 보낼 수 없거나 텍스트 채널이 아니면 저장할 수 없소. 설정 화면을 연 뒤 권한이나 다른 사람의 설정이 바뀌었다면 명령을 다시 열어 확인하시오.

주시 채널에서는 `!!요약좀` 요약과 `!!요약좀 사용량`·`!!요약좀 상태`·`!!요약좀 채널`이 동작하오. `!!요약좀 채널`은 이 서버의 주시 채널 가운데 명령한 사람에게 보이는 채널의 이름만 알려주오. 상태의 수치는 명령을 친 서버의 값만 보이되, DB 크기는 모든 서버가 함께 쓰는 파일 크기요. 1.2.0부터 상태 끝에 **명령을 친 채널의 수집 형편**이 붙소. 단계(처음 수집·연결 공백 대조·재시도 대기·막힘·준비 안내 대기·요약 가능), 이번 수집에서 처리한 쪽 수, 이 채널에 저장된 대화 수, 마지막 진척, 다음 재시도, 막힌 이유를 보여주오. 전체 분량을 모르니 백분율·남은 시간은 보여주지 않고, 읽지 못한 값은 0이 아니라 '확인할 수 없소'로 적소. 다른 채널의 이름·형편은 보이지 않소. 수집이 덜 끝났을 때의 대기 안내에도 같은 단계 한 줄이 붙소.
