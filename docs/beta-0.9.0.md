# 0.9.0-P2 개발 Discord 베타 점검표

실제 개발 봇의 명령 이벤트와 게시 결과만 확인한다. 개인 대화 대신 전용 시험 채널의 합성 대화만 사용한다. 각 실행에서 입력 명령, 결과 유형, 같은 채널 게시 여부, 민감 정보/원문 노출 여부를 **내용과 식별값 없이** 집계한다.

## 관리자와 일반 사용자 경로

| 경로 | 기대 결과 |
|---|---|
| 관리자 `/채널 설정` 열기·저장 | 서버별 현재 주시 목록이 보이고 저장 후에도 유지된다. |
| 일반 사용자 설정 접근 | 관리자 권한이 없으면 설정을 바꿀 수 없고 비공개 안내를 받는다. |
| 미주시 채널의 요약 요청 | History·CLI·게시·성공 대기 시간 없이 안전한 안내를 받는다. |
| 주시 채널의 `!!요약좀 도움` | 처리 중/대기 시간 중에도 도움말을 받을 수 있다. |

## 명령 옵션

아래 8개 옵션을 실제 일반 사용자 메시지로 보내고 형태별 정상 수락 또는 빈 대화 안내를 확인한다. 빈 결과는 모델 게시 성공을 뜻하지 않으며 성공 대기 시간을 만들지 않는다. 결과가 게시되면 300초 대기 시간이 끝난 뒤 다음 성공 요청을 보낸다.

| 형태 | 입력 예시 | 주요 경계 |
|---|---|---|
| 기본 | `!!요약좀` | 기본 1시간 |
| 숫자 | `!!요약좀 3` | 3시간 |
| 시간 | `!!요약좀 2시간` | 2시간 |
| 분 | `!!요약좀 30분` | 30분 |
| 개수 | `!!요약좀 100개` | 최신 일반 사용자 최대 100개 |
| 오늘 | `!!요약좀 오늘` | KST 자정 |
| 일 | `!!요약좀 2일` | 2일 |
| 주 | `!!요약좀 1주` | 7일 |

합성 대화의 성공 결과에서는 화자·결정/미해결·하오체·범위 머리말·멘션 억제·장문 분할을 검토한다. `0분` 등 잘못된 옵션, 중복 요청, 전역 대기열·부분 게시 실패는 자동/격리 검사와 실제 사용자 안내를 구분한다. 사용자 피드백은 치명/높음/낮음 심각도 및 재현 조건으로 기록하고, 공개 문서에는 원문을 옮기지 않는다.

이 단계의 정확 SHA와 실제 Discord 확인 결과는 [증거](../Plans/0.DevelopPhase/evidence/0.9.0-P2.md)에 기록한다. 자동 테스트, 이전 버전의 실제 Discord 결과, 이번 실제 사용자 확인을 서로 바꾸어 부르지 않는다.
