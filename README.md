최초 0.0.0~1.0.0 로드맵은 11개 버전, 버전별 5단계, 총 55단계다. 각 단계는 작업과 검증을 마치고 **Git commit → GitHub push → 원격 반영 확인**까지 끝나야 완료된다.

1.0.0a, 1.0.0b-1, 1.0.0c, 1.0.0d, 1.0.1, 1.0.2, 1.0.2b, 1.0.2c, 1.1.0, 1.1.0a, 1.1.1, 1.1.1a, 1.1.2, 1.1.2a, 1.1.3, 1.1.3a, 1.2.0, 1.3.0, 1.3.1, 1.3.2, 1.3.3은 출시됐다. 1.0.0d에서 실제 닉네임 표시와 최대 4개 병렬 모델 호출을, 1.0.1에서 `사용량`·`[범위] 자세히`·`[범위] 짧게`·`상태` 명령을, 1.0.2에서 요약 시작·진행 중 범위 안내를, 1.0.2b에서 `!!요약좀 채널` 주시 채널 목록을, 1.0.2c에서 1분 쿨타임과 거친 하오체 요약 말투를, 1.1.0에서 짧은 기본 요약·`길게`·아주 긴 `자세히`·추가 요청·비꼬는 말투를, 1.1.0a에서 주제별로 읽기 쉬운 형식과 요약창섭의 떡밥 한줄 평가를, 1.1.1에서 기본보다 먼저 따르는 추가 요청과 한줄 비평·`평가 빼줘`를, 1.1.1a에서 결론 안 난 이야기를 비꼬지 않고 진행 중으로 다루는 요약을, 1.1.2에서 이모지·주제별 한줄 비평·주제마다 1~2줄인 짧은 기본 요약을, 1.1.2a에서 마크다운 요약(제목·닉네임 밑줄·인용 비평)·짧은 도움말·누구나 쓰는 슬래시 명령어를, 1.1.3에서 관리자 기본값과 `/관리권한 설정`으로 고르는 봇 관리 역할을, 1.1.3a에서 이모지를 넣은 안내 문구를, 1.2.0에서 B01~B14 버그 수정과 상태의 현재 채널 수집 형편·범위 안 답글 연결을, 1.3.0에서 `/말투`·답장으로 범위 지정·떡밥 한줄 평가 후보 심사·`!!말하자면` 사자성어 한마디를, 1.3.1에서 시작 안내 없이 따로 쿨타임이 도는 `!!말하자면`·본인에게만 보이는 `/도움말`·서버별 빠른 모드 `/속도 설정`을, 1.3.2에서 요청 단계별 소요 시간 로그를, 1.3.3에서 대화의 프롬프트 직접 전달(긴 대화 누락 수정)과 응답 시간 단축을 제공한다. 단계별 실제 진행은 각 버전의 상태 문서를 따른다.

1.0.2의 요약 시작·진행 중 범위 안내는 `v1.0.1` 기준으로 다시 검토한 5단계 계획으로 구현했다.

1.2.0은 Improvements의 B01~B14 수정과 F02 수집 진행·차단 원인, F10 범위 안 답글 연결만 포함한 7단계 버전이다. 기존 1.2.0의 `/말투`·답장 범위·평가 다양화는 1.3.0으로 이동했다. 1.3.0에는 최근 30개 대화로 후보 4개 중 사자성어 또는 네 글자 단어 하나를 골라 고정 비하오체·이모지로 말하는 기능을 추가해 7단계·16검사로 확장했다. 1.3.0은 이 계획대로 구현·출시했다. 이력과 병합 기준은 [계획 이동 기록](Plans/0.DevelopPhase/1.2.0/MIGRATION.md)을 따른다.

`.private`, 실제 인증값, Discord 대화 원문, SQLite DB와 임시 로그는 공개 저장소에 올리지 않는다.

현재 구현은 주시 채널의 일반 사용자 대화만 요약한다. `!!요약좀`의 기본 1시간, 숫자·분·시간·개수·오늘·일·주 옵션, 범위 뒤의 `길게`/`자세히`(기본은 짧게)와 추가 요청, `!!요약좀 사용량`·`!!요약좀 상태`·`!!요약좀 채널`과 본인에게만 보이는 `/도움말`을 지원한다. 사용량은 봇 계정이 보고하는 창(현재 주간 창)만 표시하고, 상태의 DB 크기는 모든 서버가 함께 쓰는 파일 크기다. 주시 채널은 서버 관리자가 `/채널 설정`으로 고르며, 결과는 요청한 채널에만 게시한다. 성공한 요약에는 1분 대기 시간이 적용된다(1.0.2c부터, 이전 5분).

검증과 제한은 [0.9.0 후보 검토](docs/release-candidate-0.9.0.md)와 [1.0.0 출시 검토](docs/release-review-1.0.0.md)에 기록한다. 사용자 요청으로 8시간·24시간 연속 시험과 [1.0.0 새 배포의 실제 게시 확인](Plans/0.DevelopPhase/1.0.0/POSTING_WAIVER.md)을 생략했다. 장시간 가용성과 새 배포의 게시 결과는 미검증이다. 실제 Discord 권한 회수, 일반 사용자 설정 거부 조작, 외부 자동 경고도 검증·구축되지 않았다. 중요한 날짜·결정은 원문과 대조해야 한다. 정식 `v1.0.0` 태그와 배포 결과는 [GitHub Release](https://github.com/parking-place/YoYackBot/releases/tag/v1.0.0)와 [단계 증거](Plans/0.DevelopPhase/STATUS.md)에서 확인한다.
